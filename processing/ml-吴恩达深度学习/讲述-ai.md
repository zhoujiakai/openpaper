## 第一门课：神经网络和深度学习

**主持人**：吴恩达用了一个很经典的例子来开场——房价预测。你有一堆房子的特征数据，想要预测价格。最简单的做法是什么？线性回归。但房价不能为负，所以你在输出上套一个 `max(0, y)`，这其实就是 ReLU 激活函数。吴恩达说了一句让我印象很深的话：**线性回归就是只有一个神经元的神经网络**。一下子就把神经网络从神坛上拉下来了。

接着他扩展了这个例子：当你增加更多特征、堆叠更多层、加入更多神经元，你就得到了一个深层神经网络。整个第一门课的核心就是在帮你建立这个直觉。

### 从逻辑回归开始

**主持人**：课程的第二周是整个数学基础最密集的部分。吴恩达拿出了一张猫的图片，问：这张图是不是一只猫？这就是一个二元分类问题。他把一张 64x64x3 的图片展开成一个 12288 维的向量，然后用逻辑回归来做分类。

逻辑回归听起来简单，但吴恩达把它的每一个计算步骤都拆解得非常清楚：前向传播就是计算 `z = wx + b`，然后过 sigmoid 得到预测值 `ŷ`；损失函数用的是交叉熵——你如果还记得的话，就是 `-[y log(ŷ) + (1-y) log(1-ŷ)]`。他从概率论的角度推导了这个公式，这一点特别棒，让你理解交叉熵不是一个凭空定义的公式，而是从最大似然估计自然推导出来的。

### 向量化：为什么这么重要

**主持人**：这一部分有一个让我至今记忆犹新的演示。吴恩达在 Jupyter Notebook 里写了两段代码，都是计算两个一百万维向量的点积。用 for 循环，花了大概 450 毫秒；用 `np.dot()`，只花了 1.5 毫秒。三百倍的差距！这就是向量化的威力。

他花了整整三节课来讲怎么用向量化消除所有的 for 循环。最终的成果特别优雅——一次梯度下降只用了五行代码：

```python
z = np.dot(w.T, X) + b
A = 1 / (1 + np.exp(-z))     # sigmoid
dz = A - Y
dw = (1/m) * np.dot(X, dz.T)
db = (1/m) * np.sum(dz)
```

如果你跟着课程一步步推导过来，看到这五行代码的时候会有一种恍然大悟的感觉。

### 激活函数的选择

**主持人**：吴恩达介绍了四种激活函数——sigmoid、tanh、ReLU、Leaky ReLU——并且给出了非常实用的经验法则：

- sigmoid 除了二分类的输出层，基本别用。
- tanh 比 sigmoid 好得多，因为它是零均值的。
- **ReLU 是最好的默认选择**，因为它的导数在正半轴恒为 1，梯度下降更快。
- 如果不确定用什么，就用 ReLU。

这个法则到现在依然成立。吴恩达还特别强调了一个很多人会忽略的点：隐藏层必须使用非线性激活函数，否则不管堆多少层，整个网络都等价于一个线性回归。

### 访谈：Geoffrey Hinton

**主持人**：第一门课里有一个很特别的环节——吴恩达采访了 Geoffrey Hinton，就是那位被称为"深度学习教父"的人。Hinton 分享了他从 1970 年在剑桥读心理学，到在爱丁堡用神经网络做视觉理解、被主流学界排斥、最后坚持下来的故事。

Hinton 给深度学习初学者提了一条非常有性格的建议：**别看太多论文**。找到直觉告诉你别人做得不好的地方，去把它做好。相信自己的直觉，不要放弃。他还说一定要一直编程，因为只有编程才能发现让算法真正生效的那些小技巧。

## 第二门课：优化深度神经网络

**主持人**：如果说第一门课教你搭一个能跑的神经网络，第二门课就是教你怎么把它调好。这是实操性最强的一门课，内容密度也最高。

### 训练/开发/测试集的划分

**主持人**：吴恩达花了不少篇幅讲数据集的划分策略。在传统机器学习时代，数据集只有几百到一万条，用 70/30 或者 60/20/20 的比例。但在深度学习时代，数据可能是百万级别的，用 98/1/1 就够了。

但他强调了一个更关键的点：**训练集和测试集必须来自相同的分布**。他举了一个真实的教训——他的团队用中等收入地区的数据训练了一个贷款审批模型，三个月后突然被要求在低收入地区测试，效果当然很差。这个原则听起来简单，但在实际项目中非常容易犯错。

### 偏差与方差的诊断框架

**主持人**：吴恩达给出了一个非常清晰的诊断框架。拿到一个模型效果不好，你先看：

- 训练集上表现差？那是**高偏差**——用更大的网络、训练更久、换更好的优化算法。
- 训练集好但验证集差？那是**高方差**——加正则化、收集更多数据。
- 验证集好但测试集差？可能是**验证集过拟合**——需要更大的验证集。

这就是他反复强调的"正交化"思想——每个优化手段只解决一个问题，不要混在一起。

### 正则化的武器库

**主持人**：这门课介绍了三种正则化方法，我至今还会用到：

1. **L2 正则化**：在代价函数里加上权重的 Frobenius 范数。吴恩达推导了加上 L2 正则化之后，权重更新公式会多出一个 `(1 - αλ/m)` 的衰减因子，所以它也叫"权重衰减"。直觉上，正则化让所有权重变小，模型退化为更简单的函数。

2. **Dropout**：训练时随机丢弃一部分神经元。吴恩达解释说，这让模型不能过度依赖任何一个特征——如果某个神经元随时可能被关掉，网络就必须学会"分散投资"。他给了一个重要的实战建议：**调试时先关掉 dropout**，确保代价函数单调下降，没有代码 bug，再打开。

3. **数据增强**：在计算机视觉中尤其有效——镜像、裁剪、旋转、颜色偏移，都能有效增加数据量。

### 神经网络训练三板斧

**主持人**：这一部分有三个技巧，组合在一起特别有效率：

**归一化输入**：把输入特征减均值除以标准差，让代价函数的等高线图变圆。吴恩达用图像直观地展示了归一化前后的区别——归一化前梯度下降走之字形，归一化后直直地走向最优点。

**权重初始化**：不同的激活函数用不同的方差来初始化权重。ReLU 用 `sqrt(2/n)`，tanh 用 `sqrt(1/n)`。这样做能部分解决深层网络中的梯度消失和梯度爆炸问题。

**梯度检查**：在 debug 阶段，用手动计算的双边差值近似梯度，和反向传播算出来的梯度比较。如果差距在 10^-7 量级就正常，10^-3 量级就肯定有 bug。吴恩达特别提醒：检查时要关掉 dropout，而且训练时千万别开着梯度检查，太耗算力。

### 优化算法：从 SGD 到 Adam

**主持人**：这是第二门课最核心的章节之一。吴恩达从指数加权平均讲起——一个只用一行代码就能计算所有历史数据加权平均的巧妙方法——然后一路推导到深度学习最常用的优化器。

先是**动量梯度下降**：把梯度想象成小球在碗里滚动，动量让小球的左右振荡互相抵消，同时加速向碗底滑去。

然后是 **RMSprop**：对梯度变化大的参数除以一个更大的值，变化小的参数除以一个更小的值，减少振荡。

最后两者结合就是 **Adam**——Adaptive Moment Estimation。吴恩达给出了几乎不需要调的超参数默认值：β₁=0.9，β₂=0.999，ε=10⁻⁸。这套默认值到现在都是行业标准。

### 批归一化（BatchNorm）

**主持人**：如果只能从这门课里带走一个技巧，很多人会选 BatchNorm。它对隐藏层的输出做归一化，让每一层都像是"单独在训练"一样，不太受前面层权重更新的影响。

吴恩达解释了 BatchNorm 好用的原因：它让超参数搜索变得更鲁棒，模型对学习率的选择不再那么敏感。而且由于在 mini-batch 上计算的均值和方差天然带有噪声，BatchNorm 还附带了轻微的正则化效果。

当然，测试时不能对单个样本做 BatchNorm。解决办法是在训练时对每一批的均值和方差做指数加权平均，测试时直接用这些平均值。

### 访谈：Yoshua Bengio

**主持人**：吴恩达和深度学习三巨头之一 Yoshua Bengio 的对话也很有意思。Bengio 分享了一个细节：ReLU 函数一开始被学界排斥，因为它的导数在负半轴为零，大家认为激活函数必须是平滑的。直到 2009 年才通过实验发现，ReLU 反而效果更好。这让我们反思：很多被奉为真理的设计原则，可能只是来自直觉而非实证。

Bengio 的建议是：多动手写代码，不要满足于调用框架却不理解底层。他还说，不需要读五年博士，只要有基础的计算机和数学知识——概率论、代数、优化、微积分——就能在六个月内学会深度学习。

## 第三门课：结构化机器学习项目

**主持人**：这门课全部是视频，没有编程作业，但它可能是在实际工作中最有用的部分。它不教你新的算法，而是教你怎么思考机器学习项目。

### 单一数字评估指标

**主持人**：吴恩达反复强调一个观点：**验证集 + 单一数字评估指标**，能极大地加速迭代周期。他举了猫分类器的例子——你有很多模型要比较，每个模型都有精确率和召回率，怎么选？他说用 F1 分数，也就是精确率和召回率的调和平均数。

如果同时有多个指标——比如准确率和运行时间——可以用评估矩阵：挑一个作为优化指标（越高越好），其他作为满意指标（达到阈值即可）。比如"准确率尽可能高，但运行时间必须小于 100 毫秒"。

### 误差分析

**主持人**：这可能是这门课最有实操价值的内容。吴恩达演示了怎么系统地分析模型的错误：拿一个表格，第一列是所有分错的样本，第一行是每个错误的可能原因，然后逐个人工检查并统计。比如猫分类器错误中，有多少是因为把狗当成了猫？有多少是因为图片太模糊？有多少是标签本身就标错了？

做完这个分析，你就知道时间最应该花在哪个方向上。很多时候我们凭直觉以为应该优化某个方向，结果数据告诉我们最该修的其实是另一个问题。

### 贝叶斯误差与人类水平

**主持人**：吴恩达引入了一个重要的概念——贝叶斯误差，也就是理论上最低的错误率。在人类擅长的任务上（图像识别、语音识别等），吴恩达直接拿人类水平作为贝叶斯误差的近似。

这个框架帮助你在偏差和方差之间做出选择：
- 训练误差离人类水平还很远？先减偏差。
- 训练误差接近人类水平但验证误差比较大？减方差。
- 两个都接近人类水平了？恭喜你，再提升就很困难了。

### 数据不匹配问题

**主持人**：吴恩达引入了一个很多课程不会讲的概念——训练-验证集（Training-dev set）。当训练集和验证集来自不同分布时（比如训练集是网上抓的高清图，验证集是用户上传的模糊图），传统的偏差/方差分析就不够用了。你需要在训练集里再分出一部分作为训练-验证集，来区分"方差问题"和"数据不匹配问题"。

### 迁移学习与多任务学习

**主持人**：这两招在数据量少的场景下特别有用。迁移学习就是把一个在大数据集上训练好的模型（比如在 ImageNet 上训练的视觉模型），迁移到你的小数据任务上（比如医疗影像诊断）。方法也很简单：冻结前面的卷积层，只重新训练最后的全连接层和 Softmax 输出。

吴恩达强调迁移学习能成功的关键条件：两个任务的输入类型必须相同；源任务的数据量要远大于目标任务；源任务的浅层特征对目标任务有用。

### 端到端学习的取舍

**主持人**：这门课的最后一个大主题是端到端学习 vs 分阶段系统。吴恩达的观点很务实：端到端学习很优雅，但需要大量数据。当数据不够多的时候，把一个任务拆成多个阶段、在每个阶段中融入人类的领域知识，往往效果更好。

他举了自动驾驶的例子：直接端到端学习"从传感器输入到方向盘转角"需要海量数据，而分阶段——先检测行人和车辆、再规划路径、最后控制转向——每个阶段的模型都更容易训练，也更容易 debug。

### 访谈：Andrej Karpathy

**主持人**：吴恩达采访了 Andrej Karpathy，就是后来特斯拉 AI 的负责人。Karpathy 的入行经历很有趣：他本科读认知科学，对传统 AI 课讲的决策树和搜索算法完全不感兴趣，直到接触到神经网络——通过优化目标函数自动发现规律，不需要人工显式编程——他才确定这就是他想做的方向。

Karpathy 建议是：学深度学习一定要动手写底层代码，不能只调包。这样既能加深理解，出问题也才懂得怎么 debug。

## 第四门课：卷积神经网络

**主持人**：从这门课开始进入具体应用领域。卷积神经网络是整个计算机视觉的基石。

### 卷积的工作原理

**主持人**：吴恩达从一个极简的例子开始——用一个 3x3 的垂直边缘检测过滤器，对一张 6x6 的灰度图做卷积，就能提取出图像中的竖线。这个过滤器长这样：

```
 1  0 -1
 1  0 -1
 1  0 -1
```

他把卷积操作比作一个滑动的窗口，窗口内的每个像素和过滤器对应位置的权重相乘然后求和。关键洞察是：**过滤器的值是可以学习的**。通过训练，网络能自动学到任意角度的边缘检测器。

### 经典网络架构巡礼

**主持人**：吴恩达带我们回顾了卷积网络的进化史：LeNet-5 → AlexNet → VGG-16。每一代都有代际的突破。

LeNet-5 是 1998 年的手写数字识别网络，结构简单但设计优雅。AlexNet 是 2012 年引爆深度学习热潮的网络，用了 ReLU 激活函数，针对 GPU 做了优化。VGG-16 是架构最简洁的一个——规律性地把特征图尺寸减半、通道数翻倍，直到 512 维。

吴恩达建议的顺序也很有意思：先读 AlexNet 论文，再读 VGG，LeNet 论文反而比较难读。

### ResNet：让深度真正发挥作用

**主持人**：残差网络是现代深度学习的标配。它的核心思想极其简单但非常有效：在第 L 层的输出上直接加上第 L-2 层的输入——叫做"跳跃连接"。

为什么有效？吴恩达给了一个直觉：如果没有残差连接，网络越深训练误差反而越大，因为更深的网络连"恒等映射"都学不好。加了残差连接后，如果后面的层学不到任何有用的东西，它们可以学会什么都不做——权重趋近于零——这样整个块就退化为恒等映射。梯度下降很容易学会这一点，所以添加残差块至少不会损害原有性能，有时还能提升。这让 ResNet 能堆到 100 甚至 1000 层。

### MobileNet 与 EfficientNet

**主持人**：吴恩达还讲了移动端和嵌入式场景。核心技巧是深度可分离卷积——把一次普通卷积拆成两步：先对每个通道单独做 2D 卷积，再用 1x1 卷积混合通道信息。计算量只有原来的约十分之一。

MobileNet V2 在此基础上加了残差连接和 Expansion 层，先扩充特征维度再压缩回去。EfficientNet 则让你根据设备的算力灵活调整网络的分辨率、宽度和深度。这些都是学完之后可以立刻用到项目里的架构。

### 目标检测：YOLO 算法

**主持人**：第三周的内容特别精彩。吴恩达从目标定位讲起，一路推导到完整的 YOLO 算法。

YOLO 的核心思想是把图像分成网格，每个网格预测边界框的位置、尺寸、置信度和类别。然后通过交并比和非极大值抑制来筛选出最终的检测框。

吴恩达把整个流程拆解得特别清楚——从怎么定义输出格式（每个网格一个向量包含了 Pc、b_x、b_y、b_h、b_w 和各种类别概率），到怎么用锚框处理一个网格中同时出现多个目标的情况，再到怎么用非极大值抑制去除重复框。学完之后你完全能自己实现一个简易的目标检测器。

### 人脸识别：三元损失

**主持人**：吴恩达在人脸识别部分引入了一个很有意思的概念——孪生神经网络，就是用一个网络把图片编码成固定长度的向量，然后比较两个向量的距离来判断是不是同一个人。

关键是训练方法：**三元损失**。你需要三个样本——锚点 Anchor、正例 Positive（同一个人）、负例 Negative（不同的人）——训练的目标是让锚点和正例的距离比锚点和负例的距离至少小一个阈值 α。吴恩达特别强调，APN 不能随机选，要选难样本，否则模型太容易满足约束，学不到有用的特征。

### 神经风格迁移

**主持人**：这是整个课程中视觉效果最惊艳的部分。你把一张内容图片比如金门大桥的照片，和一张风格图片比如梵高的《星夜》，合在一起生成一张"梵高风格的金门大桥"。

背后的数学非常优雅：代价函数由两部分组成。内容代价比较两张图片在某个隐藏层的激活值差异。风格代价比较的是隐藏层中不同通道之间的相关性——这个相关性定义了"风格"。一个通道检测竖纹，一个通道检测橘色，如果它们在图片的同一个位置总是一起出现，那就说明这张图片的风格有"竖纹常有橘色调"的特征。

这是一篇 2015 年的论文（Gatys et al.），吴恩达说这篇论文不难懂，建议自己去看。

### 访谈：杨立昆（Yann LeCun）

**主持人**：卷积神经网络之父杨立昆的访谈也收录在这门课里。他讲述了自己怎么在所有人都唱衰神经网络的"寒冬"期坚持研究，最终 CNN 成为计算机视觉的主流方法。

杨立昆的建议非常接地气：**让自己变得有用**。找一个你认为重要而且感兴趣的论文，把它实现出来并把代码开源。工作会自动找上门来的。

## 第五门课：序列模型

**主持人**：最后一门课聚焦在自然语言处理和时间序列问题上。这是我个人觉得最烧脑的一门课，因为它引入了全新的网络架构。

### RNN 与梯度消失

**主持人**：吴恩达用命名实体识别任务来引出 RNN：一个句子中，"Teddy"是泰迪熊还是罗斯福总统的名字？这需要看上下文——"Teddy bears" 还是 "Teddy Roosevelt"。

RNN 的基本思想是在时间维度上展开循环：每个时间步接收当前输入和上一个时间步的隐藏状态，输出当前时间步的预测。但这个架构有一个致命弱点——梯度消失。早期的时间步对远处的输出几乎没有影响。

吴恩达给了一个很直观的例子：
```
The cat, which already ate ..., was full.
The cats, which already ..., were full.
```
前面的 cat/cats 决定了后面用 was/were，但普通的 RNN 很难捕捉到这种远距离依赖。

### GRU 和 LSTM

**主持人**：解决 RNN 梯度消失问题的核心是"门控"机制。吴恩达先讲 GRU（门控循环单元），再讲 LSTM（长短期记忆网络）。

GRU 引入了两个门：更新门和重置门。更新门控制旧信息保留多少、新信息注入多少；重置门控制历史信息中有多少会被用来计算新候选值。

LSTM 更复杂一些，有三个门：遗忘门、输入门、输出门。它还专门把"细胞状态"和"激活值"分开——细胞状态像一条高速公路，信息可以几乎不受阻碍地从序列开头传到结尾。

吴恩达的建议很实在：GRU 和 LSTM 在不同任务上各有胜负，但 LSTM 被更多人使用更成熟，**不确定用哪个就选 LSTM**。

### 词嵌入：词语的向量表示

**主持人**：这门课最让我痴迷的是词嵌入。传统的独热编码中，"猫"和"狗"的距离等于"猫"和"火箭"的距离——都是零相关。但词嵌入能学到：`king - man + woman ≈ queen`。

这背后是一个训练好的嵌入矩阵，把词典里每个词的 300 维向量学到了语义丰富的空间中。吴恩达介绍了三种学习词嵌入的方法：

- **Word2Vec 的跳词模型**：用一个词的嵌入预测它上下文窗口中的词。
- **负采样**：不计算完整的 Softmax，只区分正样本和几个随机负样本，大大加速训练。
- **GloVe**：统计词与词的共现次数，让嵌入向量拟合这些统计量。

他特别强调了词嵌入的迁移学习价值：从一个超大语料中学到的词嵌入，可以直接迁移到只有一万条数据的情感分类任务中，效果出奇地好。

### 序列到序列与束搜索

**主持人**：机器翻译是序列到序列模型的经典应用。一个编码器把源语言句子编码成上下文向量，一个解码器从这个向量生成目标语言。

核心挑战是：词汇表有十万个词，可能的翻译组合是天文数字，怎么找出最优的？吴恩达介绍了束搜索——每一步只保留概率最高的 B 个候选序列（B 通常取 3-10），大幅缩小搜索空间。

他还教了一个很实用的分析技巧：当模型翻译结果不好时，怎么判断是 RNN 的问题还是束搜索的问题？把人工翻译和模型翻译分别送进 RNN，比较两者的概率——如果人工翻译的概率更高，说明 RNN 没问题，是束搜索没找到最优序列，加大 B 就行。

### 注意力机制与 Transformer

**主持人**：这是课程的压轴部分，也是近年来深度学习最重要的架构创新。

传统的序列到序列模型会把整个输入编码成一个固定长度的向量，长句子信息容易丢失。注意力机制让解码器在生成每个词时，动态地"关注"输入序列的不同位置——注意力权重告诉你，生成这个词的时候应该主要看原句的哪个部分。

吴恩达接着推导了自注意力机制：输入序列中的每个词都和所有其他词计算关联度，生成上下文感知的表示。然后是多头自注意力——同时用多组不同的注意力头从不同角度理解句子。

最后所有这些组件拼在一起就是 **Transformer**。编码器是多头自注意力加前馈网络的堆叠，解码器也类似但多了一个交叉注意力层来关注编码器的输出。加上位置编码来处理词序信息，用掩码机制保证训练时不能偷看未来的词。

吴恩达在结语中提到，Transformer 催生了 BERT 等大语言模型。如果你在今天听这期播客，整个大模型时代的基石就是从 Transformer 开始的。

## 结尾

**主持人**：好，到这里五门课的核心内容就全部讲完了。最后我想分享我从这门课里收获最大的几个点：

第一，**动手实践永远是最好的老师**。吴恩达请了这么多位大佬来访谈——Hinton、Bengio、LeCun、Karpathy——你会发现他们给出的建议惊人地一致：一定要写代码，不要只理解概念。只有在编程中你才能发现那些让算法真正生效的微小细节。

第二，**建立系统性的诊断框架**。机器学习不是靠直觉瞎调参。偏差还是方差？数据不匹配还是过拟合？RNN 还是束搜索？这套诊断思维让你在遇到问题时知道该往哪个方向走。

第三，**深度学习不是魔法**。从 ReLU 到 BatchNorm 到残差连接，每一个看似神奇的技术背后都有清晰的直觉和缜密的推导。吴恩达的教学风格就是把复杂的东西拆解到你能看懂的程度。
