# 吴恩达深度学习

> 课程来源：[B站 — 吴恩达深度学习](https://www.bilibili.com/video/BV12urfB1E7s)（免费、中英文字幕），2018 版。

## 课程概览

> "吴恩达深度学习"是一套专项课程（Specialization），分为五个部分，共 192 节，视频总长 28.5 小时。

| 课程 | 内容 | 节数 | 时长 |
|------|------|------|------|
| 第一部分 | 神经网络和深度学习：基础概念、逻辑回归、浅层/深层神经网络 | 46 | 6h52m |
| 第二部分 | 优化深度神经网络：超参数调优、正则化、优化算法 | 35 | 4h48m |
| 第三部分 | 结构化机器学习项目：ML策略、误差分析、迁移学习 | 24 | 3h52m |
| 第四部分 | 卷积神经网络：CNN架构、目标检测、人脸识别、风格迁移 | 50 | 7h07m |
| 第五部分 | 序列模型：RNN/LSTM/GRU、词嵌入、注意力机制、Transformer | 37 | 5h57m |

## 学习建议

- 建议投入为视频时长的 3 倍（观看 + 消化 + 笔记 ≈ 85 小时）
- 每小节视频约 8~10 分钟，每看完一节就写一节笔记，不要堆到后面，否则容易忘掉前面的内容
- 与吴恩达机器学习有部分内容重叠（如神经网络基础），可视为复习
- 如果已有 ML 基础，第四门课（CNN）和第五门课（序列模型）是深度学习独有内容，值得重点投入
