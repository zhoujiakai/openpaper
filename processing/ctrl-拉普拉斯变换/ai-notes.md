## 1 — 序言 — 用物理方法理解欧拉公式（27:49）
- [ ] 32.5%

**核心主线：为什么复数指数（e^(st), s ∈ ℂ）是微分方程的"原子"**

**1. 指数函数的动态视角**
- 定义 e^t 的核心是 **df/dt = f**，即导数等于自身
- 把导数读成动态关系：**速度向量 = 位置向量**（不仅看斜率图，更看作运动）
- e^0 = 1 作为初始条件，系统自行演化为指数增长
- s 的推广：d/dt e^(st) = s·e^(st)，速度是位置的 s 倍

**2. s 取不同值的几何意义**
- **s = 正实数**（如 2）：速度指向右且放大 → 更快增长
- **s = 负实数**（如 -0.5）：速度指向左且缩小 → 指数衰减
- **s = i**（纯虚数）：乘以 i = 旋转 90°→ **速度⊥位置 → 圆周运动**
  - 初始位置在 1，速度大小恒为 1 → 单位圆上走弧长
  - t = π 时走到 -1 → **e^(iπ) = -1**（欧拉公式）
- **s = -0.5 + i**（一般复数）：**旋转 + 衰减 → 向内螺旋**
  - 实部 → 增长/衰减（正/负）
  - 虚部 → 振荡频率

**3. 将复数代入 e^x 的真正含义**
- 不是"重复乘法"，而是代入泰勒级数 Σ x^n/n!
- 每个 i 带来 90° 旋转，n! 在分母最终压过分子
- 但更好的理解方式：**关注导数性质而非级数展开**

**4. s 平面（S-plane）**
- 平面上每个点 s 编码整个函数 e^(st)
- 虚轴：纯振荡；左半平面：衰减；右半平面：增长
- 这叫"s 平面"，工程师常用术语

**5. 受阻尼谐振子：为什么复数指数自然出现**
- m x'' + μ x' + k x = 0（牛顿第二定律：F = ma）
- 猜 x = e^(st)，代入得 **ms² + μs + k = 0**（多项式！）
- 微分方程 → **代数方程**，解二次方程即可
- 无阻尼时（μ=0）：s = ±i√(k/m)，纯振荡
  - √(k/m) 记作 ω（角频率）
  - 代入得 e^(iωt) 和 e^(-iωt)，都是复数
- **取实部** 或 **线性叠加** 得到实值解：
  - 1/2 e^(iωt) + 1/2 e^(-iωt) = cos(ωt)
- **线性性**：方程是线性的 → 解的缩放和叠加仍是解

**6. 为什么选择指数（可推广性）**
- 猜 cos ωt 也能解无阻尼情况，但遇到阻尼 μ≠0 就不够用了
- 猜 e^(st) 统一处理所有情况：
  - 小阻尼：s 有负实部 + 虚部 → 衰减振荡
  - 大阻尼（过阻尼）：s 只有负实部 → 纯衰减
- **推广到任意线性常系数齐次 DE**：
  - 代入 e^(st) 得到特征多项式 p(s)
  - 代数基本定理：n 次多项式有 n 个根（可为复数）
  - 通解 = Σ C_k·e^(s_k t)
- **指数函数是微积分的"原子"**——复杂函数可拆解为指数之和
- 受迫振荡子等非齐次方程的解也是特定指数的组合
- **预告**：拉普拉斯变换就是系统性地做这件事的工具

## 2 — 到底什么是拉普拉斯变换？（34:41）
- [ ] 73.0%

**核心主线：把函数拆成指数片的机器，用 s 平面上的极点暴露这些指数成分**

**1. 核心动机**
- 很多函数（尤其是物理中的）可以表示为指数片的组合
- 我们需要一台"机器"：输入函数 f(t)，输出它的指数成分
- 这台机器就是 **拉普拉斯变换**

**2. 定义**
```
F(s) = ∫₀^∞ f(t)·e^(-st) dt
```
- 输入：f(t)（时域函数）
- 输出：F(s)（s 域函数，s 是复数）
- 两步操作：①乘以 e^(-st) ②从 0 到 ∞ 积分
- e^(-st) 中 s 可自由移动，像"嗅探器"一样探测 f(t) 中是否藏有对应指数

**3. 核心洞察：极点揭示指数成分**
- 如果 f(t) = e^(at)，代入定义：
  - F(s) = ∫₀^∞ e^(at)·e^(-st) dt = ∫₀^∞ e^((a-s)t) dt
  - 当 s = a 时，指数 = 0，积分发散 → **极点**
- **核心结论**：L{e^(at)} = **1/(s-a)**，在 s=a 处有一个极点
- **拉普拉斯变换的极点位置 → 对应指数成分的 s 值**

**4. 线性性**
```
L{αf(t) + βg(t)} = αF(s) + βG(s)
```
- 变换是线性的 → 可以逐项处理后叠加

**5. 实例：余割 cos(ωt)**
- cos(ωt) = ½e^(iωt) + ½e^(-iωt)
- 由线性性：L{cos(ωt)} = ½·[1/(s-iω)] + ½·[1/(s+iω)]
- 通分合并后：**L{cos(ωt)} = s/(s²+ω²)**
- 极点位于 ±iω（纯虚数，纯振荡）
- 反过来：从变换式做部分分式分解，也能得到指数成分

**6. 积分的可视化理解**
- 复数指数 e^(-st) 的积分如何理解？
- 把 [0,∞) 切成单位长区间，在每个区间上取平均值（向量）
- 把所有平均值向量首尾相加 → 最终向量 = 积分值
- s 的虚部大 → 振荡多 → 向量互相抵消 → 积分值小
- s 的实部大正 → 衰减快 → 积分收敛快
- s 的实部为负 → 发散 → 积分无定义（需解析延拓）

**7. 解析延拓**
- 拉普拉斯变换的积分只在 Re(s) > 某个阈值时收敛
- 但 1/(s-a) 在复平面上几乎处处有定义
- **解析延拓**：在半平面收敛区域定义的函数，可唯一延拓到更大的区域
- 极点信息来自延拓后的全局版本

**8. 与傅里叶变换的关系**
- 当 s = iω（纯虚数），拉普拉斯变换 ≈ 傅里叶变换
- 区别：积分从 0 到 ∞（不是 -∞ 到 ∞），指数符号惯例不同
- **拉普拉斯变换 = 傅里叶变换的推广**：不只探测纯振荡（虚轴），还探测衰减/增长（全复平面）

## 3 — 为什么拉普拉斯变换如此有用？（23:05）
- [ ] 100.0%

**核心主线：拉普拉斯变换将微分方程转为代数方程 + 极点分析揭示系统本质**

**1. 关键性质：导数在 s 域变为乘法**
```
L{f'(t)} = s·F(s) - f(0)
```
- 时域求导 → s 域乘以 s，再减去初始条件
- 这正是 e^(st) 具有性质的推广：d/dt(e^(st)) = s·e^(st)
- 初始条件 f(0) 自然地嵌入公式中（不是 bug，是 feature！）
- 对二阶导数：L{f''(t)} = s²F(s) - s·f(0) - f'(0)

**2. 为什么成立（三种解释）**
- **方法一（示例法）**：对已知变换式 e^(at) 验证，代数变形后符合
- **方法二（分部积分法）**：从变换定义出发，∫ f'·e^(-st) dt = [f·e^(-st)] + s∫ f·e^(-st) dt
- **方法三（概念法）**：从逆变换角度理解——这是最深刻的方式

**3. 实战：受迫阻尼谐振子**
```
m x'' + μ x' + k x = F₀ cos(ωt)
```
- **策略**：对所有项做拉普拉斯变换 → 解代数方程 → 逆变换回时域
- 假设初始静止（x₀=0, v₀=0）简化：
  - L{x''} = s²X(s)
  - L{x'} = sX(s)
  - L{cos(ωt)} = s/(s²+ω²)
- 变换后：
  ```
  (ms² + μs + k)X(s) = F₀·s/(s²+ω²)
  ```
  → **X(s) = F₀·s / [(ms²+μs+k)(s²+ω²)]**

**4. 极点分析：一眼看出系统行为**
- X(s) 的极点来自分母 = 0 的根：
  ① **ms²+μs+k=0**：两根在左半平面（实部负），代表系统的**固有振荡 + 衰减**
  ② **s²+ω²=0**：两根在虚轴 ±iω，代表**外加驱动力**
- 物理含义：
  - 左半平面极点 → 解中随时间衰减的**暂态分量**
  - 虚轴极点 → 解中长期存在的**稳态分量**
- 正实部极点意味着不稳定（发散），负实部 = 稳定

**5. 逆变换与最终解**
- 做部分分式分解 → 将 X(s) 拆成四项：
  ```
  X(s) = A₁/(s-α₁) + A₂/(s-α₂) + B₁/(s-iω) + B₂/(s+iω)
  ```
- 利用 L{e^(at)} = 1/(s-a) 逆变换：
  ```
  x(t) = A₁e^(α₁t) + A₂e^(α₂t) + B₁e^(iωt) + B₂e^(-iωt)
  ```
- 前两项 = 暂态（衰减）；后两项合并 = 稳态 cos(ωt)
- 初始"抖动"阶段 = 两种频率竞争，暂态衰减后进入稳态

**6. 拉普拉斯变换的整体工作流程**
```
微分方程  ──[拉普拉斯变换]──→ 代数方程
    ↑                              ↓
（逆变换）                    （代数求解）
    ↑                              ↓
时域解 x(t)  ←──[部分分式分解]──  s 域解 X(s)
```
