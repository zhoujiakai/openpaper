## 控制理论基础

看完 3 个视频（1.5 小时），掌握拉普拉斯变换的核心思想，是控制理论的数学基础。

### 你将接触到的内容

**拉普拉斯变换的完整逻辑链**

1. **复数指数的几何直觉** — 为什么 $e^{st}$（s 为复数）会自动编码振荡与增长/衰减，s 平面上的每个点对应一种运动形态
2. **变换的定义与意义** — $\mathcal{L}\{f(t)\} = \int_0^\infty f(t)e^{-st}dt$ 通过积分探测函数的指数成分，极点（pole）的位置就是指数成分的 s 值
3. **微分方程代数化** — $\mathcal{L}\{f'(t)\} = sF(s) - f(0)$ 将时域求导变为 s 域乘法，微分方程变成代数方程
4. **极点分析** — 极点在左半平面 → 衰减稳定；在虚轴 → 纯振荡；在右半平面 → 发散不稳定
5. **受迫谐振子实战** — 从方程到变换、代数求解、部分分式分解、逆变换的完整流程
