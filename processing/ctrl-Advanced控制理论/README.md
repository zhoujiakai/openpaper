## 控制理论基础

看完前 3 个小节（约 0.5 小时），掌握控制理论的符号标记法和基本术语，为后续的 MPC、模糊控制等内容做铺垫。

### 你将接触到的内容

**学习路径**

1. **控制理论概貌** — DR_CAN 用维持咖啡温度的例子，说明控制系统就是减小实际值与目标值的误差
2. **状态空间（State Space）** — 用弹簧-质量-阻尼系统推导现代控制理论的核心方程：
   $$
   \dot z = Az + Bu, \quad y = Cz + Du
   $$
3. **传递函数与状态空间的关系** — $G(s) = C(sI - A)^{-1}B + D$，A 的特征值就是 G(s) 的极点
