# LSTM 用电负荷预测

> 课程来源：[B站 — [手把手教学]基于RNN、LSTM神经网络单特征用电负荷预测](https://www.bilibili.com/video/BV1HN4y1Y7Lt)，UP主：炮哥带你学。

## 时间序列预测

该课程从零开始讲解如何用 RNN 和 LSTM 神经网络进行单特征用电负荷预测，涵盖 RNN 基础理论、LSTM 模型原理和完整的 Python 实战流程。

### 你将接触到的内容

**学习路径**

按课程章节顺序观看：先建立 RNN/LSTM 理论认知，然后搭建开发环境，最后完成用电负荷预测的完整实战项目。建议每看完一小节就整理笔记，重点理解 LSTM 门控机制如何缓解 RNN 梯度消失问题。

1. **RNN 神经网络基础** — 基本结构、前向传播与反向传播
2. **LSTM 模型原理** — 遗忘门、输入门、输出门与细胞状态更新
3. **开发环境搭建** — PyCharm、Anaconda 安装与配置
4. **用电负荷预测实战** — 数据读取、预处理、模型搭建、训练与评估
