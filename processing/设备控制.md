# 设备控制 

设备控制项目分为 3 个部分：设备驱动、控制算法、故障预测与健康管理。

- 设备驱动：通过外设接口连接被控设备，使用设备的驱动函数。 C 语言代码。
    - 实现和封装设备的驱动代码，使用 STM32 的库函数读写引脚电平信号驱动设备。
    - 设备：OLED显示屏、按键、旋转编码器、直流电机、对射式红外传感器、有源蜂鸣器、光敏电阻传感器。
- 控制算法：收集设备的数据，编写算法控制设备。 C++、Python 代码。
    - PID：倒立摆控制。设备：直流电机（底部有编码器）、角度传感器。
        - PID 是无模型的控制算法。
    - MPC：机械臂/循迹小车。MPC 在嵌入式上跑有一定计算量，通常用 Python 做仿真验证，C++ 做实际部署。
        - MPC 是有模型的控制算法。
    - LSTM：吴恩达深度学习实验。
- 故障预测与健康管理：PHM
    
    - 故障预测：收集设备历史运行数据，构建预测模型，估计设备的剩余寿命（RUL）。C++、Python 代码。
    - 健康管理：实时监控设备运行状态，进行故障诊断、健康评估与维修决策。 Java、前端代码。
