## 2017 中国工业大数据创新竞赛（成果发布）

- **来源**：[工业互联网产业联盟](https://www.aii-alliance.org/upload/202002/0228_145948_173.pdf)
- **文件**：`2017中国工业大数据创新竞赛-赛题.pdf`（5.8 MB，21 页）
- **主讲人**：李铮（中国信息通信研究院）
- **发布时间**：2018-02-01

### 内容概要

该 PDF 是首届中国工业大数据创新竞赛的成果发布演讲 PPT，由工信部指导、2017 年 7–12 月举行，主题集中在 **PHM（故障预测与健康管理）** 领域。

### 竞赛概况

| 项目 | 内容 |
|------|------|
| 赛题 1 | **风机叶片结冰预测** — 基于运行数据预测叶片是否结冰 |
| 赛题 2 | **风机齿形带故障分类** |
| 数据 | 金风科技提供，13 台风机，6 个月，12 个变量 |
| 参赛 | 1535 人次，60% 高校 + 40% 企业 |
| 获奖 | 28 支优胜团队 |

### 白皮书收录的解法（赛题 1：风机叶片结冰预测）

| # | 方法 | 团队 |

| 1 | CNN-LSTM 深度学习网络 | 万腾科技 |
| 2 | 物理原理 + KNN 分类混合模型 | 济中节能 |

| 4 | 领域知识特征构建 + 结冰概率估计 | 浙江运达风电 |
| 5 | 数据驱动 + 非均衡数据学习 | 北京邮电大学 |
| 6 | 敏感特征 + 结冰预测算法 | 西安交通大学 |

### 核心结论

1. **数据预处理** 的地位不亚于建模本身
2. **融入领域知识** 的模型通常优于纯机器学习模型，尤其在数据质量不佳时
3. 复杂 ML 模型虽能与"机理+简单模型"比肩，但训练时间显著增加、可解释性变差
4. PHM 竞赛的 PHM Data Challenge 延续了国际上 GE、Kaggle 等平台的模式（构建设备健康状态评估、剩余寿命预测等问题的众包求解）
5. 工业大数据建模的独特挑战：工况不全面、状态不平衡、数据质量要求高、对领域知识要求高
