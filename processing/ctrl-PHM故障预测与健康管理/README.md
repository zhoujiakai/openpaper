## 故障预测与健康管理

PHM（Prognostics and Health Management）是智能运维的核心技术体系，涵盖数据预处理、特征提取、健康评估、故障诊断和剩余寿命预测等关键环节。该课程从工业大数据角度出发，系统讲解 PHM 的建模方法与应用实践。

### 你将接触到的内容

**学习路径**

视频前 3 个部分（约 52 分钟）建立 PHM 基础概念与数据预处理方法；第 4-6 部分（约 65 分钟）依次讲解三个核心建模任务——健康评估、故障诊断、剩余寿命预测；第 7 部分（约 14 分钟）收束到工业大数据建模应用场景。建议按顺序观看，每看完一个 p 就整理笔记。

1. **智能运维技术引述** — PHM 的背景、定义与基本概念
2. **数据预处理与特征提取** — 信号处理、降噪、时域/频域/时频域特征工程
3. **健康评估建模** — 健康指标（HI）构建、退化趋势建模
4. **故障诊断建模** — 分类/聚类方法在故障模式识别中的应用
5. **剩余寿命预测** — RUL 预测方法：物理模型、数据驱动、混合方法
