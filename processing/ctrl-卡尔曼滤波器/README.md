# 卡尔曼滤波器

> 课程来源：[Bilibili — DR_CAN 卡尔曼滤波器合集](https://www.bilibili.com/video/BV1ez4y1X7eR)，UP 主：DR_CAN。

## 控制理论 / 状态估计

卡尔曼滤波器是**最优状态估计的核心工具**，它从带噪声的观测中递归地给出系统状态的最优估计，是连接传感器数据与控制决策的桥梁。它与 MPC / LQR 共享同一套 Riccati 数学结构，两者互补构成完整的最优控制方案（LQG 控制）。

### 你将接触到的内容

从递归处理的思想出发，逐步搭建卡尔曼滤波器所需的数学基础，再一步步推导出卡尔曼增益和五个核心公式，最后扩展到非线性系统的处理。学完可以动手做一维/二维的状态估计实例。

1. **递归算法** — 通过递归处理思想直观理解卡尔曼滤波器的基本逻辑
2. **数学基础** — 数据融合、协方差矩阵、状态空间方程与观测器问题
3. **卡尔曼增益** — 超详细数学推导，理解增益如何最优权衡预测与测量
4. **误差协方差矩阵** — 卡尔曼滤波五个公式的完整推导
5. **扩展卡尔曼滤波器** — 从线性扩展到非线性系统的状态估计
