Kalman Filter 和 MPC 是**最优控制理论中天生一对的互补技术**。

### 直观来说

MPC 需要当前状态 \(x_k\) 作为预测的初始条件，但它假设状态是已知的。现实世界中，你测不到所有状态，而且测量有噪声。Kalman Filter 就是干这个的——从带噪声的测量值中给出当前状态的最优估计 \(\hat{x}_k\)。

所以典型的完整框图是：

```
传感器 → Kalman Filter (状态估计) → MPC (最优控制) → 执行器
                      ↑                          ↓
                  噪声测量                   控制输出
```

### 理论上的深层联系

|              | MPC / LQR（控制）            | Kalman Filter（估计）          |
| ------------ | ---------------------------- | ------------------------------ |
| 要解决的问题 | 给定初始状态，找最优控制序列 | 给定带噪声观测，找最优状态估计 |
| 核心数学工具 | Riccati 方程（前向）         | Riccati 方程（后向）           |
| 代价函数     | 最小化状态偏差+控制代价      | 最小化估计误差协方差           |
| 预测方向     | 从当前向未来推               | 从过去向当前滤波               |

两者共享几乎同一套数学结构：**都是通过求解 Riccati 方程来完成最优化的过程，只是方向相反**（控制是前向传播，滤波是后向传播）。

### DR_CAN 课程的隐含前提

在这套 MPC 课程中，DR_CAN 直接假设 \(x_k\) 在每一步已知，所以笔记里直接从 \(x(k|k) = x_k\) 开始。但实际部署时，这个 \(x_k\) 几乎总是来自 Kalman Filter 的输出。MPC + KF 合在一起，就是工程上实现的**线性二次型高斯（LQG）控制的离散时域版本**。

### 一句话总结

> **Kalman Filter 给 MPC 喂"看得准的当前状态"，MPC 拿它去"算得准的未来控制"。一个管估计，一个管决策，合起来才是完整的最优控制方案。**
