## 控制科学与工程

自动控制原理是自动化、电气工程及其自动化等专业的核心基础课，研究如何构建和分析控制系统，使被控对象按照期望的规律运行。卢京潮老师的课程以清晰的数学推导和工程直觉并重著称，是国内控制考研的经典教材之一。

### 你将接触到的内容

从数学模型建立到时域、频域、根轨迹分析，再到离散系统和非线性系统，覆盖自动控制理论的完整知识体系。

1. **控制系统的数学模型** — 传递函数、结构图、信号流图
2. **时域分析法** — 一/二阶系统动态性能、稳定性判据、稳态误差
3. **根轨迹法** — 基本法则、广义根轨迹、系统性能分析
4. **频域分析法** — 频率特性、Nyquist判据、稳定裕度、系统校正
5. **离散系统** — z变换、离散数学模型、稳定性与动态性能
6. **非线性系统** — 相平面法、描述函数法
