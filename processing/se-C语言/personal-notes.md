**默写**：

```c
int *a;  // a是一个指向一个4字节int类型空间的指针，在64位操作系统中，指针a一般占8字节。
int b = 2;
a = &b;  // 将 b 在内存中的值的地址赋值给指针a。a、b 指向同一块4字节的int类型内存区域。
*a = 3;  // 直接改变 4字节 int类型内存区域中存放的值为3，b指向的int值也被改了。
int c = 10;
*c = *b;  // c的值变成和b一样：3

const int *p;  // p指向的地址内的值不可变，p指向的地址可变
int const *p;  // p指向的地址不可变，p指向的地址内的值可变。

int func(){
  int a = 2;
  return &a;  // 返回之后a指向的地址空间已经被回收，返回的是垂悬指针。
}

int func(){
  int *a;
  *a = 2;
  return a;  // 正常
}
```

传入指针，修改对应的内存区域，外部指向同一空间的指针指向的地址的内容也会修改。

传入值，C 会在函数栈中创建局部变量，函数调用返回之后，该局部变量被回收，局部变量指向的地址和外部指针指向的地址是不同的，修改没有生效。

> **AI 检查修订**（20260602周二）：
>
> **代码错误（严重）**：
> 1. **第 67-69 行**：`int c = 10; *c = *b;` — `c` 是 int 不是 int*，不能解引用。这行代码类型错误，编译不通过。
> 2. **第 70-71 行 `const` 写法搞反了**：
>    ```c
>    const int *p;   // ✅ p 指向的内容不可变（锁值）
>    int *const p;   // ✅ p 自身不可变（锁指针）
>    // 不是 int const *p，虽然 const int *p 和 int const *p 等价
>    ```
>    口诀：**const 在 `*` 左边 → 锁值；const 在 `*` 右边 → 锁针。**
> 3. **第 73-76 行**：`int a = 2; return &a;` — 返回栈变量的地址，是悬垂指针。更准确的说法：函数返回后，a 所在的**栈帧被回收**（不是"地址空间被回收"），下次函数调用会覆盖这块内存。

> - `*` 的双重角色：
>   - 声明时：描述类型——`int *p` 读作"p 是指向 int 的指针"
>   - 使用时：解引用——`*p` 按门牌号去访问
> - `&` 的唯一角色：取变量地址
> - **指针声明读法规则（从内向外，先右后左）**：
>   - `int *p`：p → 左看是 `*`（指针）→ 指向 `int`
>   - `int *arr[10]`：arr → 右看是 `[10]`（数组）→ 左看是 `*`（指针）→ 指向 `int`
>   - `int (*pa)[10]`：pa → 左看是 `*`（指针）→ 右看是 `[10]`（数组）→ `int`
> - NULL 指针：`int *p = NULL;` 解引用 → 段错误
> - 三个常见错误：野指针（未初始化）、悬垂指针（free 后还用）、类型不匹配

> **AI 检查修订**（20260602周二，本章空白，以下为完整知识点）：
>
> **声明读法**：
> ```c
> int (*f)(int, int);   // f 是指向函数的指针，函数接收两个 int，返回 int
> int *f(int, int);     // f 是函数（非指针！），返回 int*
> ```
> 拆解规则（从内向外、先右后左）：
> - `int (*f)(int, int)`：f → 左看是 `*`（指针）→ 右看是 `()`（函数，参数两个 int）→ 返回 `int`
> - `int *f(int, int)`：f → 右看是 `()`（函数）→ 返回类型是 `int *`
>
> **qsort 完整示例**：
> ```c
> #include <stdlib.h>
>
> int compare(const void *a, const void *b) {
>     return (*(int *)a - *(int *)b);  // 从小到大
>     // 注：只适用于 int。double 需用 if-else 判断，不能直接相减
> }
>
> int arr[] = {5, 2, 8, 1, 3};
> qsort(arr, 5, sizeof(int), compare);
> //  qsort(数组, 元素个数, 每个大小, 比较函数)
> ```
>
> **三种实际用途**：
> 1. **回调函数** — qsort 的比较函数是最典型例子
> 2. **状态机** — 函数指针数组 `void (*handlers[])(void)` 按状态跳转
> 3. **中断向量表** — 每个中断号对应一个处理函数指针，硬件中断来时自动跳转

>
> **声明 vs 定义**：
> ```c
> // 声明（可多次）：告诉编译器"这东西存在"
> extern int global_var;
> void some_func(int x);
>
> // 定义（只能一次）：实际分配内存 / 生成代码
> int global_var = 42;
> void some_func(int x) { printf("%d\n", x); }
> ```
> 违反"定义只能一次" → 链接错误 "multiple definition"。
>
> **多文件编译流程**：
> ```bash
> gcc -c main.c -o main.o    # 只编译+汇编，不链接
> gcc -c helper.c -o helper.o
> gcc main.o helper.o -o program  # 链接所有 .o
> ```
> 为什么要分开？改一个文件只重编译那个文件，不用全量重新编译。
>
> **make 原理**：靠时间戳判断——目标文件比依赖旧，就重新生成。
> ```makefile
> program: main.o helper.o
> 	gcc main.o helper.o -o program
> main.o: main.c helper.h
> 	gcc -c main.c -o main.o
> clean:
> 	rm -f *.o program
> ```
> CMake 是 make 的上层工具，生成 Makefile。
>
> **静态库 vs 动态库**：
> - **静态库** `.a`：链接时复制进可执行文件。文件大，但不依赖外部环境。
> - **动态库** `.so`：运行时加载。文件小，升级不重编译，但部署要带库文件。
