# C 语言 — Python 视角的系统复习

> 学习方式：知识精通三阶段工作流（AI 笔记 → 苏格拉底问答 → 模拟题 → A4 默写 → 掌握度测试），为嵌入式开发做准备。

## 编程语言 / 计算机基础

C 语言是嵌入式开发、操作系统、高性能计算的事实基础。Python 的运行时（CPython）本身就用 C 编写。掌握 C 不是学会另一门语法——而是理解 Python 替你管理的内存、类型、编译和运行时到底发生了什么，以及为什么嵌入式世界里只能靠 C。

### 你将接触到的内容

从 Python 熟练者的视角切入，聚焦 C 与 Python 的根本差异，覆盖从编译到链接的全流程知识。

1. **编译流程（预处理→编译→汇编→链接）** — 理解 .c 文件如何变成可执行文件，与 Python 解释执行的本质区别
2. **指针与动态内存** — `*`、`&` 的双重角色、值传递、堆与栈的分工，C 的分水岭
3. **数组与字符串** — 退化规则、sizeof 陷阱、`\0` 结尾的底层逻辑与缓冲区溢出
4. **结构体、函数指针与位运算** — 内存对齐、回调机制、嵌入式寄存器操作的基本功
5. **宏、编译链接与常见陷阱** — 文本替换的括号铁律、多文件编译、未定义行为速查
