### Q5 [简答题] 请解释虚函数表（vtable）的工作机制。

- **参考答案要点**：
  1. 每个含有虚函数的类，编译器生成一个虚函数表（函数指针数组）
  2. 每个对象中含一个隐藏指针 vptr，指向该类的 vtable
  3. 调用虚函数时：通过 vptr 找到 vtable，再通过偏移找到对应的函数地址
  4. 开销：对象多 4/8 字节（vptr），调用多一次间接寻址
- **得分要点**：
  1. 提到 vtable 是函数指针数组
  2. 提到 vptr 指向 vtable
  3. 提到运行时根据实际类型查找
  4. 加分项：提到开销情况
- **知识点**：多态、虚函数

### Q6 [简答题] 什么是 RAII？请举一个嵌入式场景中的例子说明。

- **参考答案要点**：
  1. RAII 的核心思想：构造时获取资源，析构时释放资源
  2. 利用栈对象的确定性生命周期来管理资源，确保资源安全释放
  3. 例子：SpiTransaction 类——构造时获取 SPI 总线并选中设备，析构时释放总线
  4. 优点：即使函数提前 return，析构函数也一定会执行
- **得分要点**：
  1. 正确解释"构造获取，析构释放"
  2. 举出具体的嵌入式例子
  3. 提到"出作用域自动执行"
- **知识点**：RAII

### Q7 [简答题] 请说明 C++ 模板和 C 宏在处理"通用代码"时的核心区别。

- **参考答案要点**：
  1. 模板有类型检查，宏是文本替换（无类型检查）
  2. 模板在编译期展开，宏在预处理期展开
  3. 模板没有宏常见的副作用问题（如 x++ 被多次展开）
  4. 模板支持特化、递归等高级用法，宏不支持
  5. 运行时效率完全相同（都是生成专用代码）
- **得分要点**：
  1. 提到类型检查
  2. 提到编译期 vs 预处理期
  3. 提到宏的副作用问题
- **知识点**：模板 vs 宏

### Q8 [简答题] 为什么嵌入式项目中通常通过基类指针 `delete` 派生类对象时，基类必须声明虚析构函数？

- **参考答案**：
  1. 如果基类析构不是 virtual，`delete base_ptr` 只会调用 Base::~Base()
  2. 派生类的资源无法被释放，导致资源泄漏
  3. 规则：只要类里有虚函数，析构函数必须声明为 virtual
  4. 可以用 `virtual ~Base() = default;` 让编译器生成默认实现
- **得分要点**：
  1. 提到只调基类析构、不调派生类析构
  2. 提到资源泄漏
  3. 提到 =default
- **知识点**：虚析构函数

### Q11 [应用题] 你需要在嵌入式项目中管理一个 I2C 温度传感器（地址 0x48），读取温度数据并通过串口输出。请用 C++ class 封装这个传感器，要求：
  1. 构造函数完成 I2C 初始化
  2. 提供 readCelsius() 方法返回温度
  3. 禁止拷贝
  4. 使用 const 成员函数标记读操作

- **参考答案**：
  ```cpp
  class TempSensor {
      uint8_t addr;
  public:
      explicit TempSensor(uint8_t a) : addr(a) {
          i2c_init();
      }
      float readCelsius() const {
          uint8_t raw[2];
          i2c_read(addr, 0x00, raw, 2);
          int16_t val = (raw[0] << 8) | raw[1];
          return val * 0.0625f;
      }
      TempSensor(const TempSensor&) = delete;
      TempSensor& operator=(const TempSensor&) = delete;
  };
  ```
- **得分要点**：
  1. 正确使用构造函数初始化
  2. 使用 const 标记 read 函数
  3. 使用 =delete 禁止拷贝
  4. 加分项：explicit 防止隐式转换
- **知识点**：class 封装、const 成员函数、拷贝控制

### Q12 [应用题] 设计一个模板类 `SlewRateLimiter`（斜坡限制器），用来限制控制量的变化速率。要求支持任意数值类型（float/int），构造时设置最大变化量 delta，提供 update(target) 方法返回限制后的值并更新内部状态。

- **参考答案**：
  ```cpp
  template<typename T>
  class SlewRateLimiter {
      T current;
      T max_delta;
  public:
      explicit SlewRateLimiter(T delta, T init = T())
          : max_delta(delta), current(init) {}
      T update(T target) {
          T diff = target - current;
          if(diff > max_delta)      current += max_delta;
          else if(diff < -max_delta) current -= max_delta;
          else                       current = target;
          return current;
      }
      T getValue() const { return current; }
  };
  ```
- **得分要点**：
  1. 使用 template<typename T>
  2. 正确实现斜坡限制逻辑
  3. 内部状态保持
  4. 加分项：默认初始值 init = T()
- **知识点**：模板
