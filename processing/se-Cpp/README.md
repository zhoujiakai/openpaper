# C++ 嵌入式自动控制实战

> 为嵌入式 C++ 开发建立系统的语言基础。

## 编程语言 / 嵌入式开发

C++ 是嵌入式自动控制领域不可或缺的语言。从 C 嵌入式的经验出发，C++ 提供的模板、RAII、多态等特性让你在保持零开销抽象的同时，将代码的可维护性和安全性提升一个台阶。掌握 C++ 不是学会"更好的 C"——而是理解编译器替你自动生成了什么，以及如何在资源受限的环境下安全地使用这些抽象。

### 你将接触到的内容

从 C 到 C++ 的平滑过渡，聚焦嵌入式自动控制场景的核心 C++ 特性，覆盖从基础语法到实战框架的全链路知识。

1. **引用、函数重载、命名空间** — C 到 C++ 的语言升级包，从指针到引用的思维转换
2. **类、封装与 RAII** — 硬件外设的 C++ 封装模式，构造/析构掌控资源生命周期
3. **继承与多态** — vtable 机制、虚析构与设备抽象框架的设计
4. **模板与编译期编程** — 零开销的控制算法泛型化（PID、滤波器、斜坡限制器）
5. **Modern C++ 实用特性与嵌入式策略** — constexpr、enum class、std::array 与 STL 容器的嵌入式取舍

### 学习规划

| 项目 | 内容 |
|------|------|
| 学习范围 | 全部 8 个核心概念（引用、class、构造析构、继承多态、操作符重载、模板、RAII、STL 策略）+ 6 个关键代码模式 + 5 个现代 C++ 实用特性 |
| 目标 | 掌握 C++ 核心特性（模板、RAII、多态），能独立编写嵌入式自动控制 C++ 代码（传感器封装、控制算法泛型化、设备框架分层） |
