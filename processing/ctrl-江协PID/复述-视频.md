## 2 — [1-1] PID基本原理（48:49）
- [x] 14.8%，20260518周一

江协拿出小车定向控制的引例，到电机定速/定位控制，再到倒立摆实验。解释PID算法在这些过程中需要执行的操作。

江协写下PID公式，定义 P 、I 、D 三部分。绘制三部分各自的图像特征。

- P（快）：起步太缓，就需要加大P项，调控更快速；
- I（准）：存在稳态误差/摩擦力，就需要加上I项，消除稳态；
- D（稳）：一头扎向目标/超调/震荡，就需要加上D项的控制，产生阻尼的效果。

江协给被控对象输出0，判断自发偏移的方向，即为稳态误差的方向。

江协讲解了三项选择的方法：

- 定速控制：一般只需要PI控制即可，不需要D项，因为不会来回震荡。
- 定位控制：需要D项为系统增加阻尼，避免来回震荡。


## 3 — [1-2] 离散PID&程序实现思路（40:28）
- [x] 22.9%，20260528周四

江协拿出连续型PID的公式：
$$
u(t) = K_{p} e(t) + K_{i} \int_{0}^{t} e(t) \, dt + K_{d} \frac{de(t)}{dt}
$$
江协推导离散型PID的公式：
$$
u(k) = K_{p} e(k) + K_{i} \sum_{j=0}^{k} e(j) \cdot T + K_{d} \frac{e(k) - e(k-1)}{T}
$$
江协位置式PID与增量式PID公式：
$$
\begin{aligned}
\text{位置式：} \quad u(k) &= K_{p} e(k) + K_{i} \sum_{j=0}^{k} e(j) + K_{d}\bigl[e(k) - e(k-1)\bigr] \\[6pt]
\text{增量式：} \quad \Delta u(k) &= K_{p}\bigl[e(k) - e(k-1)\bigr] + K_{i} e(k) + K_{d}\bigl[e(k) - 2e(k-1) + e(k-2)\bigr]
\end{aligned}
$$

江协拿出3个版本的代码。代码确定一个调控周期，每隔时间T，程序执行一次PID调控。

调控周期根据被控对象变化的快慢，可能取1毫秒到20毫秒。江协分享了经验：

- 倒立摆、平衡车、四轴飞行器等设备需要快速反应，设置调控周期 20 毫秒/ 10 毫秒/ 5 毫秒/ 1毫秒；
- 调控周期受硬件传感器等设备分辨率的限制：
    - 姿态传感器 5ms 才能更新一次数据，太快没意义。
    - 编码器有分辨率，电机调控过快，编码器测不准。
    - 有的场景下调控周期可能几百毫秒、几秒、几十秒都有可能。

三版程序的思路不同：

- 主程序中直接调控电机，调控完一次直接delay延时。
- 定时器定时中断，在中断程序中进行调控。江协说一般都使用这种。注意涉及硬件操作的函数不能在中断和主程序中都调用，有资源访问冲突问题。
- 在中断程序中修改全局标志位，主程序的循环中检查到标志位被设置为 1，就重新置 0 ，并进行调控。问题是主程序可能被其他代码阻塞，导致调控周期不准。

**位置式 PID 代码模版**

```c
#include "stm32f10x.h"                  // Device header
#include "Delay.h"
#include "Timer.h"

/*定义变量*/
float Target, Actual, Out;              //目标值，实际值，输出值
float Kp = 值, Ki = 值, Kd = 值;        //比例项，积分项，微分项的权重
float Error0, Error1, ErrorInt;         //本次误差，上次误差，误差积分

int main(void)
{
    Timer_Init();

    while (1)
    {
        /*用户在此处根据需求写入PID控制器的目标值*/
        Target = 用户指定的一个值;
    }
}

void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) == SET)
    {
        /*每隔时间T，程序执行到这里一次*/
        /**********执行PID调控**********/
        /*获取实际值*/
        Actual = 读取传感器();

        /*获取本次误差和上次误差*/
        Error1 = Error0;
        Error0 = Target - Actual;

        /*误差积分（累加）*/
        ErrorInt += Error0;

        /*PID计算*/
        Out = Kp * Error0 + Ki * ErrorInt + Kd * (Error0 - Error1);

        /*输出限幅*/
        if (Out > 上限) {Out = 上限;}
        if (Out < 下限) {Out = 下限;}

        /*执行控制*/
        输出至被控对象(Out);
        /******************************/

        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
    }
}
```

**增量式 PID 代码模版**

```c
#include "stm32f10x.h"                  // Device header
#include "Delay.h"
#include "Timer.h"

/*定义变量*/
float Target, Actual, Out;              //目标值，实际值，输出值
float Kp = 值, Ki = 值, Kd = 值;        //比例项，积分项，微分项的权重
float Error0, Error1, Error2;            //本次误差，上次误差，上上次误差

int main(void)
{
    Timer_Init();

    while (1)
    {
        /*用户在此处根据需求写入PID控制器的目标值*/
        Target = 用户指定的一个值;
    }
}

void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) == SET)
    {
        /*每隔时间T，程序执行到这里一次*/
        /**********执行PID调控**********/
        /*获取实际值*/
        Actual = 读取传感器();

        /*获取本次误差、上次误差和上上次误差*/
        Error2 = Error1;
        Error1 = Error0;
        Error0 = Target - Actual;

        /*PID计算*/
        Out += Kp * (Error0 - Error1) + Ki * Error0
             + Kd * (Error0 - 2 * Error1 + Error2);

        /*输出限幅*/
        if (Out > 上限) {Out = 上限;}
        if (Out < 下限) {Out = 下限;}

        /*执行控制*/
        输出至被控对象(Out);
        /******************************/

        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
    }
}
```

这 4 个实验都是直接套用 PID 算法代码模版。

- **位置式 PID 定速控制**

- **增量式 PID 定速控制**

- **位置式 PID 定位控制**

- **增量式 PID 定位控制**

操作过程都是一样的：

设备的物理量：

-  PWM 驱动力：-100 ～ 100
- 编码器角度：408 / 圈
- 调控周期：40ms（10 ～ 100 ms）。编码器读取周期和 PID 调控周期保持一致。
- 极性：电机的极性和编码器的极性要明确。
- 定速控制的 Target 设置为 -150 ～ 150，因为实际输出量范围大致为 -180 ～180。

 PID 参数整定：反应较快，抖动更明显。反应较慢，变化更平滑。

- 确定数量级：数量级 = 输入 / 输出。可以通过这个公式大致确定参数的数量级。
- 通过手动调节确定具体参数值。

两种误差：

- 稳态误差：由于存在摩擦力产生的自发偏移，一般误差值较大，误差的方向和自发偏移的方向一致。
- 调控误差：由于调控力度过小产生的误差，一般误差较小，方向不确定。

调控过程中的一些现象：

- 位置式 PID ：由手动切换到自动会有抖动。
- 增量式 PID 定位控制：纯 P 项调节可能存在无法到达目标值的现象。

江协使用连接CH340，串口发送波形。

江协先使用纯比例控制。江协观察到超调现象。

补充：

-  浮点数的打印： `%+04.0f` 。
    - `%f`：表示显示浮点数
    - `+`：表示显示正负号
    - `4`：表示小数点前显示 4 位
    - `.0`：表示小数点后显示 0 位

-  串口的 RX、TX 引脚要反接。

- 增量式 PID 停止自动控制时， Out 会保持原来的值，适合自动控制和手动控制切换的场景。
