## 硬件

STM32、编码器、电机、按键、旋钮、OLED 。

### 电机

PWM = **脉冲宽度调制（Pulse Width Modulation）** 

给电机供电时，不是单纯改变电压大小调速，而是**快速开关电源**：

- 开关频率很高（几千～几万次 / 秒），人眼 / 电机看不出断断续续；
- 调节**高电平通电的时间占比**，就能等效改变平均电压，控制电机转速、扭矩。

举个生活化例子，把水龙头反复快速开关：

- 开久一点、关很短 → 平均水流大（电机转得快）
- 开很短、关久一点 → 平均水流小（电机转得慢）

这里打开的时间比例就是 PWM 占空比。

### 编码器

霍尔式角度传感器，安装在电机轴顶端。

### 按键

机械轻触按键

- 内部有金属弹片，没按下时弹片分开，两个引脚**断开**，电路不通；

- 按下后弹片形变，金属触点贴合，引脚**导通**；

- 松开弹片回弹，再次断开。



## 代码

驱动：STM32定时器、STM32外部中断、编码器、电机、按键、旋钮。

实验：电机定速控制、电机定位控制。

核心：PID 算法模板。



## 算法

名称：PID。

输入：电机转速、电机转向。

参数：P、I、D。

输出：PWM 占空比。

效果：电机以目标转速旋转/电机停留在目标角度。
