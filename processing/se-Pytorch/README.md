
# PyTorch — 深度学习框架

> 学习方式：知识精通三阶段工作流（AI 笔记 → 苏格拉底问答 → 模拟题 → A4 默写 → 掌握度测试），系统掌握深度学习工程实践。

## 编程语言 / 深度学习框架

PyTorch 是当前深度学习研究与工业应用的主流框架。它的核心设计哲学是"define-by-run"——你写的就是运行时的真实代码，不是建好再执行的静态图。这让调试直观到可以在 forward 里打 print，也让自定义网络层和实验性架构的搭建变得流畅。掌握 PyTorch 不只是学会一套 API——而是理解自动微分引擎如何追踪计算、GPU 并行计算如何编排，以及从张量运算到完整训练管线的全链路能力。

### 你将接触到的内容

从张量基础到模型工程的最佳实践，覆盖深度学习开发所需的完整工具链。

1. **Tensor 体系与 Autograd** — 张量的创建/运算/设备迁移，自动微分引擎的工作原理与计算图管理
2. **nn.Module 与网络搭建** — 从全连接到 Transformer，参数注册机制、子模块递归管理与自定义层
3. **训练循环与最佳实践** — DataLoader 管道、损失函数选择、优化器配置、验证/测试的正确打开方式
4. **GPU 加速与分布式训练** — CUDA/MPS 设备管理、AMP 混合精度、DDP/FSDP 分布式策略
5. **模型部署与工程化** — 状态字典保存/加载、ONNX 导出、torch.compile 编译优化
