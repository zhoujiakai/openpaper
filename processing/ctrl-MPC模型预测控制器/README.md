# MPC模型预测控制器

> 课程来源：[B站 — MPC模型预测控制器](https://www.bilibili.com/video/BV1cL411n7KV)，UP主：DR_CAN。

## 控制理论

MPC（模型预测控制）是现代控制理论的重要分支，结合了最优化思想和反馈控制，能显式处理多变量约束问题，是工业过程控制领域应用最广泛的高级控制策略之一。

### 你将接触到的内容

从经典控制的局限性出发，系统性地理解 MPC 的"模型预测 + 滚动优化 + 反馈校正"框架，最终能读懂并运行一个完整的 MPC 代码示例。

1. **最优化控制与MPC基本概念** — 对比传统控制与最优化控制，理解 MPC 三步走思想和滚动优化机制
2. **最优化数学建模推导** — 将 MPC 问题转化为二次规划（QP）形式，消去状态变量，得到仅含控制量的标准 QP 形式
3. **一个详细的建模例子** — 代入具体数值，手工计算预测矩阵 M、C 和代价函数中的 H 矩阵
4. **完整案例讲解-Octave代码** — 在 Octave 中实现 MPC 的 QP 求解，展示不同权重参数对系统调节效果的影响
