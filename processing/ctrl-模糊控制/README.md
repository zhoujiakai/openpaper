# 模糊控制

> 课程来源：[B站 — 季洁《模糊控制》](https://www.bilibili.com/video/BV1LF411B7h6)，UP主：季洁。

## 控制理论基础

看完这个 20 分钟的视频，理解模糊控制的核心思想：把人的经验（比如"水很脏就多洗一会儿"）转化成规则，让机器自己决策，而不需要给机器建一个精确的数学方程。

传统控制依赖数学模型（微分方程、传递函数），但很多场景模型建不出来或太复杂。模糊控制绕开了这一步——用模糊集和 IF-THEN 规则模拟人的判断逻辑。1990 年松下把模糊控制装进洗衣机，成了经典案例。

### 你将接触到的内容

**模糊控制系统的完整设计流程**

1. **模糊控制系统的结构** — 用模糊控制器 FC 替代传统控制器，理解两者在结构上的差异
2. **模糊化** — 将精确的输入量（如误差）映射到隶属函数定义的模糊子集上，使用三角隶属函数等工具进行模糊语言表达
3. **模糊规则** — 凭专家经验总结 IF-THEN 规则（如洗衣机的 9 条规则），构成推理的知识库
4. **模糊逻辑推理** — 通过合成算子对规则库进行近似推理（Mamdani 算法），$U = R \circ E$
5. **清晰化** — 将推理得到的模糊输出集映射回精确值，驱动执行机构
