## 设备控制方向

看完前 **14 个视频**（8 小时，每小节 40 min），即可掌握设备控制方向上嵌入式开发最基本的上下文。

### 你将接触到的内容

**嵌入式项目的流程**

以设备驱动开发为主线，拿到一个具体的外设（如对射式红外传感器、旋转编码器、LED、蜂鸣器）到完成具体控制业务，流程如下：

1. **了解外设硬件原理** — 看手册或原理图，搞清楚电气特性、通信方式、工作时序
2. **接线与硬件连接** — 确定引脚连接（GPIO、外部中断引脚、定时器通道等），完成电路搭建
3. **编写设备驱动** — 基于库函数或寄存器操作，将底层硬件操作封装成初始化、读/写、配置等接口
4. **在主程序中集成** — 初始化外设驱动，在主循环或中断中调用驱动接口，组合多个设备完成具体的控制业务

从搭建开发环境（Keil 5 MDK）、新建工程、配置芯片，到编写代码、下载调试，完整走一遍嵌入式项目从零开始的流程。

**嵌入式硬件的概念**
- 单片机内部结构：内核、存储器、外设总线
- 开发板的结构：最小系统板、晶振、复位电路、电源、调试接口
- 元件的连接方式：GPIO 引脚与 LED、按键、蜂鸣器、传感器等外设的接线

**嵌入式软件的概念**
- 代码结构：工程目录组织、主函数与模块文件分离
- 寄存器操作与库函数调用：从直接操作寄存器到位操作和库函数封装
- 外部中断和定时器：EXTI 外部中断响应外部事件、TIM 定时中断实现精确时序
- 元件驱动开发和封装：将底层硬件操作封装为可复用的驱动接口
- 业务主程序实现：组合多个外设驱动完成一个完整的控制逻辑
