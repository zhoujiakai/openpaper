面包板的结构，拆掉底部的胶之后底部的金属爪结构：

- 两侧分别有 2 根横向的金属爪，各自的上金属爪接正极，下金属爪接负极。

按键需要选择 GPIO_Mode_IPU （上拉输入，读取按键的状态），还要添加延时消抖，上拉输入模式的一般代码：

```c
#include "stm32f10x.h"                  // Device header
#include "Delay.h"

void Key_Init(void)
{
	/*开启时钟*/
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);		//开启GPIOB的时钟
	
	/*GPIO初始化*/
	GPIO_InitTypeDef GPIO_InitStructure;
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_1 | GPIO_Pin_11;
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	GPIO_Init(GPIOB, &GPIO_InitStructure);						//将PB1和PB11引脚初始化为上拉输入
}

uint8_t Key_GetNum(void)
{
	uint8_t KeyNum = 0;		//定义变量，默认键码值为0
	
	if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0)			//读PB1输入寄存器的状态，如果为0，则代表按键1按下
	{
		Delay_ms(20);											//延时消抖
		while (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0);	//等待按键松手
		Delay_ms(20);											//延时消抖
		KeyNum = 1;												//置键码为1
	}
	
	if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_11) == 0)			//读PB11输入寄存器的状态，如果为0，则代表按键2按下
	{
		Delay_ms(20);											//延时消抖
		while (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_11) == 0);	//等待按键松手
		Delay_ms(20);											//延时消抖
		KeyNum = 2;												//置键码为2
	}
	
	return KeyNum;			//返回键码值，如果没有按键按下，所有if都不成立，则键码为默认值0
}

```

**中断系统**

江协展示一个中断系统结构图：GPIO -> AFIO -> EXTI -> NVIC -> CPU 。

- GPIO：接收传感器输出口的电平变化。
- AFIO：根据 GPIO 的输入端口选择中断引脚。AFIO 把相同的 Pin 分配到同一个 GPIO_Pin 中断通道上，所以相同的 Pin 不能同时触发中断。硬件上主要是由一些数据选择器组成，在单片机上的功能就是复用功能引脚重映射和中断引脚选择。
- EXTI：Extern Interrupt，外部中断。一共拥有 16 根中断线，EXTI 把这些中断线分配给 GPIO 中断和其他外部中断。可以设置为检测到下降沿就产生中断。
- NVIC：中断控制器，是一个内核外设。按照中断优先级给所有中断排队进 CPU。
- CPU：直接处理 NVIC 递过来的中断。

江协展示一个表格，说明中断优先级的概念。中断优先级是使用分组的概念，从抢占优先级和响应优先级两个维度进行排序，如果两个中断通道抢占优先级和响应优先级相同，就按照中断号进行排序，保证了每个中断通道都有严格的先后顺序。江协绘制一个图，说明中断的抢占优先级通过中断嵌套来实现。

## 14 — [6-2] 定时器定时中断&定时器外部时钟（38:31）

江协实现定时器中断和定时器外部时钟 2 个实验代码。

江协绘制一个计时器模块的逻辑结构图。

需要的模块：

- NVIC、GPIO 。
- STM2。
- 时基单元：预分频器、自动重装器、计数器。

**定时器**：

- 定时器的种类：定时器分 3 类，包括基本/通用/高级定时器。STM32F103C8T6 有下面 4 个定时器：
    - 高级定时器：TIM1。
    - 通用定时器：TIM2、TIM3、TIM4 。拥有定时中断和内外时钟源选择等功能。

- 定时时间的计算：预分频值、自动重装值。
    - 溢出时间就是触发一次更新事件的时间间隔秒，内部时钟源的频率是 72MHz 。
    - 溢出时间 = (PSC + 1) × (ARR + 1) / 定时器时钟频率
    - 设置溢出时间为 1s：时钟频率 = 72MHz，预分频值 PSC = 7200 - 1，自动重装值 ARR = 10000 - 1 。
- 避免一上电就触发更新事件：在时基单元初始化的时候，会自动设置更新标识位，所以一上电就会触发一次更新事件。在时基单元初始化的后面，NVIC 开启中断的前面，清除更新标志位。
- 滤波器：以采样频率 f 采样 N 个点，如果 N 个点都一样，才会有效输出。 

**定时器使用 4 个步骤**：

- 开启时钟：开启 TIM2 的外设时钟。
- 时钟源：
    - 内部时钟源：配置 TIM2 的时钟源为内部时钟源 `TIM_InternalClockConfig(TIM2)` ，
    - 外部时钟源：配置为外部 GPIOA0/ETR 时钟源 `TIM_ETRClockMode2Config(TIM2, 分频器不需要, 采样极性-上升沿有效NonInverted, 滤波器不需要)` 。

- 时基单元：初始化。
- TIM2 更新中断：使能。
- NVIC ：配置优先级分组、中断线。 
- 实现定时器函数：`TIM2_IRQHandler`

**定时器定时中断**：江协接上 OLED 显示屏用来显示计时数字。只需要配置定时器。

**定时器外部时钟**：江协把对射式红外传感器的数据引脚 DO 接到 PA0 。需要配置 GPIO 和定时器。
