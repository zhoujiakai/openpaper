**创建项目**

江协介绍官方代码文件的结构：`/STM32入门教程资料/固件库/STM32F10x_StdPeriph_Lib_V3.5.0` 。创建一个项目，添加一些必要的工程文件。

- STM32F103C8T6 的启动文件：每个型号的芯片都有一个对应的 .s 文件，这是芯片的启动文件。位置：

    ```
    /固件库/STM32F10x_StdPeriph_Lib_V3.5.0/Libraries/CMSIS/CM3/DeviceSupport/ST/STM32F10x/startup/arm/
    
    startup_stm32f10x_md.s
    ```

- 外设寄存器描述文件：描述 STM32 有哪些寄存器和它对应的地址。

    ```
    /固件库/STM32F10x_StdPeriph_Lib_V3.5.0/Libraries/CMSIS/CM3/DeviceSupport/ST/STM32F10x/
    
    stm32f10x.h
    ```

- 系统时钟配置文件。

    ```
    /固件库/STM32F10x_StdPeriph_Lib_V3.5.0/Libraries/CMSIS/CM3/DeviceSupport/ST/STM32F10x/
    
    文件夹下的 2 个文件：
    system_stm32f10x.c、system_stm32f10x.h
    ```

- 内核寄存器描述文件和配置函数。

    ```
    /固件库/STM32F10x_StdPeriph_Lib_V3.5.0/Libraries/CMSIS/CM3/CoreSupport/
    
    文件夹下的 2 个文件：
    core_cm3.c、core_cm3.h
    ```

（芯片核心的头文件、外设的头文件和配置函数，就是一些在 `/Libraries` 中的 .c、.h 文件。）

上面这些文件都放到 `/Start` 文件夹下。在工程选项里添加头文件路径：

```
工程选项（魔术棒） -> C/C++ -> Include （在这里添加头文件的文件夹路径）
工程选项（魔术般） -> Debug -> 下拉列表选择 ST-Link 调试器 -> Settings -> Flash Download -> Reset and Run（这样下载程序之后会立即复位并执行，不需要手动按复位按键才执行）
```

创建 `/User` 目录，存放程序的业务代码和 main 函数。

**基于寄存器的方式开发 STM32 。**

代码如下（末尾必须要有一个空行）：

```c
#include "stm32f10x.h"                  // Device header
int main(void){
	
	RCC->APB2ENR = 0x00000010;
	GPIOC->CRH = 0x00300000;
	GPIOC->ODR = 0x00000000;
	while(1){
	
	}
}

```

**基于库函数的方式开发 STM32。**

- 创建 `/Library` 文件夹，存放所有库文件

    ```
     库函数的源文件：
     /固件库/STM32F10x_StdPeriph_Lib_V3.5.0/Libraries/STM32F10x_StdPeriph_Driver/src
     文件夹下的所有文件。其中 misc.c 文件是内核的库函数，其他是外设库函数。
     
     库函数的头文件：
    /固件库/STM32F10x_StdPeriph_Lib_V3.5.0/Libraries/STM32F10x_StdPeriph_Driver/inc
    文件夹下的所有文件。
    ```


- 在 User 目录下添加 3 个文件：

  ```
  /固件库/STM32F10x_StdPeriph_Lib_V3.5.0/Project/STM32F10x_StdPeriph_Template/
  
  用来配置库函数头文件的包含关系、和一个用来参数检查的函数定义：stm32f10x_conf.h
  中断函数：stm32f10x_it.c、stm32f10x_it.h
  ```

  ```
  「工程选项（魔术棒）」-> C/C++ -> Define（这里填入宏定义：USE_STDPERIPH_DRIVER。这样按照stm32f10x.h的规则，stm32f10x_conf.h 才会被其包含）
  「工程选项（魔术棒）」-> C/C++ -> Include（添加 User、Library 两个头文件文件夹）
  ```
  
  代码如下：
  
  ```c
  #include "stm32f10x.h"                  // Device header
  int main(void){
  	
  	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);
  	GPIO_InitTypeDef GPIO_InitStructure;
  	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
  	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_13;
  	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
  	GPIO_Init(GPIOC, &GPIO_InitStructure);
  	GPIO_SetBits(GPIOC, GPIO_Pin_13);
  //	GPIO_ResetBits(GPIOC, GPIO_Pin_13);
  	while(1){
  	
  	}
  }
  
  ```

## 第3章：GPIO

## 5 — [3-1] GPIO输出（34:30）
- [x] 7.7%，20260616周二，90min

GPIO 的基本结构、内部电路结构。APB2 <-> GPIO [寄存器 <-> 驱动器]<-> 引脚 [PA0、PA1 ...]

- 输入驱动：用施密特触发器进行高低电平的整形。
- 输出驱动：不同的输出模式，推挽/开漏/开闭。
- 引脚：用保护二极管限定输入电压为 0～3.3V，超过这个范围的电压无法进入电路。

发光二极管的原理：正向通电点亮，反向通电不亮。外部长引脚是正极，外部短引脚是负极，内部较小的一半是正极，较大的一半是负极。

面包板的结构，拆掉底部的胶之后底部的金属爪结构：

- 两侧分别有 2 根横向的金属爪。
- 中间是很多根纵向的金属爪，并且中间都是断开的。

演示用面包板、电源、1k 电阻、发光二极管 连接电路。

江协演示按键控制 LED 和光敏电阻控制蜂鸣器。

江协展示传感器的图，演示传感器模块的原理，光敏电阻、热敏电阻、红外接收管等电阻的电路模块都是基本相似的：

- 滤波电容：保证电路稳定。
- 分压：定值电阻和传感器电阻分压，得到模拟电压的输出 AO。
- 电压比较器：对模拟电压进行二值化，得到数字电压的输出DO。
- 封装起来的传感器模块都是 4 个引脚：VCC、GND、DO、AO。

江协介绍了按键的原理，主要使用上拉电阻的方法。

江协补充 C 语言的知识：C 语言的数据类型、宏定义、typedef：结构体类型、枚举类型。

- 数据类型：stm32中的数据类型名称和 C 语言中的有所不同，比如 unsigned char 对应 uint8_t 等。
- 宏定义：变量值可以使用宏定义 `#define` 进行重命名，就是给一个具体的数值起别名。
- typedef：变量类型一般使用typedef，就是给一个类型起一个别名，原名和别名两者是等价的。
- 结构体类型：结构体就是使用了 typedef。
- 枚举类型：枚举也是使用了 typedef。
