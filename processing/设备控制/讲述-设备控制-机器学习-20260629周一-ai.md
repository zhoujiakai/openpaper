> 来源：`讲述-设备控制-机器学习-20260629周一-personal.md`
>
> 这份总结根据个人回忆内容扩展而成，目标是把课程内容串成一条完整主线：从机器学习的基本概念，到监督学习、无监督学习、推荐系统、强化学习，再到深度学习中的神经网络、优化方法、结构化项目、卷积网络和序列模型。放在“设备控制”的主题下看，这些内容共同回答一个问题：怎样让设备从数据中学习规律，并把学习到的规律用于识别、预测、决策和控制。

# 一、总体脉络

机器学习和深度学习的核心，是让系统不再只依赖人工写死的规则，而是从数据里学习一个可以泛化的模型。

在传统程序里，人先写规则，设备按照规则执行。比如温度超过某个阈值就打开风扇，距离小于某个阈值就刹车。这种方式清楚、可控，但遇到复杂环境会变得很难维护。

机器学习换了一种思路：给模型大量输入和结果，让模型自己学出输入到输出之间的关系。比如给它设备传感器数据和故障标签，它可以学会判断设备是否异常；给它图像和类别，它可以学会识别物体；给它状态、动作和奖励，它可以学会在环境中一步步做出更好的决策。

课程内容可以分成两大块：

1. 机器学习：重点是监督学习、无监督学习、推荐系统和强化学习。它更强调经典算法、特征、代价函数、模型评估和项目流程。
2. 深度学习：重点是神经网络及其训练方法。它更强调多层模型、向量化计算、优化算法、卷积网络、序列模型和实际项目落地。

如果把它们放在设备控制场景里，可以这样理解：

- 线性回归、逻辑回归：适合做基础预测和分类，比如预测设备负载、判断是否报警。
- 决策树、随机森林、XGBoost：适合处理结构化传感器数据，做故障诊断、状态分类和风险评分。
- 聚类和异常检测：适合在缺少标签时发现设备状态分组或异常运行模式。
- 推荐系统：虽然最典型场景是内容推荐，但其中的协同过滤和表示学习思想，也可以迁移到设备参数推荐、工况匹配和策略选择。
- 强化学习：最接近“控制”。它关心状态、动作、奖励和策略，适合处理机器人、移动设备、自动驾驶、无人机、能源调度等连续决策问题。
- CNN：适合处理图像和视觉任务，比如工业质检、目标检测、道路识别、人脸识别。
- RNN、LSTM、GRU、Transformer：适合处理时间序列和语言序列，比如语音识别、传感器时序分析、动作序列建模。

# 二、机器学习部分

机器学习部分包含三门课：监督学习，高级学习算法，以及无监督学习、推荐系统和强化学习。它们从最基础的预测模型开始，逐步走到完整项目、树模型、聚类、推荐和决策控制。

## 第一课：监督学习，线性回归与逻辑回归

这门课是机器学习的入口。它先建立几个基本概念：什么是机器学习，什么是监督学习，什么是无监督学习，模型为什么需要代价函数，梯度下降为什么能让模型变好。

监督学习的特点是训练数据里有明确答案。比如输入房屋面积，输出房价；输入邮件内容，输出是否垃圾邮件；输入设备传感器特征，输出是否故障。模型要做的事，是学习输入和输出之间的映射关系。

无监督学习则没有明确答案。它更像是让模型自己从数据中找结构，比如把设备运行状态自动分组，或者发现某些运行点和大多数样本不一样。

### Week 1：监督学习、线性回归、代价函数和梯度下降

第一周主要讲机器学习的基本概念，并用线性回归作为第一个例子。

线性回归解决的是连续数值预测问题。它假设输入特征和输出之间可以用一条直线或一个线性函数来近似。最简单的形式是：

```text
f(x) = wx + b
```

其中，`x` 是输入，`w` 是权重，`b` 是偏置，`f(x)` 是模型预测值。

在线性回归里，模型一开始并不知道合适的 `w` 和 `b`。它需要通过训练数据慢慢调整这些参数。为了知道模型现在好不好，需要引入代价函数。

代价函数衡量的是预测值和真实值之间的差距。线性回归常用平方误差。预测越准，代价越小；预测越偏，代价越大。训练模型的目标，就是找到一组参数，让代价函数尽可能小。

梯度下降是寻找最小代价的一种方法。直观地说，它像是在山坡上找最低点。当前参数对应山坡上的某个位置，梯度告诉我们往哪个方向代价上升最快，所以我们反方向走，就能让代价下降。

学习率决定每一步走多大。学习率太小，训练会很慢；学习率太大，可能越过最低点，甚至发散。课程通过可视化让人看到代价函数、参数变化和梯度下降路径之间的关系。

这一周的关键，不是记住公式，而是理解机器学习训练的基本闭环：

```text
做预测 -> 计算误差 -> 根据误差调整参数 -> 再做预测
```

这个闭环后来会不断重复出现，只是模型从线性回归变成逻辑回归、神经网络、决策树或强化学习策略。

### Week 2：多特征线性回归、向量化、特征缩放和多项式回归

第二周把线性回归从单个特征扩展到多个特征。

现实问题很少只由一个变量决定。比如预测设备能耗，可能要看温度、负载、转速、运行时间、环境湿度等多个特征。多元线性回归就是把多个特征组合起来：

```text
f(x) = w1x1 + w2x2 + ... + wnxn + b
```

每个特征都有自己的权重。权重越大，说明这个特征对预测结果影响越强。

课程还讲了向量化。向量化的意义是用矩阵和向量一次性表示很多样本、很多特征和很多参数。这样不仅写法更简洁，而且可以充分利用计算机底层的高效数值计算能力。后面的深度学习也大量依赖向量化。

多元线性回归同样可以使用梯度下降。只不过参数从一个 `w` 变成了一组权重。模型会同时调整所有权重和偏置，让整体代价下降。

特征缩放是这一周很重要的实践技巧。不同特征的数值范围可能差别很大，比如温度可能是几十，运行时间可能是几万秒，转速可能是几千。范围差别太大时，梯度下降会走得很别扭，收敛变慢。特征缩放把不同特征调整到相近范围，让训练更稳定。

课程还讲了如何检查梯度下降是否收敛。常见方式是观察代价函数是否持续下降，是否逐渐趋于平稳。如果代价不降反升，常见原因是学习率太大；如果下降太慢，可能是学习率太小或特征没有缩放好。

多项式回归则是在原始特征基础上构造更复杂的特征，比如 `x^2`、`x^3`。这样即使模型本身仍然是线性模型，也可以拟合弯曲的关系。它说明了一个重要思想：模型能力不仅来自算法本身，也来自特征怎么设计。

### Week 3：逻辑回归、决策边界、正则化和过拟合

第三周从回归问题转向分类问题，重点是逻辑回归。

逻辑回归虽然名字里有“回归”，但它主要用于分类，尤其是二分类。比如判断设备是否故障、邮件是否垃圾、图像里有没有某个目标。它输出的是一个介于 0 和 1 之间的概率。

逻辑回归使用 sigmoid 函数把线性结果压缩到 0 到 1：

```text
z = wx + b
a = sigmoid(z)
```

如果输出概率大于某个阈值，比如 0.5，就判为正类；否则判为负类。

决策边界是逻辑回归里非常直观的概念。它表示模型把不同类别分开的那条线、那个平面，或者更复杂的曲面。在线性逻辑回归中，决策边界通常是线性的；如果加入多项式特征，也可以得到非线性边界。

逻辑回归有自己的代价函数。不能直接使用线性回归里的平方误差，因为那样会让优化变得不合适。逻辑回归通常使用交叉熵损失，它会在模型对错误答案非常自信时给出更大的惩罚。

这一周还讲了正则化。正则化是解决过拟合的重要方法。

过拟合的意思是模型在训练集上表现很好，但到了新数据上表现很差。它像是把训练数据背下来了，而不是学到了真正规律。在线性回归和逻辑回归中，过拟合常常表现为参数过大、模型曲线过于复杂。

正则化会在代价函数里加入对参数大小的惩罚。模型不能只追求训练误差小，还要尽量保持参数不过分夸张。这样可以减少模型复杂度，提高泛化能力。

在设备控制里，过拟合尤其危险。因为设备实际运行环境会变化，模型不能只适应历史样本。正则化、验证集和模型评估，都是让模型在真实环境中更可靠的手段。

# 三、高级学习算法

第二门课把内容推进到神经网络、模型评估、机器学习项目流程和决策树。它不再只关注单个模型怎么训练，也开始关注完整项目怎么做、模型好坏怎么判断、数据不平衡怎么办。

## Week 1：神经网络、层、前向传播和矩阵乘法

第一周介绍神经网络。

神经网络可以看作很多简单计算单元组成的模型。每个神经元接收输入，乘以权重，加上偏置，再经过激活函数输出结果。多个神经元组成一层，多层叠起来就形成神经网络。

神经网络通常包含输入层、隐藏层和输出层。输入层接收数据，隐藏层提取中间特征，输出层给出最终预测。

前向传播是神经网络从输入计算到输出的过程。数据一层一层往前走，每一层都会做一次线性变换和非线性激活。最终模型输出分类概率、预测值或其他结果。

课程还讲了如何构建神经网络，以及如何用代码实现前向传播。这里矩阵乘法非常重要。神经网络里的大量计算，本质上都是矩阵乘法和向量运算。理解矩阵乘法，才能理解为什么神经网络可以高效处理成批数据。

从设备控制角度看，神经网络适合处理复杂模式。比如多个传感器信号之间的关系不是简单线性的，传统模型难以表达，这时神经网络可以用多层结构学习更复杂的映射。

## Week 2：激活函数、Sigmoid、Softmax 和多分类

第二周重点讲激活函数，尤其是 sigmoid 和 softmax。

激活函数给神经网络带来非线性。如果没有激活函数，多层线性变换叠在一起仍然只是一个线性变换，深层网络就没有意义。激活函数让网络可以拟合更复杂的关系。

Sigmoid 常用于二分类输出层。它把数值压到 0 到 1，可以解释成概率。

Softmax 常用于多分类。它会把多个输出转成一组概率，并且所有类别概率之和为 1。比如一个视觉模型要判断图像属于螺丝、齿轮、裂纹、正常工件中的哪一类，softmax 就可以给出每个类别的概率。

这一周还实现了用 softmax 进行分类。它把神经网络从二分类扩展到多分类，是后续图像分类、语音识别和自然语言任务的基础。

## Week 3：模型评估、偏差方差、基准、项目迭代和倾斜数据集

第三周关注模型评估和项目实践。

偏差和方差是判断模型问题的核心框架。

偏差高，说明模型本身太简单，连训练集都拟合不好。这是欠拟合。

方差高，说明模型太依赖训练数据，在训练集上很好，但在开发集或测试集上差。这是过拟合。

通过比较训练误差、开发集误差和基准表现，可以判断问题主要来自偏差还是方差。

课程还讲了表现基准。人类水平表现常常可以作为一个参考。如果模型远差于人类，说明还有很大改进空间；如果模型接近甚至超过人类，误差分析的方式也会不同。

机器学习项目不是一次性完成的，而是迭代过程：

```text
确定目标 -> 收集数据 -> 训练模型 -> 评估结果 -> 分析错误 -> 调整数据或模型 -> 再训练
```

这个循环比单纯调模型更重要。很多时候，改进模型不是换算法，而是通过错误分析发现数据问题、标签问题、特征问题或评价指标问题。

倾斜数据集是这一周的重要内容。所谓倾斜数据集，就是某一类样本远多于另一类。比如设备故障检测中，正常样本可能占 99%，故障样本只占 1%。这时准确率会误导人：模型什么都预测正常，也能有 99% 准确率，但它没有真正发现故障。

所以课程介绍了精确率和召回率。

精确率关心的是：模型预测为正的样本里，有多少是真的正。

召回率关心的是：所有真实为正的样本里，有多少被模型找出来。

在故障检测中，召回率很关键，因为漏报可能带来严重后果。但精确率也不能太低，否则会产生太多误报。二者之间需要权衡。

## Week 4：决策树、信息增益、独热编码、随机森林和 XGBoost

第四周讲决策树及其扩展算法。

决策树像一连串判断问题。每个节点根据某个特征做分裂，样本沿着不同分支往下走，最后到达叶子节点，得到预测结果。

构建决策树时，需要决定每一步用哪个特征来分裂。课程介绍了纯度和信息增益。

纯度表示一个节点里样本是否属于同一类。如果一个节点里的样本都属于同一类，纯度就高；如果混杂很多类别，纯度就低。

信息增益表示一次分裂让数据变得更纯的程度。信息增益越大，说明这个特征越适合用来分裂。

独热编码用于处理类别特征。比如设备类型有 A、B、C 三种，不能简单用 1、2、3 表示，因为这样会暗含大小关系。独热编码会把它们变成多个 0/1 特征，让模型正确理解类别。

随机森林是很多决策树的集成。单棵树容易过拟合，随机森林通过训练多棵不同的树，再把它们的结果综合起来，通常更稳定。

XGBoost 是一种强大的梯度提升树算法。它通过一棵树一棵树地修正前面模型的错误，常常在结构化数据任务中表现很好。对于设备运行数据、传感器统计特征、维护记录这类表格数据，XGBoost 往往是非常有竞争力的基线模型。

# 四、无监督学习、推荐系统和强化学习

第三门机器学习课讲的是监督学习之外的几类重要方法：没有标签时怎么发现结构，用户或对象之间怎么做推荐，以及智能体如何通过奖励学习决策。

## Week 1：聚类、K-means 和异常检测

第一周讲聚类和异常检测。

聚类是无监督学习任务。它没有预先给定标签，而是让算法根据样本之间的相似性自动分组。

K-means 是经典聚类算法。它大致做三件事：

1. 随机选择若干个聚类中心。
2. 把每个样本分配给最近的中心。
3. 重新计算每个簇的中心。

这个过程反复进行，直到聚类结果稳定。

在设备控制里，K-means 可以用于发现不同运行工况。比如设备可能有低负载、中负载、高负载、异常震动等状态，如果没有人工标签，聚类可以先帮助我们看出数据里天然存在的分组。

异常检测用于发现和大多数样本不一样的数据点。它非常适合设备故障预警，因为故障样本往往很少，很难收集完整标签。异常检测可以先学习“正常状态长什么样”，再判断新数据是否偏离正常模式。

课程中还讲了异常检测算法的实现。这类算法通常会估计正常数据的分布，如果新样本落在概率很低的位置，就把它视为异常。

## Week 2：协同过滤、均值归一化、基于内容的过滤和 TensorFlow 实现

第二周讲推荐系统。

协同过滤的核心思想是利用用户和物品之间的历史互动来推荐。它不一定需要知道物品具体是什么，只要知道哪些用户喜欢哪些物品，就可以学习用户和物品的隐含特征。

均值归一化用于处理评分偏移问题。不同用户打分习惯不同，有些人普遍给高分，有些人普遍给低分。归一化可以减少这种习惯差异，让模型更关注相对偏好。

基于内容的过滤则利用物品自身特征和用户偏好做推荐。比如知道某个用户喜欢某类内容，就推荐特征相似的新内容。

课程还比较了协同过滤和基于内容的过滤，并用 TensorFlow 实现了相关算法。

放在设备控制里，推荐系统的思想可以迁移到“参数推荐”和“策略推荐”。比如在相似工况下，系统可以推荐历史上表现好的控制参数；在相似设备上，可以推荐维护方案；在相似任务中，可以推荐模型或动作策略。

## Week 3：强化学习、状态、动作、价值函数和月球着陆器

第三周讲强化学习。

强化学习和前面的监督学习很不一样。监督学习有输入和标准答案，模型学习答案。强化学习没有每一步的标准答案，它只有环境反馈的奖励。智能体需要通过试错，学习在不同状态下采取什么动作，才能长期获得更高奖励。

课程用月球着陆器和火星探测器作为例子。它们非常适合解释强化学习，因为控制问题天然包含状态、动作和结果。

强化学习里的几个核心概念是：

- 状态：当前环境的描述。比如位置、速度、角度、燃料、传感器读数。
- 动作：智能体可以做的选择。比如向左喷气、向右喷气、加速、减速。
- 奖励：环境对动作结果的反馈。比如成功着陆得到正奖励，坠毁得到负奖励。
- 策略：从状态到动作的选择规则。
- 动作价值函数：衡量在某个状态下采取某个动作，长期来看有多好。
- 状态价值函数：衡量处于某个状态，长期来看有多好。

课程最后用代码实现了月球着陆器案例，并介绍了几种优化方法。

贪婪策略会选择当前看起来价值最高的动作。它简单直接，但可能过早陷入局部最优，因为它不愿意探索未知动作。

小批量更新是从经验数据中抽取一小批样本来更新模型。它比每次只看一个样本更稳定，也比每次看全部数据更高效。

软更新用于让目标网络或参考参数缓慢跟随当前网络。这样可以减少训练震荡，让强化学习训练更稳定。

强化学习和设备控制关系最直接。设备控制关心的就是在当前状态下做什么动作。机器人控制、无人车路径规划、机械臂操作、能源管理、动态调度，都可以看作强化学习问题。

# 五、深度学习部分

深度学习部分主要来自深度学习专项课程。它从神经网络基础开始，逐步讲到优化深层网络、结构化项目、卷积神经网络和序列模型。

深度学习的核心变化，是模型从浅层变成深层。浅层模型通常依赖人工特征，深度网络则可以从原始数据中自动学习多层表示。

课程中提到的五大组成部分是：

- 神经网络基础
- 深层神经网络
- 卷积神经网络
- 残差连接
- 时序模型

这些内容对应不同数据类型和任务：

- 普通表格数据：可以用全连接神经网络。
- 图像数据：适合用卷积神经网络。
- 很深的视觉模型：需要残差连接缓解梯度问题。
- 音频、文本、传感器序列：适合用 RNN、GRU、LSTM 或 Transformer。

实际应用包括垃圾邮件过滤、图像分类、目标检测、人脸识别、移动端高效网络、语音识别和机器翻译等。

## 第一课：神经网络和深度学习

第一门课讲神经网络基础。

课程先介绍监督学习和神经网络的概念。神经网络本质上仍然是在做输入到输出的映射，只是它可以通过多层结构学习复杂函数。

二元分类是神经网络入门的重要任务。比如判断图片里有没有猫，判断邮件是否垃圾，判断设备状态是否异常。这些任务都可以输出一个 0 到 1 的概率。

逻辑回归在这里再次出现。它既是机器学习里的基础分类模型，也是理解神经网络的入口。单个逻辑回归单元可以看作一个非常简单的神经元。

课程讲了梯度下降和计算图。计算图把复杂计算拆成一系列节点，方便理解前向传播和反向传播。前向传播计算预测值和损失，反向传播计算每个参数对损失的影响，也就是梯度。

向量化训练数据是深度学习里的重要实践。把多个样本组织成矩阵，可以避免低效循环，大幅提高训练速度。

课程还讲了 Python 广播机制和 Jupyter Notebook。广播机制让不同形状的数组在符合规则时自动扩展并参与计算，是 NumPy 和深度学习编程里的常见技巧。

课程中还包含对 Geoffrey Hinton、Peter A. Bell 和 Ian Goodfellow 的访谈。这些访谈帮助理解深度学习的发展背景。Hinton 是深度学习的重要奠基者之一，Goodfellow 与生成对抗网络等方向有关。

后半部分讲激活函数、深层网络的正向传播和反向传播，以及参数和超参数。

参数是模型通过训练学出来的值，比如权重和偏置。

超参数是训练前人为设置的值，比如学习率、层数、隐藏单元数、正则化强度、批量大小。超参数不会直接从数据中学习，但会显著影响训练效果。

## 第二课：优化深度神经网络，超参数调优、正则化和优化算法

第二门课关注如何把神经网络训练好。

首先讲训练集、开发集和测试集的划分。训练集用于训练参数，开发集用于调模型和选超参数，测试集用于最终评估。三者分开，是为了避免把模型调到只适合某一份数据。

偏差和方差在深度学习里同样重要。高偏差表示模型欠拟合，高方差表示模型过拟合。正则化、更多数据、改变模型规模、调整训练方式，都是解决偏差方差问题的手段。

课程提到“规划”的概念，这里可以理解为训练深层网络时对数据、模型结构、初始化和优化流程的整体设计。

梯度爆炸和梯度消失是深层网络训练中的典型问题。网络越深，反向传播时梯度需要穿过越多层。如果梯度不断变小，前面层几乎学不到东西，这就是梯度消失；如果梯度不断变大，训练会不稳定，这就是梯度爆炸。

权值初始化是缓解这些问题的重要方法。合适的初始化可以让信号在前向和反向传播时保持合适尺度，避免一开始就饱和或发散。

课程还讲了小批量梯度下降。它每次用一小批样本更新参数，兼顾了训练效率和梯度稳定性，是深度学习中最常用的训练方式。

指数加权平均用于平滑序列数据。它可以让最近的数据影响更大，过去的数据影响逐渐变小。动量梯度下降就使用了类似思想，把过去梯度方向累积起来，让优化路径更平滑。

RMSProp 会根据梯度平方的移动平均调整每个参数的学习步长。它能让不同方向的更新尺度更合理。

Adam 结合了动量和 RMSProp 的思想，同时估计梯度的一阶矩和二阶矩，是深度学习中非常常用的优化算法。

学习率衰减则是在训练过程中逐渐降低学习率。前期用较大学习率快速靠近较好区域，后期用较小学习率细致收敛。

Batch Normalization 用于规范化网络中间层的激活值。它可以加速训练，提高稳定性，并在一定程度上带来正则化效果。

课程最后训练了一个 Softmax 分类器，并介绍 TensorFlow。TensorFlow 是深度学习框架，可以自动计算梯度、管理计算图、训练神经网络，让开发者更专注于模型结构和数据流程。

## 第三课：结构化机器学习项目

第三门课讲如何系统地推进机器学习项目。

正交化是一个重要思想。它的意思是希望每个改动主要影响一个目标，而不是同时影响很多东西。比如开发集指标不好，应该知道是偏差问题、方差问题、数据分布问题还是评价指标问题，而不是盲目调整所有东西。

单一数值评估指标用于帮助团队做决策。模型可能有准确率、延迟、内存、召回率、精确率等很多指标。如果没有一个明确的主指标，模型选择会变得混乱。课程强调要用清晰的指标推动迭代。

人类水平表现再次出现。它不仅是性能参考，也能帮助分析可避免偏差。比如模型还远差于人类，说明模型或数据还有明显问题；如果模型已经接近人类，就需要更细的错误分析。

误差分析是结构化项目中的关键方法。不是只看总准确率，而是抽样查看模型错在哪里。比如视觉模型识别失败，是光照问题、遮挡问题、标注错误，还是某个类别样本太少。通过错误分析，可以决定下一步最值得做什么。

迁移学习是利用已有模型学到的知识来解决新任务。比如用在大规模图像数据上训练过的 CNN，迁移到设备缺陷检测任务，只需要较少标注数据就能取得不错效果。

多任务学习是一个模型同时学习多个相关任务。比如自动驾驶模型同时识别车道线、车辆、行人和交通标志。多个任务共享底层表示，可能互相帮助。

端到端学习是让模型从原始输入直接学到最终输出。比如从图像直接输出方向盘角度。它的优点是减少人工设计中间步骤，但缺点是需要大量数据，而且可解释性和可控性可能较弱。

课程中还包含对 Andrej Karpathy、Ruslan Salakhutdinov、Thera Card 和其他嘉宾的访谈。访谈帮助理解机器学习项目在真实研究和工业环境中的实践经验。

## 第四课：卷积神经网络

第四门课讲卷积神经网络，也就是 CNN。CNN 主要用于计算机视觉。

课程先介绍计算机视觉任务。常见任务包括图像分类、目标检测、语义分割、人脸识别和风格迁移。

边缘探测是理解卷积的入口。卷积核像一个小窗口，在图像上滑动，计算局部区域和卷积核的匹配程度。不同卷积核可以检测垂直边缘、水平边缘、纹理或更复杂模式。

填充用于控制卷积后图像尺寸。没有填充时，图像会越卷越小；加入填充可以保留边缘信息，并控制输出大小。

步长表示卷积核每次移动多少像素。步长越大，输出尺寸越小，计算量也更少。

三维卷积用于处理有多个通道的输入，比如 RGB 图像有三个颜色通道。卷积核也要覆盖这些通道。

池化用于降采样。最大池化会保留局部区域中的最大值，平均池化会保留平均值。池化可以减少尺寸和计算量，并增加一定平移不变性。

课程还讲了经典卷积网络。经典网络展示了 CNN 架构如何从简单堆叠逐渐走向更深、更高效的设计。

残差网络解决深层网络训练困难问题。残差连接让某一层的输入可以跳过若干层直接加到后面。这样梯度可以更顺畅地传播，深层网络更容易训练。

MobileNet 和 EfficientNet 关注移动端和高效网络。设备控制场景里，很多模型需要部署在边缘设备、嵌入式设备或移动端，计算资源有限，所以高效网络非常重要。

迁移学习和数据增强也是视觉任务常用方法。迁移学习利用预训练模型减少数据需求；数据增强通过旋转、裁剪、翻转、颜色变化等方式扩大训练样本多样性。

目标检测不仅要知道图像里有什么，还要知道目标在哪里。YOLO 是典型目标检测方法，它把检测问题转成一次前向传播中的位置和类别预测，速度较快，适合实时场景。

U-Net 常用于图像分割，尤其是需要像素级预测的任务。转置卷积可以把低分辨率特征图上采样回更高分辨率。

人脸识别部分讲了孪生网络和三元组损失。孪生网络学习比较两张图像是否相似，三元组损失让同一个人的图像更近，不同人的图像更远。

风格迁移则把内容图像和风格图像结合起来，生成具有某种艺术风格的新图像。它通过定义内容代价和风格代价来优化图像。

在设备控制中，CNN 可以用于视觉感知。比如机器人识别物体位置，工业相机检测缺陷，自动驾驶识别道路和行人，移动设备做人脸识别和场景理解。

## 第五课：自然语言处理，构建序列模型

第五门课讲序列模型，主要面向自然语言处理，也适用于音频和时间序列。

序列数据的特点是顺序重要。句子里词的顺序会影响意思，语音里音素的顺序决定内容，传感器时间序列里前后变化反映设备状态。

循环神经网络 RNN 是处理序列的基础模型。它会把上一步的隐藏状态传到下一步，让模型保留历史信息。这样模型在处理当前输入时，可以参考之前看到的内容。

普通 RNN 在长序列上容易遇到梯度消失，难以记住很久以前的信息。GRU 和 LSTM 就是为了解决这个问题。

GRU 通过门控机制控制哪些信息保留、哪些信息更新。LSTM 更复杂，有输入门、遗忘门、输出门和记忆单元，能够更好地建模长期依赖。

双向 RNN 同时从前往后和从后往前读序列。这样模型在理解某个位置时，可以同时参考前文和后文。它适合很多离线序列任务，比如文本分类、命名实体识别等。

词嵌入把词表示成向量。相比独热编码，词嵌入能表达词与词之间的相似性。比如“国王”和“王后”会在向量空间里比较接近，而且词嵌入可以捕捉某些语义关系。

课程中实现了情感分类任务。情感分类就是判断文本表达的是正面、负面或其他情绪。

课程还实现了英法翻译任务。机器翻译需要把一种语言的序列映射成另一种语言的序列。

BLEU 分数用于评估翻译质量。它会比较模型翻译结果和参考翻译之间的 n-gram 重合程度，是机器翻译中的常见指标。

课程还讲了促进自然语言处理发展的方法，以及 Transformer 模型。Transformer 不再依赖传统循环结构，而是用注意力机制直接建模序列中不同位置之间的关系。它更适合并行计算，也成为现代 NLP 的核心架构。

语音识别也是序列模型的重要应用。它把音频信号转成文字，本质上也是从一个时间序列映射到另一个符号序列。

在设备控制中，序列模型不仅能处理语音命令，也能处理传感器时间序列。比如根据连续振动信号判断轴承状态，根据连续电流判断电机负载，根据历史状态预测未来故障风险。

# 六、把课程内容放回设备控制

如果目标是“设备控制”，机器学习和深度学习不是孤立知识，而是一套让设备具备感知、预测和决策能力的方法。

## 1. 感知

感知是设备理解外部世界。

视觉感知可以用 CNN、YOLO、U-Net、人脸识别等方法。它让设备看到物体、缺陷、障碍物、道路、人脸或操作环境。

语音和语言感知可以用 RNN、LSTM、GRU、Transformer 和语音识别模型。它让设备理解语音指令、文本指令或日志信息。

传感器感知可以用传统机器学习、异常检测和序列模型。它让设备理解温度、振动、电流、电压、速度、位置等连续信号。

## 2. 预测

预测是根据当前和历史数据判断未来或隐藏状态。

线性回归可以预测连续指标，比如温度趋势、能耗、负载。

逻辑回归、神经网络、决策树和 XGBoost 可以做分类，比如正常/异常、故障类型、风险等级。

时间序列模型可以预测设备状态变化，比如提前发现故障征兆。

## 3. 决策

决策是根据状态选择动作。

传统监督学习可以把历史经验学成策略，例如在某种工况下推荐某种参数。

推荐系统可以推荐配置、策略或维护方案。

强化学习则直接学习状态到动作的策略，更适合连续决策控制问题。

## 4. 评估

设备控制中的模型评估不能只看准确率。

故障检测要重视召回率，因为漏报很危险。

报警系统要重视精确率，因为误报太多会让人忽略报警。

实时控制要重视延迟，因为模型太慢会影响控制闭环。

边缘设备要重视模型大小和算力消耗，所以 MobileNet、EfficientNet 等高效模型很有价值。

## 5. 落地流程

一个面向设备控制的机器学习项目，大致可以按这个流程推进：

```text
明确控制目标
收集设备数据
清洗数据和构造特征
划分训练集、开发集、测试集
选择基线模型
训练和评估
做错误分析
改进数据、特征或模型
部署到设备或控制系统
持续监控真实表现
```

这正好对应课程里反复强调的项目迭代思想。

# 八、最后总结

这份课程内容从最基础的“模型如何从数据中学习”开始，一路扩展到复杂神经网络、视觉模型、序列模型和强化学习。

机器学习部分打基础：理解特征、代价函数、梯度下降、模型评估、偏差方差、过拟合、树模型、聚类、异常检测、推荐系统和强化学习。

深度学习部分提高表达能力：用神经网络处理复杂数据，用优化算法稳定训练深层模型，用 CNN 处理图像，用 RNN、LSTM、GRU 和 Transformer 处理序列。

放在设备控制这个主题里，整套知识可以归结为三件事：

1. 让设备看懂世界：通过视觉、语音和传感器模型完成感知。
2. 让设备预测状态：通过回归、分类、异常检测和序列模型判断当前与未来。
3. 让设备选择动作：通过推荐系统和强化学习形成策略，并在真实环境中持续优化。

所以，这些课程并不是零散算法的堆积，而是一条从数据到模型、从模型到决策、从决策到控制的完整路径。
