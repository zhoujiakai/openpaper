# 一、总体实验地图

这些实验可以分成三类。

第一类是机器学习实验，重点是从结构化数据、图像数据和用户评分数据中学习规律。典型任务包括房价预测、肿瘤分类、图像分类、手写数字识别、猫狗分类和推荐系统。

第二类是深度学习实验，重点是用神经网络处理图像、文本、音频、序列和强化学习环境。典型任务包括猫分类器、垃圾邮件分类器、YOLO 目标检测、人脸识别、触发词检测、英法翻译、月球着陆器和用电负荷预测。

第三类是自动控制实验，重点是让真实或仿真的设备根据反馈完成动作。典型任务包括 STM32 红外计次、PID 电机定速、PID 电机定位、双环 PID 倒立摆、MPC 机械臂控制仿真和模糊控制洗衣机。

放在设备控制方向看，这些实验对应三种能力：

- 机器学习：让设备从数据里学会识别、预测和推荐。
- 深度学习：让设备具备视觉、语音、文本、时序和策略学习能力。
- 自动控制：让设备根据反馈稳定、准确地完成动作。

# 二、机器学习实验

机器学习实验主要来自 `ml-吴恩达机器学习/`。这些实验的共同特点是：先明确输入特征和目标标签，再选择模型，定义损失函数，训练参数，最后用指标评价模型表现。

## 1. 房价预测

### 任务

给定房子的信息，预测房价。

最简单版本只使用房屋面积一个特征，预测房价。扩展版本会使用多个特征，比如面积、卧室数量、楼层、房龄、地理位置等。

这个实验是监督学习中的回归任务。输入是数值特征，输出也是连续数值。

### 框架

课程实验主要使用 Python、NumPy、Matplotlib 和 scikit-learn。personal 中提到框架为 PyTorch，如果用 PyTorch 重写，可以把线性回归写成一个单层模型。

可理解为两个实现层次：

- NumPy/scikit-learn 版本：用于理解线性回归、代价函数、梯度下降。
- PyTorch 版本：用于练习 Tensor、自动求导、训练循环。

### 数据集特点

数据集通常是表格数据。

单变量版本：

- `x`：房屋面积。
- `y`：房价。

多变量版本：

- `X`：多个房屋特征组成的矩阵。
- `y`：房价标签。

特征尺度可能差别很大。例如面积可能是几百到几千，卧室数量可能是 1 到 5。如果不做特征缩放，梯度下降会变慢。

### 模型结构

单变量线性回归：

$$
f(x) = wx + b
$$

多变量线性回归：

$$
f(x) = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b
$$

PyTorch 版本可以写成：

```python
model = torch.nn.Linear(num_features, 1)
```

### 优化算法

主要使用批量梯度下降或随机梯度下降。

训练流程是：

1. 用当前参数计算预测房价。
2. 计算预测值和真实房价之间的误差。
3. 用均方误差构造代价函数。
4. 计算梯度。
5. 按学习率更新 `w` 和 `b`。

scikit-learn 中可以使用：

- `LinearRegression`：通常求闭式解或内部优化。
- `SGDRegressor`：使用随机梯度下降。
- `StandardScaler`：做特征标准化。

PyTorch 中可以使用：

- `MSELoss`
- `SGD` 或 `Adam`

### 评价指标

> 常用指标：
>
> - MSE：均方误差。
> - RMSE：均方根误差，更接近房价单位。
> - MAE：平均绝对误差。
> - R²：解释方差比例。
>

课程早期更关注代价函数是否下降，以及预测直线是否贴近数据点。

### 代码结构

推荐代码结构：

```text
house_price/
├── data.py          # 读取数据、特征缩放、划分数据集
├── model.py         # 线性回归模型
├── train.py         # 训练循环
├── evaluate.py      # 评价指标
└── visualize.py     # 绘制散点图、预测直线、损失曲线
```

### 实验主流程

1. 读取房价数据。
2. 可视化面积和房价的关系。
3. 初始化模型参数。
4. 计算模型预测值。
5. 定义代价函数。
6. 用梯度下降训练。
7. 绘制损失随迭代次数的变化。
8. 用训练后的模型预测新房子的价格。
9. 对比预测值和真实值。

这个实验的核心收获是：理解监督学习回归任务的基本闭环，也就是“预测、算误差、更新参数、再预测”。

## 2. 恶性肿瘤分类器

### 任务

根据患者的年龄、肿瘤大小等特征，预测肿瘤是良性还是恶性。

这是二分类任务。

输出可以表示为：

- `0`：良性。
- `1`：恶性。

### 框架

主要使用 Python、NumPy、Matplotlib 和 scikit-learn。

如果使用 PyTorch，可以用一个线性层加 sigmoid，或直接使用 `BCEWithLogitsLoss`。

### 数据集特点

数据是结构化表格数据。

典型特征：

- 年龄。
- 肿瘤大小。
- 肿瘤边界特征。
- 细胞形态特征。

课程中的简化实验常用一维或二维数据，用来可视化 sigmoid、决策边界和逻辑回归损失。

### 模型结构

模型是逻辑回归。

先计算线性部分：

$$
z = w^Tx + b
$$

再经过 sigmoid：

$$
\hat{y} = \frac{1}{1 + e^{-z}}
$$

如果 $\hat{y} \ge 0.5$，预测为恶性；否则预测为良性。

### 优化算法

使用梯度下降或 scikit-learn 的逻辑回归求解器。

损失函数使用逻辑回归交叉熵损失，而不是线性回归的均方误差。

原因是分类任务需要学习决策边界，均方误差在逻辑回归里可能形成不适合梯度下降的非凸形状。

### 评价指标

常用指标：

- Accuracy：准确率。
- Precision：精确率。
- Recall：召回率。
- F1 score：精确率和召回率的调和平均。
- Confusion Matrix：混淆矩阵。

医疗分类任务通常更重视召回率，因为漏判恶性肿瘤风险更大。

### 代码结构

```text
tumor_classifier/
├── data.py          # 读取和标准化患者特征
├── model.py         # 逻辑回归模型
├── train.py         # 训练逻辑回归
├── evaluate.py      # 混淆矩阵、准确率、召回率
└── plot.py          # sigmoid 曲线、决策边界
```

### 实验主流程

1. 准备肿瘤特征和标签。
2. 可视化不同类别样本的分布。
3. 实现 sigmoid 函数。
4. 构造逻辑回归模型。
5. 计算交叉熵代价函数。
6. 使用梯度下降训练参数。
7. 绘制决策边界。
8. 用测试样本计算分类指标。

这个实验的核心收获是：理解分类问题和回归问题不同，分类模型关心的是决策边界，而不是拟合一条直线。

## 3. 图像分类器

### 任务

将图片区分为 4 个类别：

- 猫
- 狗
- 车
- 人

这是多分类图像分类任务。

### 框架

适合使用 PyTorch。

模型可以使用迁移学习：下载在大型数据集上训练好的模型，例如 ResNet、MobileNet、EfficientNet，再把最后的分类层替换成 4 类输出。

### 数据集特点

数据集由多类图片组成，每张图片有一个类别标签。

目录通常可以组织为：

```text
dataset/
├── train/
│   ├── cat/
│   ├── dog/
│   ├── car/
│   └── person/
├── val/
│   ├── cat/
│   ├── dog/
│   ├── car/
│   └── person/
└── test/
    ├── cat/
    ├── dog/
    ├── car/
    └── person/
```

图像需要统一尺寸，并做归一化。常见增强包括随机裁剪、水平翻转、颜色扰动。

### 模型结构

迁移学习模型结构：

```text
输入图像
-> 预训练 CNN 主干
-> 全局池化
-> 新的全连接分类头
-> Softmax / logits
```

训练时通常替换最后一层：

```python
model.fc = nn.Linear(in_features, 4)
```

### 优化算法

损失函数：

- `CrossEntropyLoss`

优化器：

- `Adam`
- `SGD + Momentum`

训练策略：

1. 数据少时，冻结 CNN 主干，只训练最后分类头。
2. 数据中等时，解冻后几层进行微调。
3. 数据较多时，可以对整个模型微调，但学习率要小。

### 评价指标

常用指标：

- Top-1 Accuracy
- 每类 Precision / Recall
- 混淆矩阵

如果类别不平衡，只看总体准确率不够，要看每一类的召回率。

### 代码结构

```text
image_classifier/
├── dataset.py       # ImageFolder、transform、DataLoader
├── model.py         # 加载预训练模型并替换分类头
├── train.py         # 训练
├── evaluate.py      # 准确率、混淆矩阵
└── predict.py       # 单张图片预测
```

### 实验主流程

1. 整理图片目录和标签。
2. 定义训练集和验证集 transform。
3. 使用 DataLoader 加载数据。
4. 加载预训练 CNN。
5. 替换最后分类层为 4 类。
6. 训练分类头或微调整个模型。
7. 在验证集上计算准确率。
8. 查看混淆矩阵，分析哪些类别容易混淆。

这个实验的核心收获是：迁移学习可以把大型数据集上学到的视觉特征迁移到小数据任务上，减少训练成本。

## 4. 手写数字识别

### 任务

将数字图片区分为 0 到 9 这 10 个数字。

这是经典多分类任务。

### 框架

PyTorch。

常见数据集是 MNIST，图像是灰度手写数字。

### 数据集特点

MNIST 图像通常是：

- 单通道灰度图。
- 尺寸 28×28。
- 标签为 0 到 9。
- 类别比较均衡。

输入张量形状通常为：

```text
[batch_size, 1, 28, 28]
```

### 模型结构

简单版本可以使用全连接网络：

```text
28×28 图像
-> Flatten
-> Linear
-> ReLU
-> Linear
-> 10 类 logits
```

更标准版本可以使用 CNN：

```text
Conv2d
-> ReLU
-> MaxPool
-> Conv2d
-> ReLU
-> MaxPool
-> Flatten
-> Linear
-> Softmax / logits
```

LeNet-5 是手写数字识别中的经典结构。

### 优化算法

损失函数：

- `CrossEntropyLoss`

优化器：

- `Adam`
- `SGD`

### 评价指标

常用指标：

- Accuracy
- Confusion Matrix
- 每个数字类别的错误率

比如 4 和 9、3 和 5、1 和 7 可能更容易混淆。

### 代码结构

```text
mnist/
├── dataset.py       # 下载 MNIST、transform、DataLoader
├── model.py         # MLP 或 CNN
├── train.py         # 训练循环
├── evaluate.py      # 测试准确率
└── visualize.py     # 展示预测错误的样本
```

### 实验主流程

1. 下载或加载 MNIST。
2. 做归一化。
3. 构建 CNN 或 MLP。
4. 用交叉熵训练。
5. 在测试集上计算准确率。
6. 可视化错误样本。

这个实验的核心收获是：理解图像分类的基本流程，以及 CNN 如何比普通全连接网络更适合处理图像。

## 5. 猫狗分类器

### 任务

给定一张猫或狗的照片，根据动物特征区分猫和狗。

personal 中写到模型是决策树。这里可以理解为：不是直接用 CNN 从原始像素学习，而是先把图片或动物属性转成结构化特征，再用决策树分类。

### 框架

可以使用 Python 和 scikit-learn。

如果使用图像原始像素，决策树通常效果不如 CNN。更合理的做法是提取特征后再训练决策树。

### 数据集特点

如果是结构化特征，可能包括：

- 耳朵形状。
- 脸部比例。
- 鼻子大小。
- 毛发纹理。
- 体型。
- 颜色统计。

如果是图像数据，则需要先做特征提取，例如使用预训练 CNN 提取 embedding，再用决策树分类。

### 模型结构

决策树模型是一连串判断：

```text
特征 A 是否大于阈值？
-> 是：进入左/右子树
-> 否：进入另一子树
-> 到叶子节点输出 cat 或 dog
```

训练时，决策树会根据纯度或信息增益选择最有区分度的特征做分裂。

### 优化算法

决策树不是用梯度下降训练，而是递归选择最佳分裂。

常用标准：

- Gini impurity
- Entropy / Information Gain

### 评价指标

常用指标：

- Accuracy
- Precision
- Recall
- F1 score
- 决策树深度和叶子节点数量

如果树太深，容易过拟合。需要限制最大深度、最小样本数等参数。

### 代码结构

```text
cat_dog_tree/
├── features.py      # 图像/动物特征提取
├── train.py         # 训练 DecisionTreeClassifier
├── evaluate.py      # 准确率、混淆矩阵
└── visualize.py     # 可视化树结构
```

### 实验主流程

1. 准备猫狗样本。
2. 提取结构化特征。
3. 划分训练集和测试集。
4. 训练决策树。
5. 可视化树的分裂规则。
6. 评估分类准确率。
7. 分析错误样本。

这个实验的核心收获是：理解决策树如何通过特征阈值一步步做分类，也理解传统机器学习在图像任务中通常依赖特征工程。

## 6. 推荐系统

### 任务

给定一个用户，该用户只给少数电影评过分。根据所有用户对电影的评分，向该用户推荐更多可能喜欢的电影。

这是推荐系统任务。

### 框架

可以使用 Python、NumPy、TensorFlow 或 PyTorch。

课程中重点是协同过滤和均值归一化。

### 数据集特点

数据通常是用户-电影评分矩阵：

```text
行：电影
列：用户
值：评分
```

这个矩阵非常稀疏，因为每个用户只看过和评价过很少一部分电影。

还会有一个指示矩阵 `R`：

- `R(i,j)=1`：用户 j 给电影 i 评过分。
- `R(i,j)=0`：没有评分。

### 模型结构

协同过滤的核心是学习两个向量：

- 电影特征向量。
- 用户偏好向量。

预测评分可以写成：

$$
\hat{y}_{i,j} = x_i^T w_j + b_j
$$

其中：

- `x_i` 是电影 i 的特征。
- `w_j` 是用户 j 的偏好。
- `b_j` 是用户偏置。

训练目标是让预测评分接近真实评分。

### 优化算法

使用梯度下降或框架自动求导。

损失只在已有评分的位置计算：

```text
预测评分 - 真实评分
```

常加入正则化，避免用户向量和电影向量过拟合。

均值归一化用于解决不同电影或不同用户评分偏高偏低的问题。

### 评价指标

常用指标：

- RMSE：预测评分误差。
- MAE：平均绝对评分误差。
- Top-K Precision / Recall：推荐列表质量。
- NDCG：排序质量。

课程实验里更关注预测评分是否合理，以及推荐出的电影是否符合用户偏好。

### 代码结构

```text
recommender/
├── data.py          # 评分矩阵、指示矩阵、均值归一化
├── model.py         # 用户向量和电影向量
├── train.py         # 优化协同过滤损失
├── recommend.py     # 为用户生成推荐列表
└── evaluate.py      # RMSE 和 Top-K 指标
```

### 实验主流程

1. 读取用户-电影评分矩阵。
2. 做均值归一化。
3. 初始化用户向量和电影向量。
4. 只在已有评分位置计算损失。
5. 使用梯度下降训练。
6. 为目标用户预测未评分电影。
7. 按预测评分排序，推荐 Top-K 电影。

这个实验的核心收获是：推荐系统不一定需要明确知道电影内容，也可以只根据“相似用户喜欢相似电影”的模式学习推荐。

# 三、深度学习实验

深度学习实验主要来自 `ml-吴恩达深度学习/` 和 `ml-LSTM用电负荷预测/`。这些实验覆盖图像、文本、音频、序列、强化学习和时间序列预测。

## 1. 猫分类器

### 任务

给定一张图片，判断它是不是一只猫。

这是二分类图像分类任务：

- `1`：是猫。
- `0`：不是猫。

### 框架

可以用 NumPy 从零实现逻辑回归或神经网络，也可以用 PyTorch 实现。

吴恩达课程中常用这个任务讲二元分类、向量化、逻辑回归、前向传播、反向传播和深层神经网络。

### 数据集特点

图片通常是 RGB 彩色图。

输入形状类似：

```text
num_px × num_px × 3
```

例如 64×64×3 的图片会被拉平成 12288 维向量。

数据集包括猫图片和非猫图片。样本数量通常不大，所以容易过拟合。

### 模型结构

基础版本是逻辑回归：

```text
图片 flatten
-> 线性变换
-> sigmoid
-> 猫/非猫概率
```

深层版本是多层神经网络：

```text
输入层
-> 若干隐藏层 ReLU
-> 输出层 sigmoid
```

如果使用 CNN，模型会更适合图像：

```text
Conv
-> ReLU
-> Pool
-> FC
-> Sigmoid
```

### 优化算法

损失函数：

- Binary Cross Entropy

优化算法：

- 梯度下降
- Adam

课程重点是手动实现前向传播、反向传播和参数更新。

### 评价指标

常用指标：

- Accuracy
- Precision
- Recall
- 错误样本分析

在猫分类器中，错误分析很重要。比如有些狗、大型猫科动物、模糊图片、遮挡图片容易被误判。

## 3. YOLO 目标检测

### 任务

给定一张图片和若干类别，识别图片中所有出现的目标物体，并输出它们的位置和边界框。

与图像分类不同，目标检测不仅要回答“有什么”，还要回答“在哪里”。

### 框架

可以使用 PyTorch 或 TensorFlow/Keras。吴恩达课程中重点讲 YOLO 的原理。

### 数据集特点

每张图像的标签不是单个类别，而是多个目标框。

每个目标包含：

- 类别。
- 边界框中心坐标。
- 边界框宽高。

标签格式通常类似：

```text
class_id, x_center, y_center, width, height
```

### 模型结构

YOLO 的核心思想是：

1. 把图像划分成网格。
2. 每个网格负责预测落在该网格中的目标。
3. 每个网格预测多个锚框。
4. 每个锚框输出目标置信度、边界框坐标和类别概率。

输出张量可以理解为：

```text
S × S × B × (5 + C)
```

其中：

- `S × S`：网格数量。
- `B`：每个网格预测的锚框数。
- `5`：目标置信度 + 4 个框参数。
- `C`：类别数。

### 优化算法

损失函数通常由几部分组成：

- 目标存在与否的置信度损失。
- 边界框定位损失。
- 类别分类损失。

训练使用 Adam 或 SGD。

推理阶段使用非极大值抑制 NMS，去掉重复框。

### 评价指标

常用指标：

- IoU：预测框和真实框的交并比。
- Precision / Recall。
- mAP：平均精度均值。
- 推理速度 FPS。

设备控制场景如果用于实时检测，还必须关注延迟。

### 代码结构

```text
yolo_detection/
├── dataset.py       # 图片和标注读取
├── model.py         # YOLO 模型
├── loss.py          # YOLO 损失
├── train.py
├── infer.py         # 推理和 NMS
└── evaluate.py      # IoU、mAP
```

### 实验主流程

1. 准备带边界框标注的数据。
2. 读取图像和目标框标签。
3. 将标签编码成 YOLO 输出格式。
4. 训练模型预测框和类别。
5. 推理时筛选高置信度框。
6. 使用 NMS 去重。
7. 计算 mAP 和检测速度。

这个实验的核心收获是：理解目标检测是分类和定位的结合，也理解 YOLO 为什么适合实时检测。

## 4. 人脸识别

### 任务

给定两张照片，判断是否为同一个人。

这是人脸验证任务，也可以扩展成人脸识别任务。

### 框架

可以使用 PyTorch 或 TensorFlow/Keras。

课程中重点是孪生网络、三元组损失和人脸嵌入。

### 数据集特点

数据由人脸图片组成，每张图片有身份标签。

训练时需要构造：

- Anchor：基准人脸。
- Positive：同一个人的另一张人脸。
- Negative：不同人的人脸。

### 模型结构

核心模型是人脸编码网络：

```text
人脸图片
-> CNN
-> embedding 向量
```

判断两张人脸是否同一人时，比较两个 embedding 的距离：

```text
距离小 -> 同一人
距离大 -> 不同人
```

### 优化算法

常用三元组损失：

```text
同一人的距离要小
不同人的距离要大
并且要大出一个 margin
```

也可以把两个人脸 embedding 的差异送入二分类器训练。

### 评价指标

常用指标：

- Verification Accuracy
- FAR：误接受率。
- FRR：误拒绝率。
- ROC-AUC。

人脸识别还要关注阈值选择，因为阈值决定安全性和便利性的平衡。

### 代码结构

```text
face_recognition/
├── dataset.py       # 人脸图片、身份标签、triplet 采样
├── model.py         # CNN embedding 网络
├── loss.py          # triplet loss
├── train.py
├── verify.py        # 两张人脸验证
└── evaluate.py      # ROC、阈值、准确率
```

### 实验主流程

1. 读取人脸图片。
2. 对齐和裁剪人脸。
3. 构造 anchor-positive-negative 三元组。
4. 训练 CNN 输出 embedding。
5. 用距离阈值判断是否同一人。
6. 调整阈值，评估 FAR 和 FRR。

这个实验的核心收获是：人脸识别不是普通分类，而是学习一种相似度度量。

## 5. 触发词检测

### 任务

给定一段连续音频，检测触发词出现的时刻。

例如检测“Hey Siri”或“OK Google”。

可以使用 Python、NumPy、Keras、TensorFlow 或 PyTorch。

### 数据集特点

数据是音频序列。

需要把原始音频转换成频谱特征，例如：

- Mel Spectrogram

标签是时间序列标签：

- 未出现触发词的位置为 0。

常见结构：

```text
音频频谱
-> Conv1D / GRU / LSTM
-> 每个时间步输出触发词概率
```

模型不是只输出一个标签，而是输出一串时间步概率。

### 优化算法

损失函数：

- Binary Cross Entropy

优化器：

- Adam

由于正样本少，可能需要：

- 对正样本加权。
- 扩大触发词后的正标签持续时间。
- 做数据增强，如混入噪声。

### 评价指标

常用指标：

- Precision
- Recall
- F1
- 检测延迟
- 误唤醒率
- 漏唤醒率

设备端部署时，低延迟和低功耗非常重要。

### 代码结构

```text
trigger_word/

├── train.py
├── detect.py        # 流式检测
└── evaluate.py      # 误唤醒、漏唤醒、延迟
```

### 实验主流程

1. 收集触发词音频和背景噪声。
2. 合成训练音频片段。
3. 标注触发词出现后的时间步。
4. 提取频谱特征。
5. 训练序列模型。
6. 在连续音频上滑动检测。
7. 评估误唤醒和漏唤醒。

这个实验的核心收获是：语音触发词检测是时间序列二分类问题，重点不是只分类整段音频，而是定位触发词出现的时间。

## 6. 英法翻译

### 任务

将法语句子翻译为英语句子。

这是序列到序列任务。

### 框架

可以使用 PyTorch 或 TensorFlow/Keras。

课程中重点包括 Seq2Seq、注意力机制、束搜索和 BLEU 分数。

### 数据集特点

数据由成对句子组成：

```text
法语句子 -> 英语句子
```

输入和输出长度不固定，需要分词、构建词表、padding。

### 模型结构

基础结构是 Encoder-Decoder：

```text
法语 token 序列
-> Encoder RNN/LSTM/GRU
-> 上下文向量
-> Decoder RNN/LSTM/GRU
-> 英语 token 序列
```

带注意力机制时，Decoder 每一步都会关注 Encoder 的不同时间步，而不是只依赖一个固定上下文向量。

现代版本可以使用 Transformer。

### 优化算法

损失函数：

- CrossEntropyLoss

优化器：

- Adam

训练时常使用 teacher forcing，也就是解码器输入真实前一个词，而不是模型自己预测的前一个词。

### 评价指标

常用指标：

- Token-level accuracy
- Perplexity
- BLEU 分数

BLEU 用 n-gram 重合度衡量机器翻译结果和参考翻译的接近程度。

### 代码结构

```text
translation/
├── preprocess.py    # 分词、词表、padding
├── dataset.py
├── model.py         # Encoder、Decoder、Attention
├── train.py
├── translate.py     # 推理和束搜索
└── evaluate.py      # BLEU
```

### 实验主流程

1. 读取法英平行语料。
2. 分词并建立词表。
3. 将句子编码成 token id。
4. 构建 Encoder-Decoder 模型。
5. 使用交叉熵训练。
6. 推理时用贪心搜索或束搜索生成翻译。
7. 用 BLEU 分数评价翻译质量。

这个实验的核心收获是：机器翻译不是简单分类，而是条件语言模型，需要逐步生成目标序列。

# 四、自动控制实验

自动控制实验主要来自 `ctrl-江协STM32/`、`ctrl-江协PID/`、`ctrl-MPC模型预测控制器/` 和 `ctrl-模糊控制/`。这些实验的共同特点是：有明确被控对象，有输入和输出，有反馈，有控制算法。

## 1. STM32 红外传感器计次

### 任务

使用对射式红外传感器，用挡片遮挡红外光路，实现计次。

每遮挡一次，系统计数加一。

### 工具链

软件平台：

- Keil5 MDK
- STM32 标准库或寄存器开发
- ST-Link 下载调试

代码语言：

- C

硬件：

- STM32F103 开发板。
- 对射式红外传感器。
- 挡片。
- OLED 或串口用于显示计数。

### 硬件结构

对射式红外模块由发射端和接收端组成。

当无遮挡时，接收端能收到红外光，输出一种电平。

当挡片遮挡时，接收端收不到红外光，输出电平变化。

STM32 将该信号接入 GPIO 或 EXTI 外部中断引脚。

### 代码结构

```text
infrared_counter/
├── main.c
├── delay.c / delay.h
├── exti.c / exti.h
├── oled.c / oled.h
└── infrared.c / infrared.h
```

### 主程序逻辑

```text
初始化系统时钟
初始化 OLED 或串口
初始化红外传感器 GPIO
初始化 EXTI 外部中断
while(1) {
    显示当前计数值
}
```

外部中断逻辑：

```text
检测到遮挡边沿
-> 进入中断服务函数
-> 判断中断标志
-> 计数加一
-> 清除中断标志
```

### 评价指标

主要看：

- 是否每次遮挡只计一次。
- 快速遮挡时是否漏计。
- 是否发生抖动导致重复计数。
- OLED 或串口显示是否实时。

### 实验重点

这个实验的重点是理解 GPIO 输入、EXTI 外部中断和事件计数。

轮询也能做计数，但中断更适合捕捉短暂变化。这个实验是后面编码器计数、电机测速和外部事件响应的基础。

## 2. PID 电机定速控制

### 任务

调节电机 PWM 占空比，实现电机定速旋转。

目标是：用户设置一个目标转速，电机稳定跟随目标转速。

### 工具链

软件：

- Keil5 MDK
- SerialPlot
- ST-Link

代码语言：

- C

硬件：

- STM32F103。
- 编码电机。
- TB6612 电机驱动模块。
- 编码器 A/B 相输入。
- 电位器或按键设置目标转速和 PID 参数。
- 串口输出曲线到 SerialPlot。

### 硬件结构

STM32 输出 PWM 到 TB6612，TB6612 驱动电机。

编码器输出 A/B 相脉冲，STM32 定时器编码器模式读取计数。

每个控制周期计算一次当前速度，再用 PI 控制器调整 PWM。

### 代码结构

```text
pid_speed/
├── main.c
├── pid.c / pid.h
├── motor.c / motor.h
├── encoder.c / encoder.h
├── timer.c / timer.h
├── adc.c / adc.h
└── serialplot.c / serialplot.h
```

### 主程序逻辑

```text
初始化 GPIO、PWM、编码器、定时器、ADC、串口
while(1) {
    读取旋钮或按键设置
    更新目标转速和 PI 参数
    等待定时器周期控制
}
```

定时器中断逻辑：

```text
读取编码器计数差
计算当前转速
error = target_speed - current_speed
output = PI(error)
限幅 output 到 PWM 范围
设置电机方向和 PWM 占空比
发送 target/current/output 到 SerialPlot
```

### 控制算法

定速控制一般使用 PI：

- P 项负责快速响应。
- I 项负责消除稳态误差。
- D 项通常不需要，因为速度信号容易有噪声，且定速控制的震荡不像位置控制那么明显。

### 评价指标

主要看：

- 稳态误差。
- 上升时间。
- 超调量。
- 速度波动。
- 对目标变化的跟随能力。
- 对负载扰动的恢复能力。

### 实验重点

这个实验的重点是形成电机速度闭环：

```text
目标转速 -> PI -> PWM -> 电机 -> 编码器反馈 -> 当前转速
```

它是后续定位控制、倒立摆和运动控制的基础。

## 3. PID 电机定位控制

### 任务

调节电机 PWM 占空比，实现电机定位。

目标是：让电机转到指定角度并停住。

### 工具链

同定速控制：

- Keil5 MDK
- STM32
- TB6612
- 编码器
- SerialPlot

### 硬件结构

硬件和定速控制类似，但被控量从速度变成位置。

位置由编码器累计计数得到：

```text
累计脉冲数 -> 角度
```

### 代码结构

```text
pid_position/
├── main.c
├── pid.c / pid.h
├── motor.c / motor.h
├── encoder.c / encoder.h
├── timer.c / timer.h
├── adc.c / adc.h
└── serialplot.c / serialplot.h
```

### 主程序逻辑

```text
初始化电机、编码器、PWM、定时器、串口
设置当前位置为零点
while(1) {
    读取目标角度
    显示目标和当前位置
}
```

定时器中断逻辑：

```text
读取编码器累计计数
换算当前位置角度
error = target_position - current_position
output = PID(error)
限幅 output
设置电机方向和 PWM
发送波形到 SerialPlot
```

### 控制算法

定位控制通常需要 PID。

- P：让电机朝目标位置运动。
- D：抑制冲过目标后的震荡。
- I：消除最后的定位偏差。

调参顺序通常是：

```text
先 P
再 D
最后 I
```

### 评价指标

主要看：

- 定位误差。
- 超调角度。
- 调节时间。
- 稳定后抖动幅度。
- 重复定位精度。

### 实验重点

定速控制关心“转多快”，定位控制关心“停在哪里”。

由于电机有惯性，位置控制更容易冲过目标，所以 D 项比定速控制更重要。

## 4. 双环 PID 倒立摆实验

### 任务

调节电机 PWM 占空比，实现倒立摆直立不倒，并尽量保持支点运动可控。

### 工具链

软件：

- Keil5 MDK
- SerialPlot
- ST-Link

代码语言：

- C

硬件：

- STM32。
- 减速电机。
- 编码器。
- TB6612 电机驱动。
- MPU6050 姿态传感器。
- 导电滑环。
- 倒立摆机械结构。

### 硬件结构

倒立摆的摆杆可以绕支点旋转。

MPU6050 测量摆杆角度。

电机控制支点水平移动。

编码器测量电机或支点速度。

控制器根据角度和速度输出 PWM，让支点移动去“接住”摆杆。

### 代码结构

```text
inverted_pendulum/
├── main.c
├── pid.c / pid.h
├── motor.c / motor.h
├── encoder.c / encoder.h
├── mpu6050.c / mpu6050.h
├── timer.c / timer.h
└── serialplot.c / serialplot.h
```

### 主程序逻辑

```text
初始化电机、编码器、MPU6050、定时器、串口
校准角度零点
while(1) {
    处理模式切换
    显示角度、速度、输出
}
```

控制中断逻辑：

```text
读取当前角度
读取当前速度
角度误差 = 目标角度 - 当前角度
角度环 PID 输出目标速度
速度误差 = 目标速度 - 当前速度
速度环 PID 输出 PWM
限幅并驱动电机
```

### 控制算法

倒立摆使用双环 PID：

```text
角度环 -> 目标速度
速度环 -> PWM
```

角度环常用 PD：

- P 让摆杆回到直立。
- D 抑制角度变化速度，提前“刹车”。

速度环常用 PI：

- 让支点速度跟随角度环给出的速度目标。

### 评价指标

主要看：

- 直立保持时间。
- 抗扰动恢复能力。
- 摆杆角度波动范围。
- 支点漂移距离。
- 是否出现高频抖动。
- 自动启摆是否成功。

### 实验重点

这个实验比普通电机 PID 更难，因为倒立摆本身是不稳定系统。控制器必须持续快速响应，否则摆杆会倒下。

它综合了传感器读取、滤波、双环控制、PWM 输出和实时调参，是设备控制中非常典型的综合实验。

## 5. MPC 机械臂控制仿真

### 任务

控制机械臂执行动作。

personal 中写的是机械臂控制仿真。结合 MPC 课程，可以把它理解为：用模型预测控制让机械臂在约束下跟踪目标轨迹。

### 工具链

软件平台：

- Python / MATLAB / Octave
- NumPy
- 优化求解器
- 可视化工具

代码语言：

- Python、MATLAB 或 Octave

框架：

- MPC 建模与 QP 求解

### 被控对象

机械臂可以抽象为一个多关节系统。

状态可能包括：

- 关节角度。
- 关节角速度。

控制输入可能是：

- 关节力矩。
- 关节速度指令。
- 关节位置增量。

输出可能是：

- 末端执行器位置。
- 关节角度。

### 代码结构

```text
mpc_arm/
├── model.py         # 机械臂动力学/离散状态空间模型
├── mpc.py           # 预测矩阵、代价函数、约束
├── solver.py        # QP 求解器接口
├── simulate.py      # 滚动仿真
└── plot.py          # 轨迹和控制量可视化
```

### 主程序逻辑

```text
初始化机械臂状态
设置目标轨迹
for 每个采样时刻:
    读取当前状态
    用模型预测未来 N 步
    构造代价函数
    构造输入/状态/输出约束
    求解最优控制序列
    执行第一个控制量
    更新仿真状态
    记录轨迹和控制量
```

### 控制算法

MPC 的核心是：

```text
预测未来
-> 优化一串控制量
-> 只执行第一步
-> 下一时刻重新预测和优化
```

代价函数通常包含：

- 轨迹跟踪误差。
- 控制输入大小。
- 控制变化率。

约束包括：

- 关节角度范围。
- 关节速度限制。
- 力矩限制。
- 末端位置安全范围。

### 评价指标

主要看：

- 轨迹跟踪误差。
- 是否违反约束。
- 控制输入是否平滑。
- 到达目标所需时间。
- 仿真稳定性。

### 实验重点

这个实验的重点是理解 MPC 和 PID 的区别。

PID 只根据当前误差调节，MPC 会根据模型预测未来，并把约束写进优化问题。这使 MPC 更适合机械臂、车辆、无人机等多变量、有约束的系统。

## 6. 模糊控制洗衣机

### 任务

根据一些条件，自动控制洗衣机的洗衣时长。

这是模糊控制实验。它不依赖精确数学模型，而是把人的经验规则写成模糊控制器。

### 工具链

可以使用：

- Python / MATLAB
- 模糊控制工具箱
- 手写隶属函数和规则推理

代码语言：

- Python 或 MATLAB

### 输入输出

输入可以包括：

- 衣物重量。
- 污浊程度。
- 水浑浊程度。
- 油污程度。

输出可以是：

- 洗涤时间。
- 水流强度。
- 漂洗次数。

personal 中重点是控制洗衣时长。

### 模型结构

模糊控制器包括：

```text
输入清晰值
-> 模糊化
-> 模糊规则推理
-> 输出模糊集合
-> 清晰化
-> 洗衣时长
```

### 设计步骤

1. 确定模糊控制器结构。
2. 定义输入和输出变量。
3. 为每个变量设计隶属函数。
4. 建立模糊规则。
5. 使用 Mamdani 等方法做模糊推理。
6. 清晰化输出控制值。

例如规则可以写成：

```text
如果衣物很多 且 污浊程度高，则洗衣时间长
如果衣物较少 且 污浊程度低，则洗衣时间短
```

### 评价指标

主要看：

- 洗衣时间是否符合直觉。
- 不同输入变化时输出是否平滑。
- 极端输入下是否安全。
- 规则是否覆盖常见情况。
- 是否出现不合理跳变。

### 代码结构

```text
fuzzy_washer/
├── membership.py    # 隶属函数
├── rules.py         # 模糊规则
├── inference.py     # 模糊推理
├── defuzzify.py     # 清晰化
└── demo.py          # 输入样例和输出曲线
```

### 实验重点

模糊控制适合模型难以精确建立，但人类经验比较清楚的系统。

洗衣机不是严格按一个公式决定洗多久，而是根据衣物多少、脏污程度等经验条件做近似判断。模糊控制把这种经验规则变成可计算的控制器。

# 五、项目整体总结

这份项目实验内容可以理解为一条从“数据学习”到“设备控制”的路线。

机器学习实验让人理解基础模型如何从结构化数据和评分数据中学习规律。房价预测训练回归能力，肿瘤分类训练二分类能力，图像分类和手写数字识别训练多分类能力，猫狗分类训练决策树，推荐系统训练协同过滤思想。

深度学习实验把数据类型扩展到图像、文本、音频、序列和强化学习环境。猫分类器、YOLO、人脸识别对应视觉感知；垃圾邮件和英法翻译对应文本理解；触发词检测对应音频时序；月球着陆器对应连续决策；用电负荷预测对应设备时序预测。

自动控制实验把模型和算法落回真实或仿真的控制对象。红外计次训练外部中断和传感器输入；PID 定速和定位训练反馈控制；倒立摆训练双环控制和实时系统；MPC 机械臂仿真训练约束优化控制；模糊洗衣机训练经验规则控制。

放在设备控制方向看，最终目标是：

1. 能采集数据。
2. 能训练模型。
3. 能评价模型。
4. 能读取传感器。
5. 能控制执行器。
6. 能用反馈稳定系统。
7. 能把智能感知、预测和控制算法组合成完整设备项目。

这正是设备控制项目从软件、算法到硬件闭环的完整实验链路。
