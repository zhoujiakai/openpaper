# 控制理论

Dr_CAN 的advanced控制理论主要讲了状态空间的基础，包括什么是状态空间，以及如何求解状态空间方程的解。课程中提到了矩阵指数函数，主要内容就是这些。课程总时长为25分钟。



# PID

这门课程主要讲解了PID的基本原理。离散型PID又分为增量式PID和位置式PID。课程还介绍了基本驱动代码的编写、编码电机的原理以及SiriPlot的使用。最后，使用PID进行了两个实验：电机定速控制电机定位控制。

PWM调速原理以数千至数万赫兹频率交替供电，通过调节占空比实现电机转速控制。开发流程包含编写定时器驱动、外部中断驱动、编码器驱动、电机驱动等底层模块。核心控制算法采用PID控制器，根据编码器反馈的转速和转向数据，通过比例-积分-微分运算输出PWM占空比，实现电机定速或定位控制。



# MPC

MPC模型预测控制器部分讲解了最优化控制和MPC的基本概念，并对最优化的数学建模进行了推导。最后，使用一个详细的建模例子，给出了MPC的代码模板，并用Octave代码实现了模型预测控制。



# 拉普拉斯变换

拉普拉斯变换的讲解视频采用物理方法讲解欧拉公式，介绍了拉普拉斯变换的原理，并通过直观的可视化画面展示了拉普拉斯变换为什么会生效，增强了直觉理解。



# 模糊控制
