# 卡尔曼滤波器



卡尔曼滤波器

卡尔曼滤波器是最优状态估计的核心工具，从带噪声观测中递归给出系统状态最优估计，与MPC或LQR共享Riccati数学结构。内容包括递归算法思想、数学基础（数据融合、协方差矩阵、状态空间方程）、卡尔曼增益推导、误差协方差矩阵和五个核心公式的完整推导，以及扩展到非线性系统的扩展卡尔曼滤波器。


# 自动控制原理

自动控制原理

自动控制原理是自动化、电气工程等专业的核心课程，研究如何构建和分析控制系统使被控对象按期望规律运行。课程内容从数学模型建立到时域分析、根轨迹法，再到离散系统和非线性系统，覆盖自动控制理论的完整知识体系。控制系统数学模型部分包括传递函数、结构图和信号流图。时域分析法涵盖一阶、二阶系统动态性能、稳定性判据和稳态误差。根轨迹法包括基本法则、广义根轨迹和系统性能分析。频域分析法涉及频率特性、Nyquist判据、稳定裕度和系统校正。离散系统部分包括Z变换、离散数学模型、稳定性与动态性能。非线性系统部分介绍相平面法和描述函数法。
