# C

C语言在嵌入式开发中的核心地位

C语言是嵌入式系统开发和高性能计算的基石，Python解释器CPython本身采用C编写。掌握C语言的关键在于理解内存管理机制，而非单纯学习语法。从Python开发者视角切入，需重点关注C与Python在编译流程、运行时环境等方面的本质差异。嵌入式领域受资源限制必须依赖C语言，需要全面掌握从源代码编译到链接的完整工具链运作原理。这种底层知识有助于理解高级语言抽象背后的实现机制，特别是在内存分配、指针操作等系统级编程方面。

C语言核心概念与嵌入式开发基础

预处理阶段是编译过程的第一步，通过预处理指令处理源代码。汇编和链接过程解释了信息文件如何转换为可执行文件，与Python的解释执行有本质区别。指针和动态内存管理涉及星号和end符号的双重角色，包括值传递、堆与栈的分工，这是C语言的重要分水岭。数组与字符串部分讨论了数组的字符串表示，数组退化的规则，sizeof的陷阱，以及字符串以空字符结尾的底层逻辑与缓冲区溢出问题。结构体、函数指针与位运算部分涵盖内存对齐、回调机制和嵌入式寄存器操作。宏、编译链接与常见陷阱部分包括文本替换的括号规则、多文件编译和未定义行为的快速检查方法。

# C++

C++在嵌入式自动控制领域的应用

C++是嵌入式自动控制领域不可或缺的语言，从C嵌入式经验出发，C++提供的模板、RAII、多态等特性可以在保持零开销抽象的同时提升代码的可维护性和安全性。掌握C++需要理解编译器自动生成的内容以及如何在资源受限环境下安全使用这些抽象。内容涵盖从C到C++的平滑过渡，聚焦嵌入式自动控制场景的核心特性，包括引用、函数重载和命名空间等基础语法升级。类封装部分涉及硬件外设的C++封装模式，构造函数管理资源生命周期，继承与多态包括虚函数表和虚析构函数。模板与编译器编程部分实现零开销的控制算法泛化，如PID滤波器和谐波限制器。STL容器在嵌入式系统中的取舍也是重要内容。

# PyTorch

PyTorch深度学习框架的核心特性

PyTorch是当前深度学习研究与工业应用的主流框架，其核心设计哲学是"define by run"，即编写的代码就是运行时真实执行的代码，这使得调试直观，可以在forward函数中直接打印，也便于自定义网络层和实验性框架的搭建。掌握PyTorch不仅是学习API，还需要理解自动微分引擎如何追踪计算、GPU并行计算如何编排，以及从张量运算到完整训练管线的全链路能力。内容从张量基础到模型工程最佳实践，覆盖深度学习开发所需的完整工具链，包括张量创建、运算、设备迁移，自动微分引擎工作原理与计算图管理。网络搭建部分涵盖从全连接到Transformer的参数注册机制、子模块递归管理和自定义层。训练循环部分包括数据管道、损失函数选择、优化器配置和验证测试方法。GPU加速与分布式训练涉及CUDA、MPS设备管理和混合精度训练。模型部署部分包括状态字典保存加载和ONNX导出。
