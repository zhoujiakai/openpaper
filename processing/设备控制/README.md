## 概述

这个岗位的技术对标到研究生方向就是做控制的专业。

就是**控制科学与工程**这个一级学科底下的二级学科：**模式识别与智能系统**。（codex：需要引用中国的国家官方的学科划分标准）。

岗位一般叫做算法工程师，岗位一般会提到 PID、MPC、PHM、工业算法等关键词。

技术上包含 3 个部分：编程、机器学习、自动控制。

- 编程：掌握 C、C++、Python。C 涉及一些设备驱动，C++ 涉及一些业务实现和部署，Python涉及一些机器学习模型的仿真、训练和可视化。

- 机器学习：掌握 LSTM。
- 自动控制：需要了解嵌入式的项目周期，还需要了解预测模型和控制算法，主要是 3 个类型：PID、MPC、模糊控制。还需要了解 PHM 的项目周期。

设备控制主题，把所有会的内容讲一遍，会讲 3 个小时。



## 难度

主要是 3 个网课：

- 吴恩达《机器学习》20 小时。
- 吴恩达《深度学习》30 小时。
- 卢京潮《自动控制原理》58 小时。

主要是 2 本教材：

- 周志华《机器学习》62.6 万字。
- 胡寿松《自动控制原理（第八版）》99.9 万字。

> 自动控制原理学习之前，可以选择先学习下信号与系统。
>
> 可以先补齐一些数学基础：微积分、线性代数、概率论与数理统计、PCA主成分分析；微分方程、状态空间、稳定性分析。
