现在我来讲一下设备控制这四个模块的内容：

1. 编程
2. 机器学习
3. 自动控制
4. 项目



# 编程

这一块主要涉及几种不同的场景：

1. C 语言：用于驱动层
2. C++：用于业务层
3. PyTorch：用于模型的实现、验证以及可视化

主要就是这三种语言。

先说 C 语言的吧，C 语言我比较熟。

C 语言的话，我主要知道这些：
1. 指针
2. 宏定义
3. 类型定义
4. 结构体

我就知道这些。

然后再说 C++。

C++ 加入了类的概念，所以我可以用它去写一些传感器，并封装成类。

此外还有一些注意事项：比如可能需要关掉异常处理。我就知道这些。

PyTorch 的话，它有一个 Dense 类或者 Linear 层可以用来定义每一层。

它支持自动求导（AutoGrad）。在编程和接口使用上有一些注意事项，比如 eval 模式、AutoGrad 的设置，以及 zero_grad（梯度清零）等，这些都需要设置一下。目前我就知道这两个。

对了，编程这一块需要知道一些嵌入式的概念。比如 STM32 嵌入式项目开发的流程：

1. 从阅读硬件手册开始，了解硬件的机理
2. 编写或封装驱动程序
3. 组合不同的传感器去实现主程序的业务流程

这就是一个典型的嵌入式项目开发流程和周期。

此外还需要用到一些软件，主要是：
1. Keil MDK：用来开发 STM32 平台的 IDE
2. SerialPlot：用来显示波形



# 机器学习

再说一下机器学习的内容。机器学习分为两个课程：一个是机器学习，一个是深度学习。

1. 机器学习部分
   主要是学习机器学习项目的一些故障诊断，以及基础的机器学习算法，包括有监督和无监督学习：
   (a) 有监督学习：讲了线性回归和逻辑回归。
   (b) 无监督学习：讲了强化学习，其中包含一个“月球着陆器”的动手编程实验。
   (c) 传统算法：比如决策树、K-means 聚类等。
   (d) 基础理论：讲了激活函数、前向传播和反向传播的原理，帮助建立起一些直觉。

2. 深度学习部分
   除了浅层神经网络，还讲了深层神经网络，并介绍了各种任务：
   (a) 视觉与识别：目标检测、人脸识别。
   (b) 行业应用：推荐系统（如电影推荐系统）、故障检测。
   (c) 移动端优化：介绍了高效移动网络等旨在降低移动端计算成本的网络架构。

大概就是这些，这就是我直播的全部内容了。

对了，机器学习部分还有一项内容：因为我们经常需要处理传感器的时序数据，所以还需要加入一个关于 LSTM 用电负荷预测的实验。

# 自动控制

接着自动控制这一块，我们需要了解以下几个部分：

1. 控制算法
   (a) 经典的 PID 算法
   (b) MPC（模型预测控制）

2. 自动控制原理的相关概念
   (a) 状态空间、时域空间等概念
   (b) 拉普拉斯变换（因为状态方程的编写都是基于拉普拉斯变换的）

简单来说，大概需要知道这些内容



# 项目

这一部分，前面三个模块每个模块都有各自的项目，我们一个一个来说。

比如编程这一块，会有 STM32 相关的项目：
1. 用对射式红外传感器去计次的实验
2. 电机的定位控制和定速控制实验
3. 双环 PID 的倒立摆实验

对于机器学习这个模块，我们也有相关的实验。具体包括：

1. 机器学习实验
   (a) 线性回归：房价预测
   (b) 逻辑回归：肿瘤分类
   (c) 推荐系统：协同过滤
   (d) 故障检测：K-means 聚类算法
   (e) 强化学习：火星探测器、月球登陆器实验

2. 深度学习实验（或项目）
   (a) 深层网络：YOLO、人脸识别
   (b) LSTM 内容：英法翻译、触发词检测

3. 自动控制实验
   (a) 电机控制：电机定位控制、电机定速控制（利用 PID 实现）
   (b) 倒立摆实验：双环 PID 控制倒立摆
