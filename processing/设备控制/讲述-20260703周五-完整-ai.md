# 一、总体框架

设备控制可以理解成一个由“软件、数据、控制、实验”组成的综合方向。

四个核心模块是：

1. 编程：把程序真正运行在设备上，完成传感器读取、外设驱动、通信、执行器控制和主流程组织。
2. 机器学习：让系统从数据中学习规律，完成识别、预测、分类、异常检测、推荐和决策。
3. 自动控制：让设备根据反馈稳定、准确、快速地达到目标。
4. 项目：把编程、机器学习和自动控制放进真实或仿真的实验中验证。

可以用一个闭环来理解设备控制：

```text
传感器采集状态
-> 程序读取和处理数据
-> 模型识别、预测或判断
-> 控制算法计算控制量
-> 执行器产生动作
-> 系统状态改变
-> 传感器再次反馈
```

其中：

```text
编程解决“怎么实现”
机器学习解决“怎么从数据中学习”
自动控制解决“怎么稳定达到目标”
项目解决“怎么组合成完整系统”
```

# 二、编程模块

编程模块是设备控制的底座。没有编程，算法无法运行，传感器无法读取，执行器无法控制，模型也无法接入系统。

编程部分主要包括四条线：

1. C 语言：底层驱动和嵌入式基础。
2. STM32：真实单片机平台和外设控制。
3. C++：设备抽象、业务组织和工程结构。
4. PyTorch：机器学习模型实现、训练、验证和部署前准备。

## 1. C 语言

C 语言适合设备端开发，因为它贴近硬件、运行开销低、能直接处理内存和寄存器。

在设备控制中，C 语言主要用于：

1. 写外设驱动。
2. 操作 GPIO、定时器、ADC、DMA、串口、I2C、SPI 等硬件模块。
3. 读写传感器数据。
4. 输出 PWM 控制电机或其他执行器。
5. 处理中断和实时任务。
6. 组织嵌入式主程序。

需要掌握的核心知识包括：

1. 编译流程：`.c` 文件经过预处理、编译、汇编、链接，最后生成可执行程序或固件。
2. 类型系统：理解整型、浮点型、无符号数、`const`、`volatile` 等。
3. 指针：理解地址、解引用、数组传参、结构体指针和硬件寄存器访问。
4. 数组和字符串：用于采样缓存、串口缓冲区、协议数据包和显示缓存。
5. 动态内存：理解堆和栈，但嵌入式里通常谨慎使用动态分配。
6. 结构体：把传感器、电机、通信包、控制器状态组织成一个整体。
7. 函数指针：用于回调、状态机、中断处理和命令分发。
8. 位运算：用于设置、清除、翻转和读取寄存器位。
9. 宏和预处理：用于常量、条件编译、平台适配和调试开关。
10. 多文件工程：通过 `.h` 声明接口，通过 `.c` 实现功能，最后链接成完整程序。

C 语言在设备控制中的关键直觉是：

```text
硬件寄存器可以看成固定地址上的内存；
控制硬件，本质上就是按规则读写这些地址上的位。
```

## 2. STM32

STM32 是常见的嵌入式平台，它把 C 语言和真实硬件连接起来。

STM32 学习内容可以按外设展开：

1. GPIO：控制高低电平，驱动 LED、按键、继电器等。
2. OLED：显示调试信息和系统状态。
3. EXTI：处理外部中断，比如按键、传感器触发信号。
4. TIM 定时器：实现定时任务、PWM 输出、输入捕获、编码器测速。
5. ADC：读取模拟量，比如电压、温度、光照、传感器信号。
6. DMA：让数据搬运不占用太多 CPU。
7. USART：串口通信，用于调试、上位机交互和数据输出。
8. I2C：连接低速传感器和外设。
9. SPI：连接高速外设，如显示屏、Flash、部分传感器。
10. RTC、PWR、WDG、Flash：用于时间、电源、看门狗和非易失存储。

典型 STM32 项目流程是：

```text
阅读硬件手册
-> 搭建 Keil MDK 等开发环境
-> 建立工程
-> 配置时钟和外设
-> 编写驱动
-> 编写主程序
-> 下载到开发板
-> 用串口、OLED、SerialPlot 等工具调试
```

STM32 的意义是让设备控制不只是“算法”，而是落到真实的引脚、电机、传感器和通信接口上。

## 3. C++

C++ 在设备控制中的主要作用是改善工程组织。

C 语言适合贴近硬件，但当系统变复杂后，如果所有逻辑都写成函数和全局变量，代码会变得难维护。C++ 可以用类和对象把设备抽象出来。

例如：

```text
Motor 类：封装电机 PWM、方向和速度接口
Encoder 类：封装编码器计数和测速
PID 类：封装控制参数和计算过程
Sensor 类：封装传感器初始化和读取
System 类：组织整个设备主流程
```

C++ 重点知识包括：

1. 引用、函数重载、命名空间。
2. 类和对象。
3. 构造函数、析构函数和 RAII。
4. 拷贝控制和移动语义。
5. 继承和多态。
6. 模板，用于泛型算法和固定尺寸控制器。
7. `constexpr`、`enum class`、`std::array` 等现代 C++ 特性。
8. STL、智能指针和嵌入式资源限制之间的取舍。

在嵌入式环境中使用 C++ 要注意：

1. 谨慎使用动态内存。
2. 有些项目会关闭异常。
3. 注意虚函数、RTTI、模板实例化带来的体积开销。
4. 保证启动流程、链接脚本和运行时支持正确。

C++ 的核心价值可以概括为：

```text
用接近硬件的性能，组织更清晰、更可维护的设备控制工程。
```

## 4. PyTorch

PyTorch 是机器学习和深度学习模型实现的重要工具。

它在设备控制中的位置通常不是直接控制底层硬件，而是用于：

1. 训练故障检测模型。
2. 训练图像识别模型。
3. 训练传感器时序预测模型。
4. 验证模型效果。
5. 保存模型并为部署做准备。

核心概念包括：

1. Tensor：保存数据和参数。
2. Autograd：自动求导，构建计算图并反向传播。
3. `nn.Module`：定义神经网络模型。
4. 损失函数：衡量预测和真实结果的差距。
5. 优化器：根据梯度更新参数，比如 SGD、Adam。
6. Dataset 和 DataLoader：管理数据集和批量加载。
7. 训练循环和验证循环：包括前向传播、计算损失、反向传播、清空梯度和更新参数。
8. 设备管理：CPU、GPU、MPS。
9. 模型保存、加载和 checkpoint。
10. 模型导出：为 ONNX、TorchScript、TensorRT 或边缘部署做准备。

PyTorch 训练时常见注意点：

1. 每轮更新前调用 `zero_grad()`。
2. 训练时使用 `model.train()`。
3. 验证和推理时使用 `model.eval()`。
4. 推理阶段通常配合 `torch.no_grad()`。
5. 训练集、验证集、测试集要区分清楚。

PyTorch 在设备控制中的典型流程是：

```text
采集设备数据
-> 清洗和标注数据
-> 构建 Dataset
-> 定义模型
-> 训练和验证
-> 保存模型
-> 转换或部署
-> 接入设备控制系统
```

## 5. 完整嵌入式项目周期

一个完整嵌入式项目通常包括：

1. 明确需求：设备要测什么、控什么、达到什么指标。
2. 阅读硬件资料：芯片手册、传感器手册、电机驱动手册。
3. 硬件连接：确认电源、引脚、通信接口和执行器。
4. 驱动开发：让每个外设单独工作。
5. 模块封装：把传感器、执行器和控制算法整理成模块。
6. 主程序集成：用状态机或任务循环组织系统逻辑。
7. 调试观测：串口输出、OLED 显示、SerialPlot 波形。
8. 参数调优：采样周期、滤波参数、PID 参数等。
9. 稳定性测试：异常输入、长时间运行、掉电恢复和看门狗。
10. 文档整理：记录接口、参数、问题和调试结论。

# 三、机器学习模块

机器学习模块回答的问题是：怎样让系统从数据中学习规律。

在传统程序里，人写规则，设备执行规则。机器学习则是给模型数据，让模型学习输入和输出之间的关系。

设备控制中常见的机器学习任务包括：

1. 预测：预测负荷、能耗、温度、寿命、未来状态。
2. 分类：判断设备是否故障、图像属于哪一类、状态属于哪种工况。
3. 聚类：在没有标签时发现不同运行模式。
4. 异常检测：发现偏离正常状态的数据。
5. 推荐：推荐参数、工况策略或维护方案。
6. 强化学习：通过状态、动作和奖励学习决策策略。

## 1. 监督学习

监督学习的训练数据包含输入和标准答案。

典型任务：

1. 线性回归：预测连续值。
2. 逻辑回归：做二分类。
3. 多分类模型：从多个类别中选择一个。

线性回归的形式是：

```text
f(x) = wx + b
```

它通过代价函数衡量预测值和真实值的差距，再用梯度下降更新参数。

多特征线性回归可以写成：

```text
f(x) = w1x1 + w2x2 + ... + wnxn + b
```

它适合预测设备负载、能耗、温度等连续量。

逻辑回归用于分类。它先计算线性结果，再通过 sigmoid 函数输出概率。常用于：

1. 判断设备是否异常。
2. 判断肿瘤良恶性。
3. 判断样本是否属于某一类。

监督学习的重要概念包括：

1. 代价函数。
2. 梯度下降。
3. 学习率。
4. 特征缩放。
5. 训练集、验证集、测试集。
6. 过拟合和欠拟合。
7. 正则化。

基本训练闭环是：

```text
预测 -> 计算误差 -> 计算梯度 -> 更新参数 -> 再预测
```

## 2. 高级学习算法

高级学习算法包括神经网络、模型评估、决策树和集成学习。

神经网络由多层神经元组成。每一层通常包括：

```text
线性变换 -> 激活函数
```

前向传播负责从输入算出输出，反向传播负责根据误差更新参数。

激活函数让神经网络具备非线性表达能力。常见激活函数包括：

1. Sigmoid：常用于二分类输出。
2. ReLU：常用于隐藏层。
3. Softmax：常用于多分类输出。

模型评估关注模型到底哪里不好：

1. 偏差高：模型太简单，训练集表现也不好。
2. 方差高：模型过拟合，训练集好但验证集差。
3. 数据倾斜：某一类样本太少，准确率容易误导。
4. 精确率和召回率：尤其适合故障检测、医疗分类等任务。

决策树通过一系列特征判断完成分类或回归。关键概念包括：

1. 信息增益。
2. 纯度。
3. 独热编码。
4. 随机森林。
5. XGBoost。

在设备控制中，树模型很适合处理结构化表格数据，例如设备运行记录、传感器统计特征、维护记录和报警日志。

## 3. 无监督学习、推荐系统和强化学习

无监督学习没有明确标签，目标是从数据中发现结构。

K-means 聚类的流程是：

```text
选择聚类中心
-> 分配样本到最近中心
-> 更新中心
-> 重复直到稳定
```

它可以用于发现不同工况，例如低负载、中负载、高负载、异常振动等。

异常检测用于学习正常数据的分布，再发现偏离正常模式的数据。它适合设备故障预警，因为故障样本通常少且难以完整收集。

推荐系统包括：

1. 协同过滤：根据用户和物品历史互动学习隐含特征。
2. 基于内容的推荐：根据对象特征和偏好做推荐。
3. 均值归一化：处理评分偏移。

放在设备控制中，推荐系统思想可以迁移到：

1. 参数推荐。
2. 工况匹配。
3. 维护方案推荐。
4. 控制策略选择。

强化学习通过试错学习策略。核心概念包括：

1. 状态。
2. 动作。
3. 奖励。
4. 策略。
5. 状态价值函数。
6. 动作价值函数。

典型实验包括月球着陆器和火星探测器。强化学习和控制问题很接近，因为两者都关心在当前状态下选择什么动作，才能让系统长期表现更好。

## 4. 深度学习

深度学习使用多层神经网络学习复杂数据中的特征。

第一部分是基础神经网络：

1. 输入层、隐藏层、输出层。
2. 前向传播和反向传播。
3. 向量化计算。
4. 激活函数。
5. 损失函数。
6. 参数初始化。

第二部分是训练优化：

1. 训练集、开发集、测试集划分。
2. 偏差和方差分析。
3. 正则化。
4. Dropout。
5. Batch Normalization。
6. Mini-batch 梯度下降。
7. Momentum、RMSProp、Adam。
8. 学习率调节。

第三部分是结构化机器学习项目：

1. 明确评价指标。
2. 建立基准。
3. 做误差分析。
4. 处理数据分布不一致。
5. 迭代改进数据、模型和训练策略。

第四部分是卷积神经网络。CNN 适合视觉任务，包括：

1. 图像分类。
2. 目标检测。
3. 人脸识别。
4. 工业质检。
5. 道路、物体、零件识别。

重要结构包括：

1. 卷积层。
2. 池化层。
3. 全连接层。
4. 残差网络。
5. YOLO。
6. Siamese 网络。

第五部分是序列模型。序列模型适合处理时间、语言和声音：

1. RNN。
2. GRU。
3. LSTM。
4. Attention。
5. Transformer。

典型任务包括：

1. 语音识别。
2. 触发词检测。
3. 机器翻译。
4. 传感器时序预测。
5. 用电负荷预测。

## 5. 机器学习放回设备控制

机器学习在设备控制中主要承担四种角色：

1. 感知：从图像、声音、传感器中识别目标、状态或异常。
2. 预测：预测未来负荷、寿命、温度、故障趋势。
3. 决策：根据状态选择动作或策略。
4. 评估：判断模型是否可靠，是否能在真实环境中泛化。

完整落地流程是：

```text
采集设备数据
-> 清洗和标注
-> 选择任务类型
-> 训练模型
-> 验证效果
-> 部署到系统
-> 在线监控和迭代
```

# 四、自动控制模块

自动控制回答的问题是：设备如何根据反馈稳定地达到目标。

控制系统的基本闭环是：

```text
目标值 -> 控制器 -> 执行器 -> 被控对象 -> 传感器反馈 -> 与目标比较 -> 再控制
```

自动控制的核心不是让设备“动一下”，而是让设备在扰动、误差和不确定性存在时，仍然能稳定、准确地完成任务。

## 1. 控制理论基础

控制系统通常包括：

1. 目标值。
2. 控制器。
3. 执行器。
4. 被控对象。
5. 传感器。
6. 反馈通道。

状态空间是现代控制的重要表达方式：

```text
x' = Ax + Bu
y  = Cx + Du
```

其中：

1. `x` 是状态。
2. `u` 是输入。
3. `y` 是输出。
4. `A` 描述系统自身动态。
5. `B` 描述输入怎样影响状态。
6. `C` 描述状态怎样变成输出。
7. `D` 描述输入是否直接影响输出。

状态空间的意义是：不只看输入和输出，还看系统内部状态。

常见概念包括：

1. 相图：观察系统状态轨迹。
2. 离散化：把连续系统变成单片机可计算的离散系统。
3. 可控性：判断输入能不能影响所有关键状态。
4. 可观测性：判断输出能不能反推出内部状态。
5. 稳定性：判断扰动后系统是否回到平衡点附近。
6. LQR：在误差和控制代价之间折中求最优反馈。
7. 观测器：估计无法直接测量的状态。

## 2. 拉普拉斯变换

拉普拉斯变换是经典控制中的重要数学工具。

它的作用是把微分方程转换成代数方程，让系统分析更容易。

在控制系统中，它常用于：

1. 建立传递函数。
2. 分析极点和零点。
3. 判断系统稳定性。
4. 理解超调、振荡、衰减和响应速度。
5. 设计或分析控制器。

直观地说，很多系统响应都可以看成指数、衰减和振荡的组合。拉普拉斯变换把这些动态放到复平面中观察。

极点的位置很重要：

1. 极点在左半平面：系统响应衰减，趋于稳定。
2. 极点在右半平面：系统响应发散，不稳定。
3. 极点带虚部：系统可能振荡。

## 3. PID 控制

PID 是工业和嵌入式中最常用的控制算法。

PID 由三部分组成：

1. P：比例项，根据当前误差调节。
2. I：积分项，根据累计误差调节，消除稳态误差。
3. D：微分项，根据误差变化趋势调节，抑制超调和震荡。

可以用一句话记住：

```text
P 看现在，I 看过去，D 看趋势。
```

离散 PID 是单片机中的实现形式。控制器每隔一个采样周期读取反馈，计算误差，再输出控制量。

PID 实现时需要关注：

1. 采样周期。
2. 输出限幅。
3. 积分限幅。
4. 积分分离。
5. 微分滤波。
6. 参数整定。
7. 传感器噪声。
8. 执行器饱和。

PID 常见应用包括：

1. 电机定速控制。
2. 电机定位控制。
3. 温度控制。
4. 舵机控制。
5. 倒立摆控制。

电机控制中常见硬件和工具包括：

1. PWM：调节电机输入功率。
2. 编码器：测量速度或位置。
3. 电机驱动模块：放大控制信号，驱动电机。
4. SerialPlot：观察速度、目标值、误差和控制输出波形。

双环 PID 常用于倒立摆。内环控制角度，外环控制位置。它体现了复杂系统中多个闭环协同控制的思想。

## 4. MPC 模型预测控制

MPC 的核心思想是：用模型预测未来，再通过优化选择当前控制动作。

基本流程是：

```text
获取当前状态
-> 预测未来一段时间的系统变化
-> 构造代价函数
-> 加入约束条件
-> 求解最优控制序列
-> 执行第一个控制动作
-> 下一时刻重新预测和优化
```

MPC 的重要概念包括：

1. 预测模型：描述系统如何随输入变化。
2. 预测时域：向未来看多远。
3. 控制时域：优化未来多少个控制动作。
4. 代价函数：衡量跟踪误差、控制能量和动作变化。
5. 约束：输入限制、状态限制、速度限制、安全边界等。
6. 滚动优化：每次只执行第一个动作，然后重新求解。

MPC 的优点是能自然处理约束和多变量系统。它适合：

1. 机械臂。
2. 自动驾驶轨迹控制。
3. 能源调度。
4. 化工过程。
5. 慢动态系统。

MPC 的局限是计算量较大、依赖模型质量、实现复杂度高。

## 5. 模糊控制

模糊控制适合系统模型难以精确建立，但有人工经验规则的场景。

它的思路是用语言规则控制系统，例如：

```text
如果误差很大，就强力调节
如果误差较小，就轻微调节
如果误差变化太快，就提前抑制
```

模糊控制系统通常包括：

1. 模糊化：把精确输入变成模糊量。
2. 规则库：根据经验写控制规则。
3. 推理机：根据规则推理控制结果。
4. 解模糊：把模糊结果变成实际控制量。

适合场景包括：

1. 洗衣机控制。
2. 温度控制。
3. 风扇调速。
4. 难以精确建模但经验规律明显的系统。

## 6. 控制方法对比

几种控制方法可以这样理解：

```text
PID：简单、常用、容易落地，适合大量单变量闭环控制。
MPC：能预测未来、能处理约束，适合复杂多变量系统。
模糊控制：不依赖精确模型，适合经验规则清楚的系统。
状态空间控制：适合现代控制、多变量系统和内部状态分析。
拉普拉斯方法：适合经典控制、传递函数和频域分析。
```

# 五、项目模块

项目模块把前面三类能力放到实验中验证。

项目可以分成三大类：

1. 机器学习实验。
2. 深度学习实验。
3. 自动控制实验。

这些项目对应设备控制中的三种能力：

```text
机器学习：识别、预测、分类、推荐
深度学习：视觉、语音、文本、序列和策略学习
自动控制：反馈、稳定、跟踪和执行
```

## 1. 机器学习实验

### 房价预测

任务：根据房屋特征预测房价。

类型：监督学习回归任务。

常用工具：

1. Python。
2. NumPy。
3. Matplotlib。
4. scikit-learn。
5. PyTorch。

核心模型是线性回归：

```text
f(x) = wx + b
```

实验流程：

```text
读取数据
-> 可视化数据
-> 定义模型
-> 定义均方误差
-> 用梯度下降训练
-> 绘制损失曲线
-> 用模型预测新样本
```

意义：理解监督学习回归任务的完整闭环。

### 恶性肿瘤分类器

任务：根据患者特征判断肿瘤是良性还是恶性。

类型：二分类任务。

核心模型是逻辑回归：

```text
z = w^T x + b
预测概率 = sigmoid(z)
```

评价指标包括：

1. Accuracy。
2. Precision。
3. Recall。
4. F1 score。
5. Confusion Matrix。

意义：理解分类问题、决策边界和医学任务中召回率的重要性。

### 图像分类器

任务：把图像分成猫、狗、车、人等类别。

类型：多分类图像任务。

常用方法：

1. PyTorch。
2. CNN。
3. ResNet、MobileNet、EfficientNet 等预训练模型。
4. 迁移学习。

流程：

```text
整理图片目录
-> 数据增强和归一化
-> 加载预训练模型
-> 替换分类头
-> 训练
-> 验证和测试
```

意义：把视觉感知能力接入设备控制系统。

### 手写数字识别

任务：识别 0 到 9 的手写数字。

类型：多分类任务。

常用数据集：MNIST。

意义：理解图像分类、softmax、多分类交叉熵和基础神经网络训练流程。

### 猫狗分类器

任务：判断图片是猫还是狗。

类型：二分类图像任务。

常用方法：

1. CNN。
2. 数据增强。
3. 迁移学习。
4. 训练集、验证集、测试集划分。

意义：练习真实图片数据集上的深度学习分类流程。

### 推荐系统

任务：根据用户和物品的历史评分或交互做推荐。

核心方法：

1. 协同过滤。
2. 基于内容的推荐。
3. 嵌入向量。
4. 均值归一化。

放在设备控制里，可以迁移为参数推荐、维护方案推荐和工况策略推荐。

## 2. 深度学习实验

### 猫分类器

任务：判断一张图片是不是猫。

意义：理解二分类神经网络、前向传播、反向传播、损失函数和训练循环。

### 垃圾邮件分类器

任务：判断文本是否为垃圾邮件。

类型：文本分类任务。

涉及内容：

1. 文本预处理。
2. 特征表示。
3. 分类模型。
4. 准确率、精确率、召回率。

意义：理解自然语言任务和分类任务的一般流程。

### YOLO 目标检测

任务：在图像中检测目标的位置和类别。

不同于图像分类，目标检测不仅要判断“是什么”，还要判断“在哪里”。

输出通常包括：

1. 边界框。
2. 类别。
3. 置信度。

在设备控制中，YOLO 可以用于机器人抓取、视觉巡检、目标跟踪和安全监控。

### 人脸识别

任务：判断两张人脸是否属于同一个人，或识别具体身份。

核心思想：

1. 把人脸图像映射成特征向量。
2. 比较特征向量距离。
3. 距离小则认为相似。

意义：理解特征嵌入、相似度和验证类任务。

### 触发词检测

任务：从音频序列中检测关键词。

常用方法：

1. 音频特征提取。
2. RNN、GRU、LSTM。
3. 序列标注。

意义：理解语音和时间序列数据的建模方式。

### 英法翻译

任务：把英文句子翻译成法文。

类型：序列到序列任务。

涉及内容：

1. 编码器。
2. 解码器。
3. Attention。
4. Transformer 思想。

意义：理解输入序列和输出序列长度不固定时的建模方法。

### 月球着陆器

任务：控制着陆器安全降落。

类型：强化学习任务。

核心流程：

```text
观察状态
-> 选择动作
-> 获得奖励
-> 更新策略
-> 反复训练
```

意义：理解状态、动作、奖励、策略和控制决策之间的关系。

### 用电负荷预测

任务：根据历史用电数据预测未来负荷。

类型：时间序列预测任务。

常用模型：

1. RNN。
2. LSTM。

## 3. 自动控制实验

### STM32 红外传感器计次

任务：使用对射式红外传感器统计物体经过次数。

涉及内容：

1. GPIO。
2. 外部中断。
3. 计数变量。
4. OLED 或串口显示。

意义：理解传感器输入、中断响应和嵌入式事件处理。

### PID 电机定速控制

任务：让电机转速稳定在目标速度。

系统组成：

1. 电机。
2. 电机驱动。
3. 编码器。
4. STM32。
5. PID 控制器。
6. PWM 输出。

流程：

```text
读取编码器速度
-> 与目标速度比较
-> PID 计算控制量
-> 调整 PWM
-> 电机速度变化
-> 再次反馈
```

意义：理解闭环速度控制。

### PID 电机定位控制

任务：让电机转到目标位置。

定位控制和定速控制相比，更关注角度或位置误差。

意义：理解位置闭环、稳态误差、超调和响应速度。

### 双环 PID 倒立摆

任务：让倒立摆保持平衡。

通常包含：

1. 角度环。
2. 位置环。
3. 电机驱动。
4. 编码器或角度传感器。
5. 实时 PID 计算。

意义：理解复杂系统中多个闭环的协同控制。

### MPC 机械臂控制仿真

任务：用模型预测控制机械臂轨迹或状态。

涉及内容：

1. 系统模型。
2. 预测时域。
3. 约束条件。
4. 代价函数。
5. 滚动优化。

意义：理解 MPC 在复杂多变量系统中的作用。

### 模糊控制洗衣机

任务：根据衣物脏污程度、重量等规则控制洗衣过程。

涉及内容：

1. 模糊变量。
2. 隶属函数。
3. 规则库。
4. 模糊推理。
5. 解模糊。

意义：理解不依赖精确模型、依靠经验规则的控制方式。

# 六、四个模块的组合关系

设备控制中的四个模块不是分开的课程，而是会在一个系统中同时出现。

以智能电机控制系统为例：

1. C 语言编写编码器、电机驱动、串口通信和定时器中断。
2. STM32 运行实时控制程序。
3. C++ 封装电机、编码器、PID 控制器和系统状态。
4. PID 控制电机速度或位置。
5. SerialPlot 显示速度、目标值、误差和控制输出。
6. PyTorch 训练故障检测模型或负荷预测模型。
7. 机器学习模型判断设备状态是否异常。
8. 项目实验验证系统是否稳定、准确、可靠。

再以视觉机器人为例：

1. 摄像头采集图像。
2. 深度学习模型识别目标位置。
3. 控制算法计算运动轨迹。
4. STM32 或其他控制器驱动电机。
5. 传感器反馈位置和姿态。
6. 控制器持续修正动作。

四个模块的对应关系可以总结为：

```text
C 语言：贴近硬件，写驱动和底层逻辑
STM32：承载真实嵌入式控制系统
C++：封装设备对象和业务流程
PyTorch：训练和验证智能模型
机器学习：从数据中学习规律
自动控制：根据反馈稳定动作
项目：把所有能力整合并验证
```

# 七、最终总结

设备控制完整学习内容可以压缩成一条主线：

```text
先用编程把设备跑起来，
再用机器学习让设备看懂数据，
再用自动控制让设备稳定行动，
最后用项目把所有知识连成系统。
```

编程模块解决实现问题。它包括 C、STM32、C++ 和 PyTorch，其中 C 和 STM32负责底层硬件，C++ 负责工程组织，PyTorch 负责模型训练。

机器学习模块解决智能问题。它包括监督学习、无监督学习、推荐系统、强化学习、深度学习、CNN 和序列模型，主要用于识别、预测、分类、异常检测和决策。

自动控制模块解决稳定问题。它包括状态空间、拉普拉斯变换、PID、MPC 和模糊控制，核心是通过反馈让系统稳定达到目标。

项目模块解决落地问题。它把房价预测、肿瘤分类、图像分类、YOLO、人脸识别、月球着陆器、用电负荷预测、红外计次、电机控制、倒立摆、MPC 和模糊控制等实验串起来。

所以，设备控制最终不是单独学某一门技术，而是形成一条完整能力链：

```text
硬件接口 -> 驱动程序 -> 数据采集 -> 模型学习 -> 控制算法 -> 执行器动作 -> 反馈调试 -> 项目验证
```

这就是四个文件压缩后的完整框架。
