# 机器学习

机器学习基础概念与项目流程

机器学习分为四个主要方面：机器学习流程、线性回归与逻辑回归、误差分析、系统评估指标。机器学习项目流程包含数据收集、模型建立、误差分析三个关键步骤，需要不断迭代优化。线性回归作为单层神经网络，通过全连接层和sigmoid激活函数实现二分类。逻辑回归使用不同的损失函数计算预测值与真实值的差异。误差分析通过比较模型输出与人类基准线来评估偏差和方差，判断是否存在欠拟合或过拟合问题。系统评估使用单一数值指标如F分数，综合考量准确率和召回率来评价模型性能。

模型优化与正则化技术

针对模型过拟合问题，采用正则化方法在成本函数中加入惩罚项控制权重大小。通过权衡数据拟合度与参数复杂度，防止模型过度关注特定特征。权重惩罚使模型减少对不重要特征的关注，提升泛化能力。优化过程涉及偏差-方差分析，比较训练集与验证集表现差异，采用收集更多数据或调整正则化强度等措施。F分数作为综合评估指标，通过调和平均数计算准确率与召回率，公式包含分子运算与分母组合的特定计算方式。

# 深度学习

深度学习核心技术架构

深度学习包含神经网络基础、深层神经网络、卷积神经网络(CNN)、残差连接(RN)和时序模型五大组成部分。神经网络从基础单层结构延伸到具有多个隐藏层的深层架构。卷积神经网络专门处理二维图像数据，残差连接解决了深度网络中的梯度消失问题。时序模型适用于音频等时间序列数据处理。强化学习作为特殊分支，通过月球登陆器等案例进行演示。实际应用涵盖垃圾邮件过滤、图像分类、目标检测(ULO)、人脸识别、移动端高效网络等场景。

RNN与LSTM用电负荷预测实战

该课程从零开始讲解如何使用RNN和LSTM神经网络进行单特征用电负荷预测，涵盖RNN基础理论、LSTM模型原理和完整的Python实战流程。学习路径按课程章节顺序，先建立LSTM理论认知，再搭建开发环境，最后完成用电负荷预测的实战项目。RNN神经网络基础部分包括基本结构、前向传播和反向传播。LSTM模型原理部分详细讲解遗忘门、输入门、输出门与细胞状态更新机制。开发环境搭建涉及PyTorch和PyCharm的安装配置。用电负荷预测实战包括数据读取、预处理、模型搭建、训练与评估。重点理解LSTM门控机制如何缓解RNN梯度消失问题。
