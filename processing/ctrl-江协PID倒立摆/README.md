# 江协科技 PID 入门教程（电机控制 / 倒立摆）

> 课程来源：[B站 — PID 入门教程](https://www.bilibili.com/video/av113576383612352)（免费、中文字幕），UP主：江协科技。

## 设备控制方向 · 入门指引

看完第 **1、2、3、5 集**（共 4 集，约 2 小时 49 分），即可掌握基本的 PID 算法原理、了解需要的实验设备，并独立完成 PID 闭环控制电机的实验。

### 你将接触到的内容

**PID 算法原理**

- P（比例）、I（积分）、D（微分）三部分的物理含义与数学形式
- 从连续 PID 到离散 PID 的推导，单片机上的实现逻辑
- 位置式 PID 与增量式 PID 的代码模板

**实验设备**

整套实验平台的核心组件：
- STM32 开发板
- 带编码器的减速直流电机
- 上位机工具 SerialPlot（串口波形观察与调参）

**闭环控制实验**

- 实现位置式 PID 与增量式 PID
- 闭环定速控制与定位控制
- 调参方法与波形分析
