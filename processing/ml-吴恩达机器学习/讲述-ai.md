## 开场

大家好，欢迎来到今天的节目。这期我们要聊的是一套"曾让几百万人入坑"的经典课程——吴恩达的机器学习专项课。这个专项课实际上是由三门小课组成的，我一共花了将近两周时间系统学完，总共142节、差不多20个小时。

## 第一课：监督学习——线性回归与逻辑回归

### 机器学习是什么

先搞清楚机器学习到底是什么。吴恩达引用了亚瑟·萨缪尔1959年的经典定义——"赋予计算机无需明确编程即可自主学习的能力"。听着抽象，但例子很好懂：你不用写一堆规则告诉电脑"什么样的邮件是垃圾邮件"，你只需要给它一堆邮件样本，让它自己学。萨缪尔自己就做了一个跳棋程序，让电脑自我对弈了几万局，自己学会了哪些是好的棋盘位置。

那机器到底怎么学呢？吴恩达说，**监督学习占到了实际应用的99%**。监督学习就是数据有标签——你知道正确答案是什么，让模型去学"输入到输出的映射"。垃圾邮件判断、语音识别、机器翻译、广告推荐、自动驾驶、产品缺陷检测……这些全是监督学习。

剩下的就是**无监督学习**——数据没有标签，让算法自己去发现结构。聚类、异常检测、降维，都是这一类。不过第一课的重点还在监督学习上。

### 线性回归与梯度下降——机器学习的根基

吴恩达用一个经典例子开场：**房价预测**。你有不同房子的面积和对应价格，要找到一条直线来拟合这个关系。公式极其简单：$f_{w,b}(x) = wx + b$。但关键问题是——你怎么知道 w 和 b 取多少才算"好"？

这就引出了核心概念：**代价函数**。把预测值和真实值之间的差距平方、求和、取平均，得到函数 $J(w,b)$。J 越小，模型越好。训练模型的本质，就是在找让 J 最小的 w 和 b。

怎么找呢？机器学习里最重要的优化算法——**梯度下降**。想象你站在一个凹凸不平的高尔夫球场上，360度看一圈，找到下山最快的方向，走一小步，停下来再看，再走。每一步的方向由**导数**告诉你，步长就是**学习率**。

关于学习率，吴恩达给了一个很实用的经验：从 0.001 开始，3 倍 3 倍往上试——0.001、0.003、0.01、0.03……分别看每次的学习曲线，找到最正常的那条。还有一个容易犯错的细节：梯度下降的代码里，w 和 b 必须**同时更新**，不能先更新一个再更新另一个。

吴恩达还提了一个有趣的性质：平方误差代价函数在数学上是**凸函数**，像个碗一样只有一个最低点。梯度下降不会困在局部最小值里，一定能找到全局最优。但后面讲逻辑回归的时候，这个好性质就没了。

### 多元特征、向量化与特征工程

现实数据通常不止一个特征。房价不光看面积，还看卧室数、楼层、地段。这时候模型就变成了 $f_{\mathbf{w},b}(\mathbf{x}) = w_1x_1 + w_2x_2 + \dots + w_nx_n + b$。

特征多了，有两个关键技巧。一是**向量化**——用 NumPy 的矩阵运算代替 for 循环，代码简洁到一行 `f = np.dot(w, x) + b`，更重要的是它利用了 CPU 甚至 GPU 的并行能力，速度比循环快得多。

二是**特征缩放**。如果特征的尺度差太多——面积几百几千，卧室数只有 1 到 5——代价函数的等高线图会被压扁，梯度下降来回震荡。吴恩达讲了三种缩放方法：除以最大值、均值归一化、Z-score 归一化。目标是让特征尺度大体落在 [-3, 3] 之间。

还有一个重要概念叫**特征工程**和**多项式回归**。如果你有房子的长和宽，可以自己构造一个新特征"面积 = 长 × 宽"。如果你觉得房价和面积不是直线关系，就用 $x^2$ 或 $\sqrt{x}$ 作为特征把直线变弯。特征工程的好坏，完全取决于你对业务的理解。

### 分类：逻辑回归与 Softmax

线性回归解决的是"预测数字"，但大量实际问题是"判断类别"——肿瘤良性还是恶性、邮件是不是垃圾邮件。这就是**分类**。

你可能想：线性回归直接套上去，大于 0.5 算 1，小于 0.5 算 0，行不行？吴恩达专门演示了为什么不行。假设数据里有个特别大的恶性肿瘤样本，线性回归为了在数值上迁就它，整条线会被拉歪，分类边界就不准了。

正确的方法是**逻辑回归**。名字有"回归"，但它是个分类算法。核心操作是把 $wx+b$ 塞进 Sigmoid 函数：$g(z) = \frac{1}{1+e^{-z}}$，输出被压缩到 0 和 1 之间。吴恩达建议直接把这个输出理解为**概率**。

代价函数也得换。平方误差在逻辑回归上不是凸函数，而是毛茸茸的、充满局部最小值的曲线。吴恩达引入了**交叉熵损失**——如果真实标签是 1、模型预测接近 0，损失就爆大；预测也接近 1，损失就接近 0。这样代价函数就变回了凸函数。

有趣的是，逻辑回归和线性回归的梯度下降公式长得几乎一样，但内部完全不同——因为 $f(x)$ 的定义不一样。如果任务是多分类——比如手写数字 0 到 9——就用 **Softmax 回归**，输出 N 个概率，加起来等于 1。

吴恩达还讲了一个工程细节：为了减少浮点数舍入误差，TensorFlow 推荐的做法是输出层用 `linear` 激活，在损失函数里加 `from_logits=True`，预测时再手动补上激活函数。

### 过拟合与正则化

模型不是越复杂越好。吴恩达画了三张图：**欠拟合**，模型太简单，连训练数据都没学好；**刚刚好**，泛化性好；**过拟合**，模型太复杂，把噪音都记住了，房价曲线能扭成麻花。

解决过拟合有三个方法。最优解是**增加训练数据**。不行就从一百个特征里**筛选**出关键的几个。第三个是**正则化**——在代价函数后面加上 $\frac{\lambda}{2m}\sum w_j^2$，惩罚太大的参数。注意 b 一般不需要正则化。$\lambda$ 太大就欠拟合，太小就过拟合。

这就是第一门课的全部内容。线性回归、逻辑回归、梯度下降、特征工程、正则化——这些是所有机器学习算法通用的底层构建块。第二门课会在这个基础上进入神经网络和决策树。

## 第二课：高级学习算法——神经网络、决策树与实战心法

### 神经网络：从需求预测到人脸识别

第二门课开场，吴恩达用一个**需求预测**的例子拆解神经网络。他手动做特征工程：价格加运费等于实惠度，销量代表认知度，价格加材质代表质量——三者合并输出"畅销可能性"。这就是一个三层的神经网络。

但真正的神经网络不需要手动做特征工程。你把所有输入全连接起来，隐藏层**自己**会学到抽象特征。吴恩达用人脸识别演示了这个过程：浅层学到边缘和短线，中层学到鼻子耳朵，深层学到一个完整的人脸。这些不是人设计的。

用 TensorFlow 实现只需要三步：指定架构、编译、训练。

```python
model = Sequential([
  Dense(units=25, activation='sigmoid'),
  Dense(units=15, activation='sigmoid'),
  Dense(units=1, activation='sigmoid')
])
model.compile(loss=BinaryCrossentropy())
model.fit(X, Y, epochs=10)
```

### 激活函数的选择：ReLU 一统天下

关于激活函数，吴恩达有一个明确的建议：**隐藏层直接用 ReLU**——$g(z) = \max(0, z)$。原因有两条。第一，计算比 Sigmoid 快得多。第二，也是更重要的——Sigmoid 两端都是平的，梯度趋近于零，梯度下降跑不动；而 ReLU 只有左半边是平的，右半边一直有梯度，收敛快得多。Leaky ReLU、tanh、Swish 也有用的，但 ReLU 对大多数场景足够了。

输出层的激活函数看任务：二元分类 Sigmoid，多分类 Softmax，回归 Linear。

一个必须理解的点：**没有激活函数**，线性函数的线性函数还是线性函数——不管加多少层，没激活函数就等价于一层线性回归，根本学不到复杂模式。激活函数是神经网络能表达非线性的根本原因。

吴恩达还推荐了 **Adam 优化器**，它能自动观察收敛方向、动态调整每个参数的学习率——朝着最优点冲的时候加大步伐，振荡的时候减小。今天大多数从业者都用 Adam 而不是原始梯度下降。

### 实战心法：偏差、方差与诊断流程

模型搭好了，怎么系统性地提升它？吴恩达给了一张诊断流程图。训练完后，先看训练集误差：如果大，说明**高偏差**，模型太弱，加大模型。如果训练误差小但验证误差大，说明**高方差**，过拟合了，加数据或加正则化。两个都小，就做好了。

关键是要引入**基准性能**。吴恩达拿语音识别举例：训练误差 10.8%，验证误差 14.8%，看起来还行？但人类误差是 10.6%。一对比就清楚了：训练误差接近人类水平（低偏差），但验证误差和训练误差差得远（高方差）。没有基准，你根本不知道什么是"好"。

遇到**数据倾斜**怎么办？比如罕见病患者只占 0.5%，一个永远说"没病"的模型准确率就能到 99.5%。这时候要用**精确率和召回率**，吴恩达推荐用 **F1 分数**来综合评估。他讨论了阈值调节的实际考量：侵入式治疗提阈值宁可漏诊，非侵入但危险的疾病降阈值宁可误诊。

数据不够有两个出路。一是**数据增强**——OCR 里旋转缩放扭曲字母，语音加背景噪音。二是**迁移学习**——拿别人训好的大模型，只换输出层，用自己的少量数据微调。这有效的直觉原因很简单：神经网络浅层学的是边缘检测、角点检测这些通用特征，对所有任务都适用。

吴恩达还有一个非常接地气的经验：做**误差分析**。比如 100 封垃圾邮件漏网了，手动分类——21 封医药推销、18 封钓鱼网站、7 封路由异常、5 封图片内嵌、3 封拼写错误。你就知道优先解决占大头的，而不是花好几周处理那 3 封拼写错误。

### 决策树、随机森林与 XGBoost

除了神经网络，吴恩达还讲了一大类算法：**决策树**。他用猫狗分类的例子特别直观——根据耳朵形状、脸型、有没有胡须一步步判断。算法的核心就两个问题：选哪个特征分裂（选**信息增益**最大的，也就是熵减最多的），什么时候停（纯度为 1、到最大深度、或样本太少）。

单棵树不够稳定，于是有了**随机森林**——放回抽样生成多份略有不同的数据集，每份训一棵树，投票决定。吴恩达给的经验值是：树的数量 B 取 100，每棵树的特征数 k 取 $\sqrt{n}$。

但吴恩达说现在最常用的是 **XGBoost**。核心改进非常巧妙：给之前被分错的样本加权，就像练钢琴时专门练不熟的部分。XGBoost 在 Kaggle 比赛里和深度学习并列是赢比赛最多的算法，吴恩达夸了它五个优点：开源、快速高效、自带默认参数、内置正则化、竞赛竞争力强。

什么时候用决策树、什么时候用神经网络？吴恩达总结得很清楚：决策树适合**结构化数据**，训练快，可解释性强。神经网络适合**所有类型**，尤其是图像、音频等非结构化数据，还能用迁移学习，可以多个网络串在一起端到端训练——决策树只能一棵一棵来。

第二课到此结束。神经网络和决策树是两大主流模型，偏差方差诊断和误差分析是调优模型的核心方法论。第三课进入无监督学习和强化学习。

## 第三课：无监督学习、推荐系统与强化学习

### 无监督学习：聚类与异常检测

第三课首先讲两种无监督学习算法。第一种是 **K-means 聚类**——对没有标签的数据进行分组。随机初始化几个质心，每个点归入最近的质心，重新计算质心，重复直到不变。吴恩达提醒一个关键技巧：跑 50 到 100 次不同的随机初始化，选代价函数最低的那次。

第二种是**异常检测**，工业界应用非常多——发动机质检、数据中心监控、金融欺诈。核心是用高斯分布对每个特征建模，新样本在所有特征上的概率乘积太小就标记为异常。吴恩达强调了一个根本区别：异常检测是在划定"正常范围"，所以新类型的异常也能捕获；监督学习是在学"特定正样本的特征"，遇到没见过的异常就识别不出。所以欺诈检测这种异常手段不断变化的场景，更适合异常检测；垃圾邮件这种类型相对固定的，适合监督学习。

### 推荐系统：协同过滤与基于内容的过滤

商业应用里最普遍的是推荐系统。吴恩达讲了两大类。

**协同过滤**是根据和你相似的用户的行为来推荐，本质上是在同时学习每个用户的偏好参数和每部电影的特征。一个重要的实现细节是**均值归一化**——对完全没有评分记录的新用户，不做归一化的话，梯度下降会把他的参数全压到零，推荐就会毫无意义。均值归一化之后，新用户默认能得到每部电影的平均分。

**基于内容的过滤**是用两个神经网络分别算出用户向量和内容向量，点乘得到评分。面对海量目录时，吴恩达给了一套工程方案——"检索加排序"：先用多个策略（用户最近看的电影找相似、最活跃的类型找 Top N、地区热门等）粗筛出几百个候选，再让模型精排。

### 强化学习：试错中学习

最后的强化学习，吴恩达用了最直观的比喻——训练小狗，做对了说"good dog"，做错了说"bad dog"。

核心是四要素：状态、动作、奖励、下一个状态。算法在环境中不断试错，目标是最大化长期回报。吴恩达用火星探测器的例子演示了折扣因子和回报计算，然后引出最重要的公式——**贝尔曼方程**：

$Q(s, a) = R(s) + \gamma \cdot \max_{a'} Q(s', a')$

当前动作的价值等于即时奖励加上折扣后的最佳未来价值。如果环境有随机性，就取期望值。

吴恩达非常坦诚：强化学习的商业应用比前两门课少得多，他自己也只有少数几次用到，主要在机器控制领域。但他演示了一个月球着陆器——用 DQN 算法让神经网络学会在模拟环境中平稳降落——非常酷。强化学习目前调参还很痛苦，参数设差了可能会花一百倍时间训练。他的原话是："监督学习设置不合适的学习率可能要花 3 倍时间，强化学习可能要花 10 倍甚至 100 倍。"

## 结尾

好，三门课讲完了。我们快速回顾一下整条脉络——

**第一课**，打地基：线性回归、逻辑回归、梯度下降、特征工程、正则化。这是所有机器学习共享的底层语言。

**第二课**，上武器：神经网络（从全连接层到 ReLU 到 Adam）、决策树到 XGBoost，再加上偏差方差诊断、误差分析、迁移学习这套实战方法论。

**第三课**，拓边界：无监督学习（K-means、异常检测）、推荐系统（协同过滤、基于内容过滤）、强化学习（贝尔曼方程、DQN）。

这门课可能没有讲 Transformer 这类最前沿的架构，但吴恩达建立的那些底层直觉——梯度下降怎么下山、代价函数怎么衡量、偏差和方差怎么诊断、误差分析怎么做——这些才是工程中每天都在用的核心思维。无论你之后用 XGBoost 还是神经网络，这些思维是共通的。
